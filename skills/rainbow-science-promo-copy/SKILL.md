# Rainbow 科普视频宣传文案

为同一条科普视频生成一套可直接发布的跨平台文案。品牌署名为“rainbow鱼”。系列名沿用本期用户或项目已确认的选择；“每天5分钟科普”与“每天5分钟知识”尚待统一，不自行定名。需要系列或封面尺寸依据时读 [差异记录](../rainbow-video-cover/references/series-and-size-status.md)；没有确认依据可先省略系列前缀。文案要像一个懂工程、会讲故事的人在分享发现，先抛出生活问题，再给出可验证的结果，避免论文摘要式口吻。

## 发布字段与输出范围

只输出本次指定的平台；未指定而要求全平台时覆盖四个平台。区分写作建议与平台硬性限制：下列长度、段落和话题数量只是写作建议，最终以当前投稿页面、官方活动规则为准。发布前或用户要求“自动符合规范”时，读 [references/platform-preflight.md](references/platform-preflight.md) 并执行检查。不能把离线字符计数称为平台校验通过。

1. **标题**：需要新拟时给 3 个主标题候选并推荐 1 个，再给各目标平台最终标题。已选定标题优先沿用，仅因实际字段限制或事实冲突修订并说明原因。标题中只保留一个核心冲突。
2. **正文**：按平台语气分别写；第一句能独立成立，前两句不要复述标题。可直接粘贴的正文中不混入候选标题、编辑说明或首评。
3. **话题与提及**：分别保存为 `tags` 和 `mentions`；话题先具体主题，再系列和泛兴趣词，避免同义堆叠。活动必带话题、提及优先，须在真实页面选择候选并核对选中结果。
4. **章节与署名**：章节与同版本视频时间线对应；素材来源、音乐署名、事实限定与AI声明保留在适合的平台字段中。分区、合集和活动分别记录，不互相替代。
5. **首评候选**：需要时给一句提问或可参与的小实验，与正文分开。生成候选不等于授权发送或置顶，执行发布交给 `rainbow-publish` 并沿用本次授权范围。
6. **封面短文案**：标题可调整时给同一底图使用的两版短标题，各不超过12个汉字，围绕同一个可兑现的承诺；必要副句不超过16个汉字。封面只保留一个视觉问题，用户已锁定的标题沿用。只交文案时说明缩略图尚待合成检查；同时做封面时按封面技能比较320 px与160 px可读性。

交付最终文案时，为每个平台保留明确的 `title`、`description`、`tags`、`mentions`、`cover`、`collection`、`category`、`chapters`、`credits`、`source_type`、`ai_declaration`、`campaign` 字段（不适用可省略），并记录视频版本、时长及校验结果。正文已包含的署名不在投稿时重复追加；首评候选单独存放。

## 标题规则

- 需要系列前缀时使用本期已确认名称，格式可为“已确认系列名｜本期主题”；交付成稿填入真实名称，不保留占位字。尚未确认就只写主题，不从历史默认句推定名称，也不擅自给已确认名称换简称。
- 标题优先使用“日常物件/现象 + 反常识问题 + 可见结果”，例如“支架凭什么敢挖空？”；专业词放在后半句或简介中解释。
- 优先使用真实动词：挖空、变薄、承重、失效、长出来、少一半；少用“揭秘、震撼、顶级、保姆级”等泛化词。
- 不编造播放量、实验数据、论文结论或平台热词。若引用搜索到的高播放案例，只提炼结构，不照搬标题。
- 避免标题党承诺与视频内容不一致；“一口气看懂”只在内容确实覆盖完整链路时使用。

## 自然表达与必要说明

正文先给读者一个想看下去的问题，再用具体画面和工程取舍推进。用成片能兑现的悬念吸引人，避免写成参数清单或审核说明。

- 把必要限定嵌进叙述，例如直接写“最大设计续航30小时”，不用再反复解释“并非实飞时长”。教学画面可自然写为“用3D动画拆开机翼”，无需叠加多句否定式免责声明。仍须避免让观众误以为看到了实测或厂家结构。
- 平台已有AI内容字段时填写该字段，正文不机械重复同一声明。来源和音乐署名合并成文末一句，完整参考资料保留在本地文案包；平台、许可或用户要求展示的具体信息照常保留。
- 少用“核心是：”“看点：”“特别说明：”等提示语和连续冒号，优先写完整自然的句子。章节时间、URL和机器字段中的冒号正常保留。
- 成稿清理使用 `lieflat-less-ai-tone` 的明确规则；用户要求增强吸引力或重写时按该范围改写，不把一般润色冒充该技能的检测结论。

## 平台适配

- **抖音**：一句强冲突 + 一个结果；正文 2–4 行，口语化，话题 4–6 个。
- **小红书**：标题可带一个明确收益点；正文用“看到什么—为什么—看完得到什么”的三段式，话题 6–8 个，避免营销腔。
- **B站**：标题允许更具体，可加入 SIMP、有限元、3D 打印等检索词；简介交代内容时间线和适合人群，话题 4–6 个。
- **微信视频号**：标题和正文更克制；首句适合转发给朋友，话题 3–5 个。

## 写作流程

1. 从视频中提取一个可见问题、转折和结果，列出“封面承诺→开头画面→正文结论”的对应关系，以时间点／镜头号和结论证据核对。深度教程可以承诺一个可复现成果与学习价值，不强行制造生活悬念；仅有脚本时区分计划与已验证画面。
2. 先锁定本次视频版本、对应封面与文案来源；时长、章节、结论以同版本交付为依据。发现旧版文案时另存修订稿，不把旧时长或旧章节直接带入新版。只有需要新标题灵感时再查公开案例，记录结构，不复制原句或把历史播放量当成当前表现。
3. 先写一个跨平台主标题，再按平台语气改写；不要把同一段话重复四次。
4. 检查三处承诺是否在对象、问题、结果范围与条件上对应；不要求重复相同口号。结论不足就收窄标题，画面缺失就记录缺口，不替成片编造兑现。再删空泛夸张词、重复信息、无法验证的数字和过长副标题，解释必要专业词。
5. 核对各目标平台当前字段、封面、活动入口和声明，完成有依据的精简，再保存最终文本与校验结果。超限时改写完整语义，不能硬截断科学限定、来源或署名；“设计值／实测值”“教学演示／真实实验”不能互换。网页尚不可用的项目记为待核验，不宣称保证过审或获得活动资格。
