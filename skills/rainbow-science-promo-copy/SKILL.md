# Rainbow 科普视频宣传文案

为同一条科普视频生成一套可直接发布的跨平台文案。默认系列名为“每天5分钟知识”，品牌署名为“rainbow鱼”。文案要像一个懂工程、会讲故事的人在分享发现，先抛出生活问题，再给出可验证的结果，避免论文摘要式口吻。

## 固定输出

每次输出以下模块，并标明平台：

1. **主标题候选**：给 3 个，分别偏好奇、偏结果、偏反常识；推荐 1 个主用标题。
2. **平台标题**：抖音、小红书、B站、微信视频号各 1 个，控制在手机首屏可读长度；标题中只保留一个核心冲突。
3. **简介/正文**：按平台语气分别写；第一句必须能独立成立，前两句不要复述标题。
4. **话题**：每个平台 4–8 个，先放具体主题，再放系列和泛兴趣词；避免堆同义词。
5. **首评/置顶评论**：一句提问或一个可参与的小实验，引导评论，不使用“求三连”等空泛话术。
6. **封面短文案**：主标题不超过 12 个汉字，副句不超过 16 个汉字；封面只保留一个视觉问题。

## 标题规则

- 系列标识统一写作：`每天5分钟知识｜本期主题`。如果封面空间紧张，可缩短为 `每天5分钟·本期主题`。
- 标题优先使用“日常物件/现象 + 反常识问题 + 可见结果”，例如“支架凭什么敢挖空？”；专业词放在后半句或简介中解释。
- 优先使用真实动词：挖空、变薄、承重、失效、长出来、少一半；少用“揭秘、震撼、顶级、保姆级”等泛化词。
- 不编造播放量、实验数据、论文结论或平台热词。若引用搜索到的高播放案例，只提炼结构，不照搬标题。
- 避免标题党承诺与视频内容不一致；“一口气看懂”只在内容确实覆盖完整链路时使用。

## 平台适配

- **抖音**：一句强冲突 + 一个结果；正文 2–4 行，口语化，话题 4–6 个。
- **小红书**：标题可带一个明确收益点；正文用“看到什么—为什么—看完得到什么”的三段式，话题 6–8 个，避免营销腔。
- **B站**：标题允许更具体，可加入 SIMP、有限元、3D 打印等检索词；简介交代内容时间线和适合人群，话题 4–6 个。
- **微信视频号**：标题和正文更克制；首句适合转发给朋友，话题 3–5 个。

## 写作流程

1. 从视频中提取一个可见的日常问题、一个转折和一个结果。
2. 查找同主题的高播放公开标题，记录其“对象、冲突、结果、专业词”的排列方式；不得复制原句。
3. 先写一个跨平台主标题，再按平台语气改写；不要把同一段话重复四次。
4. 检查：有没有空泛夸张词、重复信息、无法验证的数字、过长副标题或专业词未解释。
5. 最后给出推荐发布顺序和一个可用于评论区互动的问题。
