# 组会演示制作

把用户提供的人物信息、研究材料和未来构想，组织成听众能理解、现场能讲清、换电脑能使用的演示。以内容和证据为骨架，让动画解释过程，让交互服务讲述。

## 领域子版本

物理逆问题、扩散载荷反演或 PINN 研究的文献先行三维组会，可使用 [zuhui-inverse-physics](../zuhui-inverse-physics/SKILL.md)。该子版本补充坐标与受力约定、可辨识性、概率校准和真实/示意证据边界；其他组会仍沿用本技能。

## 开始时做什么

先判断是新建演示、局部改版，还是仅打包。已有工程先查看启动方式、章节配置、素材目录、依赖和用户当前反馈；局部修改保留已确认的内容与交互，避免重新设计整套作品。

用户只要提纲、文案或讲稿时，只完成相应文稿，不扩展为网页或视频工程。

新建时从已有上下文提取信息，只补问缺口。可把 [内容填写单](assets/内容填写单.md) 交给用户，但不要让用户为了开始工作填完整份问卷。优先了解：

1. **讲给谁、讲多久、想留下什么印象**：首次见面、阶段进展，还是讨论下一步方向。
2. **有哪些已知内容和素材**：个人介绍、研究主题、真实过程与结果、现有文件或链接。
3. **怎样交付和播放**：现场交互网页、自动播放视频、可编辑幻灯片，是否需要换电脑离线启动。

照片、校徽、风格参考、声音和生成预算都是按需补充项。缺少照片不应阻塞研究内容制作；缺少正式成果时可以呈现研究问题与计划，不得把计划写成结论。信息足够就实施，先完成不依赖缺失信息的工作。

## 默认方向与选择

以下仅用于用户未指定时，已有明确要求优先。

| 项目 | 推荐起点 | 何时调整 |
| --- | --- | --- |
| 画幅 | 16:9、1920×1080；视频 30 fps | 根据投影、屏幕与交付要求调整 |
| 风格 | 浅色背景、单一主色、少量强调色、大字号 | 从用户参考图提取配色、层级、间距与构图 |
| 内容 | 一页一个问题或一个研究阶段，主视觉占主要面积 | 信息密度过高时拆页；不要为了页数重复内容 |
| 现场模式 | 人工翻页，当前页可视化自动运行 | 按用户选择滚轮、按键或按钮；点击模型不误翻页 |
| 声音 | 现场讲解版无配音、无背景音乐 | 用户明确需要解说、音乐时再加入 |
| 技术 | 动态网页和视频共用 React/Remotion 场景 | 仅需可编辑 PPT 时优先制作 PPT；不强制转为网页 |
| 生成素材 | 先使用真实、本地且可复用的素材 | 数字人、概念片等确有帮助时按预算生成 |

## 高校组会截图风格模板

当前用户已保存一套浙江大学高校组会参照：[持久版式与资产](../zuhui-inverse-physics/references/zju-projection-style.md)。需要沿用该风格时直接读取其中的参照图、矢量校徽、封面/正文 SVG 和样式，不再要求重新提供截图。采用大字精简模式：默认去掉正文小字、重复副标题和来源脚注，细节收进讲稿/来源面板；必要证据类型仍通过清楚的标题或大字图例表达。用户另指定风格或机构时遵循新要求。

当用户提供高校组会截图作为视觉参考时，提取版式规则而不是复制截图中的身份、标题、日期或研究内容。默认采用 16:9、白底、深蓝主色、顶部系列标题区、顶部蓝紫细分隔线、右上角机构标志、中文章节序号和右上角页码。封面可采用“系列标题头 + 大幅蓝色主题带 + 汇报人 + 日期”的结构；主题带正文使用白色大字，关键副标题使用黄色。正文使用高对比黑色大字，红色表示风险或阻断，黄色表示关键结论；强调色只用于传达状态，不把整页做成装饰性渐变。

截图式高校组会模板的文字层级要在投影距离下成立：顶部系列标题和章节标题使用高字重与明显字号差，正文结论优先使用深蓝或黑色粗体，说明文字保持较短行宽和足够行距；重要结论可放进整宽蓝色主题带，使用白色粗体并以黄色突出关键词。字号放大后重新检查标题、脚注和图例的安全区，不能用缩小字体掩盖溢出或重叠。

模板至少提供封面、章节页、问题定义页、技术流程页、结果页和结论页。页面布局固定标题、正文、主视觉、证据标签和页码的层级；正文不被图表或三维场景遮挡，投影尺寸下仍能快速扫描。不要把每个章节机械拆成相同数量的小节，按研究问题和讲述节奏组织页面。

机构标志通过配置传入，不写死学校、个人或项目身份。优先使用机构公开的 SVG 等矢量资产；只有位图时才进行人工矢量化，并保留原始来源、处理方式和展示用途记录。使用前检查透明背景、比例、清晰度和安全边距。

复杂物理系统优先使用可交互主场景。场景中的耦合层、传感器、力箭头和损伤状态应能点击切换；点击只更新对应物理通道、图例、曲线和说明，不触发翻页。桌面现场模式应支持滚轮翻页，使用 Shift 或 Ctrl 加滚轮进行三维缩放，并提供小型全屏按钮。至少提供暂停、继续、复位、旋转、缩放、目录或页码定位以及证据来源入口。动态必须解释输入、过程和输出，不能只是背景装饰。

对于风机、车辆、机器人或其他结构系统，三维主模型应优先使用工程化几何：合理的比例、锥形或变截面构件、连接件、支撑边界、作用点和坐标关系。低模示意可以用于概览，但不能把主要研究对象做成无连接关系的玩具几何；所有简化、变形放大、箭头归一化和隐藏层都要在讲稿或图例中说明。

每页显式区分真实结果、仿真结果、原理示意、当前阻断和未来计划。截图中的示意动画、模型轨迹和后验样本不得标成实测过程；失败的域外工况、未完成的材料或连接等效以及缺失的同步真值应在结果页直接呈现。

### 结果优先的现场模板

当用户要求“少文字、多展示”时，采用结果优先的顺序：先展示单个子系统的观测或场，再展示耦合前后的差异，最后强调方法带来的信息增益。每页保留一个结论句、一个证据标签和一个主要视觉，正文尽量压缩为 1–2 个短段；不要为了填满版面重复“问题—过程—输出”三栏。

复杂物理系统的内容顺序服从用户的讲述目标。用户强调整体耦合时，在同一页、同一模型和同一时间轴展示所有通道，再通过聚焦按钮解释局部；不要强制拆成多个重复的子系统页。单个子系统的结果可用真实实验图、载荷热力图、时序曲线或参数场补充，整机主场景始终保留结构连接关系。

### 等比全屏与有意义的交互

- 用固定 16:9 逻辑画布整体等比缩放，缩放因子取可用宽度/画布宽度与可用高度/画布高度的较小值。宽屏、非 16:9 屏和手机均允许留边，不独立拉伸画布、模型或字体。全屏变化后同步更新尺寸。
- 主场景使用工程比例与结构连接，细化真实对象特征；浮式系统须包含半潜柱、浮筒、连接构件、导缆点和海床锚固，避免孤立薄圆盘。几何近似和坐标压缩必须标明。
- 每个模式按钮都要切换明确的信息，如受力箭头、响应热力、观测点、后验均值和区间；通道按钮同时更新高亮、图例、局部数据和证据说明。没有数据的通道显示边界或原理说明，不编造数值。
- 选择通道不是重新运行求解器，不能把高亮开关称为耦合消融实验。通道切换不重置相机与时间，不触发翻页。
- 数据入口直接链接当前结果对应的 CSV、NPZ、JSON 或原图，并提供原始相对路径、单位、版本和 SHA-256。不同实验协议的时序、汇总分数不能拼接成一个结果。
- 已保存动画帧可插值以改善连续性，但插值不是新求解结果。未保存的去噪过程必须标为原理示意；后验样本必须来自实际采样数组。
- 自动检查实际全屏、移动/桌面画幅、像素非空、暂停稳定、模式差异、旋转缩放、末页停留、来源链接、离线加载及资源释放。图表页隐藏没有作用的三维控件。

现场步骤控件使用“观测、场、后验、回放”等短标签或图标，不显示无语义的 1、2、3、4。右上角页码只显示当前页，不显示总页数；顶部系列标题可以简化为“研究成果”。滚轮负责翻页，Shift/Ctrl 加滚轮负责三维缩放，小型全屏按钮不占用主要视觉。

真实结果图和动态三维图可以同页出现：前者展示已保存数据，后者解释空间关系和作用方向。两者必须有清晰的来源或证据标签；归一化颜色、放大变形、箭头缩放和原理性采样不得冒充新的求解结果。避免将演示过程称为“修复”，直接展示结果、比较和研究边界。

## 制作流程

### 1. 从材料中确定可讲的内容

阅读 [内容与分镜](references/内容与分镜.md)。用“问题—输入—过程—输出—下一步”整理每项研究，将内容区分为已完成、正在做、拟探索。说明用户本人参与的部分，区分复现、改进和原创工作。

真实结果注明来源、单位与适用条件；示意图和假设模型明确标识。仅凭仓库名称、截图或宣传性介绍，不能推断已经完成的功能。源研究工程作为只读素材来源，把必要文件复制到独立演示工程。

形成章节表：每页目的、主要视觉、步骤、证据状态、讲述时间、交互方式、素材缺口和讲稿要点。向用户简要说明重要假设即可，不把常规排版决策变成逐项审批。

### 2. 先做一页完整样板

选一个最能代表内容复杂度的页面，同时落实字号、视觉主体、步骤切换和讲稿。按最终投影尺寸检查可读性，再复用设计系统到其余章节。

标题直说内容，如“之前的研究”“目前的进展”“后续方向”。避免未经用户要求的口号、夸张成果描述和“点击推进／由你掌握节奏”等制作过程文案。操作提示放在控件、悬浮提示或启动说明中。

### 3. 让每个步骤展示自己的内容

需要动态、三维、数字人或生成素材时，阅读 [可视化与交互](references/可视化与交互.md)。每个步骤必须具有可辨认的输入、视觉状态或输出，不能只换标题而复用同一段无关动画。

先实现信息与状态变化，再加入平滑衔接。区分页面停留、流程进度、三维视角和人物动作；切换一个步骤不应无意重播人物或翻页。现场等待不自动切到下一页，自动视频版使用独立时间表。

### 4. 完成演示与讲稿

统一章节配置管理标题、场景、步骤、自动版时长、动画范围、来源与讲稿。现场版和视频版共用内容；现场版允许停留和操控，视频版按帧确定性播放。保持同一套依赖兼容，不无故升级已有工程。

逐页写口语讲稿，补足屏幕上省略的解释。另写简短操作提示，说明讲到哪里切换步骤、拖动模型或停下讨论。讲稿不得新增画面或材料未支持的成果。

### 5. 验证并交付

阅读 [验证与离线交付](references/验证与离线交付.md)，执行与本次改动相称的检查。用户要求“另一台电脑一键运行”时，交付可实际启动的免安装包；不能把要求用户安装开发环境的源码压缩包称为一键版。

按需交付：演示网页、源码、讲稿、分镜、素材来源、自动视频、离线启动包。用户仅要求局部修改时，更新受影响的内容和相应产物，不重新生成无关素材。完成后给出成品入口、最少启动步骤、实际验证结果和仍存在的限制。

## 完成标准

- 听众能说出汇报者在研究什么、已经做到什么、接下来打算做什么。
- 每页重点清楚，动态视觉解释内容，步骤之间存在真实区别。
- 身份、成果、数据、单位、来源和研究状态均有依据。
- 现场讲述节奏由用户掌控，暂停、返回、拖动与快速点击不会破坏状态。
- 请求的交付物真实可用；离线版使用本地资源，收费调用仅发生在制作阶段。
- 技能和输出模板不预置任何人的身份、单位、课题、项目路径、照片、徽标或密钥。

## 静态缩略图目录

现场演示的页面目录默认采用可点击的静态缩略图网格，每页显示实际页面画面、短标题与页码，区分主线和补充，并高亮当前页。缩略图由最终页面在代表性步骤与确定的暂停时刻渲染，保存为本地 asset；不使用无关配图或多个持续运行的三维画布。打开目录不重置当前页的时间、参数或相机；关闭后继续原状态，点击卡片才跳转。长目录可以滚动，打开时让当前页可见，键盘焦点与关闭入口始终可达。

标题、页序、数据或图形变更后重新生成对应缩略图，并与最终离线包或 EXE 一起交付。检查所有缩略图加载、图文与页码对应、补充页跳转、暂停状态保持和离线可用；不得只测试目录按钮能否打开。讲稿按同一页序生成，包含口述、公式的通俗解释、操作时机和页间过渡。

用户要求用最少内容讲清时，优先用一个贯穿例子连接问题、状态、过程、结局与检验；主线每页口述两至四句，再配一次有解释作用的操作。公式用一行白话建立与画面的对应，推导和详细结果保留在补充页或折叠讲稿中。动画中的坐标、数字、滑块与账本必须来自同一时刻和同一模型；教学分位点的连续移动不能冒充随机样本路径。时长随内容决定，不固定套用某个页数。
