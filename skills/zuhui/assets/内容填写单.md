# 组会内容填写单

不需要一次填完，也不需要先写成正式稿。先提供汇报目的、听众、时长和已有素材；其余信息可以边做边补。只填写愿意公开、与这次汇报有关的内容。

## 1. 这次准备怎么讲

- 场景：首次组会 / 阶段进展 / 方向讨论 / 其他。
- 听众：主要是什么背景，是否熟悉我的领域？
- 时长：约多少分钟，是否另留讨论时间？
- 核心信息：希望大家记住哪一件事？
- 播放方式：现场互动 / 自动视频 / 可编辑 PPT。
- 目标电脑：操作系统、是否有网络、是否需要免安装启动。

## 2. 自我介绍（需要时填写）

- 姓名或希望显示的称呼：
- 专业 / 所在团队 / 导师等需要公开的信息：
- 来自哪里、个人兴趣或适合破冰的小特点（可选）：
- 熟悉的方向：建议 2–3 项，各用一句普通人能懂的话解释。
- 想和团队一起尝试什么：
- 是否需要照片或人物形象：原照片 / 适度卡通化 / 动作视频 / 可旋转三维模型 / 不需要。
- 不想出现在页面中的信息：

## 3. 每项研究或工作（可复制本节）

- 标题：
- 状态：已完成 / 正在做 / 计划探索。
- 为什么做：解决谁的什么问题？
- 一句话说明：不用专业术语，怎样解释这件事？
- 输入：数据、条件、用户需求或其他起点是什么？
- 过程：通常经历哪 3–5 个步骤？
- 输出：得到什么模型、图表、文件或判断？
- 我参与的部分：
- 最希望展示的真实过程或结果：
- 已知限制、尚未验证的部分：
- 希望老师或同学给什么建议：
- 素材位置：可读取的文件路径、仓库、网页或说明。

## 4. 后续方向

- 想继续探索的问题：
- 与已有工作的联系：
- 第一件能做的小实验或小验证：
- 需要的数据、方法、设备或合作：
- 什么现象能说明值得继续，什么结果会促使调整方向：

## 5. 可提供的素材

- 原版徽标、品牌规范或风格参考图（可选）：
- 演示视频 / 界面截图 / 模型 / 网格 / 点云 / 高斯泼溅：
- 真实数据表、时间序列、计算结果和对应说明：
- 最能代表每个步骤的材料：
- 照片参考（如需人物形象，清晰正面和不同角度通常更有帮助）：
- 外部素材的作者、来源及许可（知道多少写多少）：
- 可以公开 / 仅本地展示 / 不得使用的内容：

## 6. 风格、互动和生成选项

- 喜欢的风格：简洁学术 / 轻松介绍 / 科技展示 / 参考图片。
- 翻页方式：滚轮 / 按键 / 按钮；是否允许点击空白翻页？
- 希望观众看清或可以操作的地方：步骤、进度、视角、参数等。
- 声音：现场讲解 / 配音 / 音乐；是否需要字幕？
- 是否允许使用生成 API：
- 如允许：指定服务、可用地域、累计费用上限（含重试）。
- 密钥只在本地环境变量或不随包分发的配置中设置，不填写在这份材料里。

## 最简请求示例

> 使用 $zuhui，帮我制作一套面向跨专业同学的组会演示，讲约 7 分钟。内容包含一页自我介绍、之前的工作、现在的进展和两个后续方向。真实素材在我提供的目录中。整体简洁，以动态可视化为主，现场手动翻页；另附逐页讲稿。先指出缺少的关键材料，不确定的事实不要补写。
