# 验证与离线交付

用于验收、导出和换电脑运行。检查范围随本次改动而定；通过相关检查后，不重复运行没有新增价值的全套测试。

## 交付清单

根据用户请求选择，不默认把所有格式都生成一遍。

| 交付物 | 应包含 |
| --- | --- |
| 交互演示 | 本地入口、完整静态资源、清晰启动方式 |
| 自动视频 | 确认的画幅、帧率、时长和音轨配置 |
| 可编辑幻灯片 | 可编辑文字与图表、替代静态画面；说明不能保留的网页交互 |
| 讲稿 | 逐页口语稿、时长建议、独立的操作提示 |
| 分镜与来源 | 章节表、素材作者与许可、真实/示意标记、变更记录 |
| 源码工程 | 兼容依赖、锁文件、复现命令，不包含密钥 |
| 免安装包 | 已构建网页、运行时、启动器、素材、运行说明和必要许可 |

文件名和版本要能区分“源码交付”与“免安装演示”。用户只要上台展示时，把最直接可用的入口放在交付说明最前面。

## 内容、交互、画面

**内容**：核对姓名与用户愿意公开的信息；研究状态、成果归属、图例、单位与数据来源；未来方向没有被写成已发布成果。人物照片和生成角色类型的描述准确。

**交互**：实际操作前进、返回、暂停、定位、步骤点击、三维旋转/平移/缩放、复位、全屏和结尾停留。快速连续输入、反向滚动、页面重入不能跳页、卡住或无意重播人物。循环页至少验证一次循环边界。

**画面**：在目标比例和常见投影尺寸截图检查正文、图例、控件、长标题、展开态和固定标识。对转场检查前帧、中间帧、后帧；对循环比较首尾；对带人物的片段检查手部、脸部和切换姿态。

**性能**：记录窗口尺寸、设备/浏览器环境、素材规模、取样时段、实际帧率或帧间隔。若构图或质量档位发生改变，一并记录；不得将端到端的对比宣称为只改变某个算法的性能实验。

只把已经运行的检查写为通过。截图、测试报告和已知限制应与最终交付版本对应。

## 视频导出

- 使用元数据工具核对分辨率、帧率、帧数、时长与音轨；静音版应确认没有意外音轨。
- 逐章检查代表画面和所有改动涉及的转场，完整解码以发现损坏帧或截断。
- 拼接片段前统一时间基准、编码参数与音轨配置；不能只看播放器显示的总时长。
- 长视频可缓存章节，仅重渲染受影响的章节及相邻转场，再验证最终合成。
- 导出的模型视频是固定视角录制，不应在说明中承诺可以像网页一样交互。

## 真正的一键离线版

先确认目标操作系统和架构。不得默认一个 Windows 启动器也能在 macOS 或 Linux 运行；制作对应平台产物，或明确所支持的平台。

如果需要本地 HTTP 服务，把可再分发且匹配架构的运行时与已构建网页一起封装，或采用合适的桌面应用打包方案。用户不应再安装包管理器、执行依赖安装或构建命令。系统浏览器可以作为前提，但应写清支持的平台和浏览器；没有浏览器这一前提时再评估更完整的桌面封装。

一个合适的目录可以是：

```text
meeting-portable/
├── 启动程序
├── web/                 已构建网页和本地素材
├── runtime/             需要的运行时及许可证
├── app/                 本地服务与启动逻辑
├── 资料/                讲稿、来源、分镜
├── 自动播放视频.mp4     按需附带
└── 使用说明.txt
```

启动器需要处理这些实际问题：

1. 以程序所在目录定位文件，支持中文和空格路径，不依赖原电脑盘符、工作目录或全局 PATH。
2. 本地服务只绑定回环地址，自动选择可用端口；通过就绪信号后打开浏览器，不只固定睡眠几秒。
3. 重复启动复用当前服务，避免多个后台进程和端口冲突。
4. 正确提供字体、模型和媒体 MIME；视频支持 HEAD、Range、206 与 416，拖动进度能继续播放。
5. 服务只暴露演示资源，不允许路径遍历读取其他文件；退出控制不能被无关网页随意触发。
6. 给用户明确的退出入口，清理自己创建的服务；异常退出也不遗留孤儿进程。资源释放可重复调用，不因窗口关闭和程序退出同时发生而报错。
7. 本地启动过程不需要管理员权限或可见命令窗口；错误提示应可理解，并指向本地诊断记录。

只将允许再分发的运行时和素材装入包中，保留作者署名、许可及必要的变更说明。校验运行时来源、版本与官方摘要；不要从不明位置复制可执行文件。

## 模拟另一台电脑

针对最终压缩包测试，而不只是测试原工程目录：

1. 将包解压到新的、包含中文与空格的目录，核对文件清单和摘要。
2. 启动时使 PATH 不包含开发用运行时，工作目录设到别处；确认进程实际使用随包附带的文件。
3. 阻断外网但允许回环请求，浏览每个页面并触发主要步骤，检查模型、字体、视频与讲稿缺失情况。
4. 验证浏览器窗口确实打开、滚轮/按钮可用、全屏可用；不能只测到服务端口就宣称一键启动完成。
5. 验证重复启动、端口占用、正常退出和异常退出清理。只关闭测试创建的窗口和进程。
6. 对备用视频验证实际播放、暂停和跳转。流媒体页面可能持续请求数据，使用媒体就绪状态验证，不应一律等待 networkidle。

扫描交付清单，排除 `.env`、API 密钥、私人配置、无关照片、生成缓存、开发依赖和绝对本机路径。说明测试覆盖了哪些环境；模拟检查不等于已在所有目标电脑上验证。

交付回复通常只需：压缩包链接、支持平台、“完整解压后双击哪个文件”、实际检查结果，以及确实影响使用的限制。
