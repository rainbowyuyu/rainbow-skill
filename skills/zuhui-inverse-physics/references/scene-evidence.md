# 场景与证据契约

## 每页的单一数据入口

推荐每页维护：章节、标题、结论、副标题、三项以内的屏幕要点、公式、场景类型、讲解步骤、证据类型、来源、单位、时长、口语讲稿、现场操作提示。若图例与场景颜色不同，应显式配置颜色，不能按文字顺序随意着色。

## 选场景的判断

| 解释目标 | 合适的动态三维场景 | 必须声明的边界 |
| --- | --- | --- |
| 文献关系 | 方法路线与问题节点，逐步突出输入/输出 | 关系图是综述组织，不是性能结果 |
| 后验多解 | 参数空间地形、可行带与候选点 | 玩具参数空间不是实体或论文输出 |
| PDE / PINN | 响应场、采样点、留出点与残差 | 示意残差不能伪装成实际优化历史 |
| 分布载荷 | 固定端梁/板、两向位移与带符号力箭头 | 坐标、单位、重力扣除、形变放大、几何简化 |
| 参数化 | 空间基函数与系数时间曲线逐步叠加 | 深度是通道还是展向；统一幅值比例 |
| 可辨识性 | 实际奇异谱和阈值，多解的载荷/观测对照 | 白化、参数维度、阈值与噪声模型 |
| 扩散去噪 | 多通道信号从噪声到候选 | 保存轨迹或解释性插值要显式区分 |
| 真实结果 | 实际节点响应、区间、评分与原始图 | 单样本与聚合指标不能混用 |
| 未来拓展 | 改变方程的梁、板、接触体与观测接口 | 都是计划，不能暗示已验证通用性 |

## 数组与图表

- 实验数组转换使用结构化解析，保留小奇异值精度，说明抽样和显示截断。
- 原始系数的区间与空间力场的区间不同；线性组合的分位数不能简单由各系数分位数相加。
- 相同图上的方法用相同幅值和长度比例；力箭头方向由有符号分量计算，不随相机改变物理方向。
- 模态梁的表面仅作可视几何，不声称有真实层合壳、精细气动翼型或逆向重建精度。
- 非周期瞬态的末尾重播是片段回放，不应伪装成持续周期运动；说明可暂停单帧。

## 最小可核验交付

1. 演示页面中的结论与机器可读指标对应。
2. 讲稿解释符号与限定条件，没有新增成果。
3. 来源索引包含本地相对路径、论文 DOI/链接及核查层级。
4. 最终离线包无秘密、个人配置或开发依赖，保留再分发许可。
5. 逐页截图、像素变化和交互检查对应最终构建版本。
