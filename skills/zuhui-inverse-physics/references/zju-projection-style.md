# 浙江大学组会大字版

适用于当前用户要求沿用的高校组会参照。已有参照和校徽已持久保存，后续任务直接读取本地资产；不重复索要截图，也不把参照图上的研究标题、姓名、日期复制成新报告身份。

## 可直接复用的资产

相对本技能根目录：

| 资产 | 用途 |
| --- | --- |
| `assets/zju-group-meeting/reference-cover.png` | 用户提供的封面构图参照 |
| `assets/zju-group-meeting/reference-content.png` | 用户提供的正文层级与蓝底结论条参照 |
| `assets/zju-group-meeting/reference-emblem.png` | 用户提供的校徽形状参照 |
| `assets/zju-group-meeting/zju-emblem.svg` | 真实路径型矢量校徽，透明背景，22 个 path，无嵌入位图 |
| `assets/zju-group-meeting/cover-template.svg` | 可编辑 1920×1080 封面结构 |
| `assets/zju-group-meeting/content-template.svg` | 可编辑 1920×1080 正文结构 |
| `assets/zju-group-meeting/probability-grid.svg` | 已确认的概率网格视觉的独立矢量版本 |
| `assets/zju-group-meeting/theme.css` | 对应 HTML 投影样式，可按实际 DOM 适配 |
| `assets/zju-group-meeting/manifest.json` | 原图来源、校徽来源、处理方式与 SHA-256 |

SVG 模板只带通用文字。`scripts/build_reference_assets.py` 可在本地重新生成三个 SVG，使用标准库，不调用网络；它保留已有校徽及其来源。校徽是机构标志，来源页将其标为非自由校徽，不将其写成 MIT 素材或无限制图库资源。新报告的标志应符合用户指定机构。

## 版式

- 固定 1920×1080 整页等比缩放，不独立拉伸文字、图表或校徽。
- 封面：白底；左上深蓝系列标题；右上矢量校徽；蓝紫向白淡出的横线；中部整宽蓝色主题带；白色加粗大标题；下方黑色加粗作者/导师和日期。允许在主题带右侧保留动态概率网格，不增加小字副标题。
- 正文：左上深蓝章节标题、右上当页页码，校徽可与页码并排；顶部蓝紫淡出横线；黑色粗体的一句核心判断可配空心方块；主体由一张大图承担；底部整宽蓝色结论条用白色粗体，关键词用黄色。
- 参考字号：章节 60–66，核心判断 46–52，短要点 36–42，公式 32–38，结论 46–52。图内说明和轴标按最终显示尺寸至少约 28；数学上下标保留正常排版，不能把整个公式缩成脚注。
- 一页一条主信息。删除重复的章名副标题、指标释义段、来源脚注和“核心理解”等空标签；来源、限定条件、完整口述通过图标面板打开。把必要证据类型纳入标题，如“真实生成：机器评分”“合成基准”，不把合成曲线包装成实测结果。
- 无公式的页面让主视觉居中放大，不留下空白侧栏。正文不要同时重复“标题、导语、正文、解释、结论”五遍同一信息。

推荐颜色：章节 `#080080`，封面主题带 `#076fb6`，结论带 `#2877b6`，关键字 `#fff200`。主题色复用不改变图表中原有方法/通道颜色的含义。

## 动态与清晰度

维持手动翻页、语义步骤、暂停/定位、相机旋转缩放及状态保存。动效展示路径、概率流或已有轨迹，不用无意义的抖动。Canvas 按实际显示尺寸提供足够像素密度；SVG 校徽和模板保留矢量路径，不能把 PNG 包在 SVG 标签里冒充矢量。

1600×900 逻辑画布可等比采用：标题 44、重点 28–34、图例与控件 22–24，字重 800–900。正文不额外显示小章名和重复导语；一条结论放蓝底白字条。图表 Canvas 文字也要同步放大，单位不能压住标题，数学组合字符要检查实际字体渲染。技术细节通过讲稿和文件面板展开。

受力热图必须明确量纲：截面弯矩、位移和应力不可混称。分通道场采用同一已验证算子，先检查带符号状态和内力的叠加，再计算合量；合量颜色不可直接相加。固定色标并标清非线性映射刻度，形变倍率不能改变物理读数或颜色。等效支撑不能伪装成单缆张力，环境水面不能伪装成 CFD。采样动画的步数与结构的物理时间独立；关闭反馈对照不沿用旧后验为新预测。

放大字体后检查所有图例、边界和控件，必要时缩短措辞或重排，而不是退回小字。校徽顶部与右侧留安全边距。用封面、公式/动态复杂页、数据结果页三种截图对照参照；最后检查完整离线包和每个语义步骤。
