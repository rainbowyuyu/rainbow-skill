# 物理逆问题组会

本技能是 `zuhui` 的领域子版本。用户同时提供原版技能时沿用其交付与现场演示约定；本文件也可独立用于科学组会，不要求用户重复调用原版。

## 已保存的视觉参照

制作高校组会展示时，默认采用已保存的[大字版参照](references/zju-projection-style.md)。参照图、浙江大学路径型 SVG 校徽、可编辑封面/正文 SVG、概率网格 SVG 和 HTML 样式位于 [assets/zju-group-meeting](assets/zju-group-meeting/manifest.json)。先读取并复用这些本地素材；资产可用时无需让用户再次展示参照图或重新上传校徽。用户另指定机构或风格时以新要求为准。

投影页优先保留章节标题、一句核心判断、必要公式/图例和蓝底结论条。采用黑色/深蓝粗体大字，不铺陈小字号正文、来源文件名、技术说明或重复副标题。详细条件、完整文献和推导放在可打开的讲稿/来源中；会改变结论解释的条件，用大字写入图例或标题，例如“合成对照”“机器评分”，不能仅靠隐藏说明纠正误导的标题。

已有封面动态网格等获用户认可的视觉应保留；几何与公式资产可复用，研究者姓名、导师、日期和课题数据每次从当前请求填写。非物理研究也可沿用此版式与证据约定，仅应用与该研究有关的领域规则，不强行加入风机、PINN 或扩散反演内容。

## 内容顺序

根据用户指定时长制作四个章节：**已有研究与进展 → 方法入门与反推过程 → 技术与实际证据 → 边界、普适性与拓展**。在进入复杂结果前，用一页简洁说明扩散模型和 PINN 的定义、输入、输出及分工。25–30 分钟按信息密度控制页数，优先合并重复的算法介绍、回放和指标页，不为凑页数重复整机模型。

文献先明确输入、未知量、约束、真值类型、评价场景和未解决之处，再说明本研究的位置。逐篇区分“书目核实”“读过全文”“代码许可核实”“官方基准已运行”。不同任务或不同观测条件的论文数字不能直接排行榜式比较。

## 物理与证据

- 源研究只读，将必要数组、图表复制到独立演示目录并记录相对来源及校验和。
- 每页标明实测、仿真、原理示意或未来假设。未保存的去噪中间过程、优化路径可以动画解释，但不能标为实际模型运行轨迹。
- 先定义坐标、单位、初始/边界、重力处理、未知量与已知结构。分清外载、支撑反力、惯性项及外载力矩。
- 用正向映射和可辨识性说明“解释了观测”与“识别了真值”的差别。正向求解器一致不能替代反演真值或实物核验。
- 公平比较使用相同观测、缺失掩码和留出条件。均值修正不自动获得校准后验；概率区间同时报告覆盖和宽度。
- 把失败与适用范围放在实际结果页，不藏在末尾。样本规模、结构和训练时长等潜在原因在消融前仍是猜测。

## 三维讲解与现场状态

读 [场景与证据契约](references/scene-evidence.md)，按每页的问题选择有意义的场景。先做一张复杂代表页，用截图确认正文、场景比例、相机和单位，再扩展其余页面。

实体空间、时间信号空间、后验参数空间必须有可辨识轴标，不能把三维曲线包装成实体几何。几何简化、变形放大、力箭头归一化和显示抽样均需说明。

页面、讲解步骤、播放时间和相机独立保存；观众停留时不自动换页。切换步骤应改变场景含义。提供暂停、定位、轨道旋转、缩放、复位、目录、讲稿和来源入口，操作说明放在工具提示或附带说明里。

对于完整风机或其他多物理系统，主场景可按气动力、波浪水动、海流、系泊、土动力、结构和损伤分层。每层都要有明确颜色、作用位置、箭头方向、坐标和证据状态；点击某层只改变该层的高亮与解释，不重置相机、动画时间或页面。全量视图应保留各通道同时存在时的耦合关系。

对于需要探索风电场布局的展示，允许建立独立的**可编辑布局实验台**：机组数、X/Y 位置、偏航角、来流速度/方向、湍流强度和观测掩码都可以改变，拖拽、增删和导入导出必须实际改变计算输入。预烘焙尾流核、快速代理和完整求解器要分开标注；预烘焙插值结果不能冒充新运行的 FAST.Farm、CFD 或扩散模型。布局范围、最小机间距、来流/偏航/湍流边界、切入和额定区间、远场外推必须显示或在来源页说明。快速代理应在后台 Worker 计算，避免拖拽阻塞页面；应提供完整 FLORIS/FAST.Farm 复算入口。

布局反推要明确观测、未知量、真值和动力学来源。可变机数模型不应把固定三机网络硬套到新机组数；可先用共享节点/边编码的线性基线或图先验做原型，再以完整布局为单位划分训练/验证/测试。缺测时应展示区间变宽或先验主导；无观测时不能宣称识别出真实力。耦合矩阵的方向、单位和含义需清楚标注，上游/下游关系不能只用装饰性连线表示。

整机主模型应保持结构主体始终可见；选择某一耦合层时，将其他层降权或半透明，而不是把塔架、平台或叶片全部隐藏。桌面演示支持滚轮翻页、Shift/Ctrl 加滚轮缩放和全屏切换；这些操作不能改变当前证据状态或误触发通道按钮。

扩散反演页面应把稀疏响应、缺测与噪声、经典单解、后验样本、物理一致性引导、PINN 残差和独立求解器回放分成可讲解的步骤。后验样本用于表达多解与不确定性，不能被描述为真实实验轨迹。区间覆盖率、区间宽度、不可辨识方向和域外失败必须和点估计同时展示。

断裂页面必须区分刚度代理损伤、真实裂纹传播、位移解码和同步载荷真值。土动力页面必须区分线性接口、非线性 p-y/t-z/q-z 本构、循环退化、孔压和已验证的双向耦合；没有对应接口和收敛证据时，只能标为阻断或未来计划。

## 结果展示规范

### 少页数的统一系统叙事

用户要求整体耦合或世界模型方向时，主线可收拢为约 8 页：问题、相关工作、方法入门、独立耦合技术路线、统一交互总图、分协议证据、推广方向、答疑。旧实验保留在可点开的补充材料，返回时保存步骤、时间和相机；主线少页不意味着删除失败或合并不同协议的分数。

统一总图应让实体响应、载荷、后验区间与回放共用同一工况和物理时间。模态选择真正切换特征向量与模态坐标，并同时显示对应的广义力后验；部件模态与整机模态须区分，质量归一化的单位和重频基底不唯一须说明。非旋转梁不得配上旋转画面后声称完成旋转气弹分析。采样进度独立于物理时间，中间态只读已保存链。

技术路线需说明共同状态、接口力、方向性反馈、观测映射、预计算算子与有效域。保持输入的反馈开关属于干预前向对照，不自动成为新条件下的反演。预烘焙、解析条件扩散、神经扩散、高保真与实物分层报告；不能把同 ROM 的两种积分方式称为独立高保真求解器。世界模型应落到动作条件状态转移、反事实真值、长时稳定、跨布局泛化和校准验收，作为未来方向时显式标明。

物理逆问题组会优先展示“已有结果长什么样”。用户强调整体耦合时，优先在一页完整风机上同时展示风、浪、流、系泊、土体边界和结构，点击局部再展开相应结果；分通道曲线作为补充，避免重复多页同一模型。方法页要把主线讲成“现象 y → 载荷后验 f → 物理检查 → 独立回放”，让听众看到反推发生在哪里。每页只保留一个主结论，文字压缩到结论、证据状态和来源，动态三维场景负责解释作用点、坐标、方向与反馈路径。

扩散和 PINN 的入门页应有动态但简洁的过程图：扩散至少显示观测条件、加噪/去噪和多个候选载荷；PINN 至少显示观测误差、动力学残差和物理一致性检查。两者要明确分工，不能把 PINN 残差动画写成载荷真值证明。组会字体参考高校模板使用高字重、高对比标题和简短说明，放大字号后逐页检查脚注、图例和来源入口的安全区。

结果页可并列已有实验图、热力图、后验曲线和三维模型。已有图必须绑定源文件、单位、数据版本和证据类型；三维重建允许归一化和变形放大，但要在图例或讲稿中写明。相同颜色体系持续表示通道：气动、波浪水动、海流、系泊、土动力、结构和损伤，选中一个通道时只降低其他通道透明度，不隐藏主体或重置时间/视角。

不使用没有语义的数字步骤控件。步骤应使用“观测、经典解、后验、物理、回放”等标签；顶部页码只显示当前页。展示文案围绕“结果、比较、证据、边界”组织，不用“修复中”等开发状态词替代研究结论。

完整漂浮式风机的三维比例应包含塔架、机舱、叶片、中心柱/偏置柱、水下浮筒、连接构件、悬链系泊、锚点、海床和水线。避免把浮体画成薄圆盘或把桩直接连到浮体；若使用简化几何，标明其为解释视图。风、浪、流、系泊和土动力箭头应放在各自的作用高度，方向和支撑反力分开。

## 交付与验证

### 连续柔性与叙事闭环

- 弹性形变应来自保存的场、模态或明确的求解模型。仅有叶尖坐标时，沿展向的参考形状属于显示映射，不得升级为完整气弹有限元结果。可用公开截面参数补充独立梁示例，但与原反演协议及分数分开。
- 连续表面沿中心线更新，截面随切向旋转，更新法线；根部位移和转角符合约束。保留未变形轮廓、物理量单位和倍率；曲率、位移、应力各用准确名称。特写应放大主体，不用夸张未标注形变替代可见性。
- 25–30 分钟主线优先围绕一个研究问题展开：现象与价值、已有工作、方法、同一案例的反推与回放、独立证据、推广边界。重复的管线、文件目录和历史单例收进可点开的补充材料，返回时保留主线页的步骤、时间及视角。
- 完整讲稿包含每页口述、必要点击、建议时长、承上启下的过渡和预备答疑。现场主线结束后停留；补充材料不自动接着播放。正文少字不等于省略证据边界，详细条件放讲稿和文件入口。
- 扩散演示优先播放实际保存的采样中间态。说明采样步与物理时间的区别、可见样本数和坐标缩放；未保存的迭代不补造成真实轨迹。PINN 入门先聚焦一组可读对照，再用全集审计判断增益，避免大量曲线遮蔽结论。

### 数组到画面的可追溯规则

- 完整系统回放用同一工况、同一时轴的响应和载荷；坐标变换必须保持右手系，并分别处理转子局部力、惯性系水动力及系泊标量。
- 用保存的平台六自由度、叶尖位移或其他观测驱动模型时，说明几何形函数与海床压缩等显示近似。没有缆索内部张力场时，只能以导缆孔张力给整根缆着色，不生成虚假的沿缆分布。
- 真值、确定性结果、后验均值、样本与校准区间分别读取原数组。不得把均值基线当扩散、用区间内插线当独立后验样本，或把不同版本的汇总分数附到旧代表曲线上。
- PINN 的单例改善与全集表现分开呈现；较低物理残差不等价于较低载荷真值误差。均值校正后不可自动沿用此前的覆盖率声明。
- 实物 DIC 缺少可靠时间戳时按采集索引回放；二维位移不能表述为三维实测。刚度代理不等于裂纹传播。
- 有限元单元拓扑必须核实。四节点四面体不能按四边形绘制，应提取边界三角面并检查朝向；应力单位未确定时明确标注源单位。
- 通道聚焦不改变动画时间或视角，不冒充重新计算。全屏对整个 16:9 画布等比缩放；实际验证按钮引起像素及数据面板变化，并检查直接数据链接。

交付现场入口、逐页口语讲稿、分镜/证据索引，以及请求的离线产物。静态 PDF 只能标为备份，不能声称保留三维交互。离线版用最终产物在禁网、中文/空格新目录下验证，避免依赖原工程盘符或运行时请求。

用 Playwright 检查所有页面与步骤、桌面/投影/移动尺寸、真实 canvas 像素、动画变化、相机操作、暂停重入、快速翻页和结尾停留。全篇代表帧做缩略图核查；颜色、图例、坐标、公式与源数组一致。记录实际浏览器、尺寸、性能取样和未覆盖范围。

可编辑布局页额外检查：数值编辑、拖拽、增机/减机、偏航和风向变化、缺测区间、耦合矩阵点击、撤销、导入/导出、最小间距拒绝、24 台上限、离线 Worker、预设与完整求解器复算链接，以及修改布局后相机/时间是否保持。保留代理失败案例和边界附近的求解器对照，不能只保留通过样本。

本技能不预置任何研究者身份、设备地址、课题数值或账号信息。创建演示不自动授权训练、上传、发布或外部联系。

## 静态缩略图目录

### 旋转与方向联合演示检查

- 运行风机的角度必须来自运行点积分与计算转速状态；驻停协议保留独立入口，不能仅给驻停数组添加转动。
- “场聚焦”和“输入开关”分开：前者保留物理状态，后者必须切换实际求解输入、对应观测与条件后验。明确开关是否也取消均值，不能残留隐藏的平均外载。
- 风、浪、流、地震方向使用明确的坐标和“朝向 / 来向”定义。地理到三维坐标变换保持右手系，入射波面与惯性力相位一起核验。
- 漂浮式系统的地震通过锚基与土体进入；单桩另用对应基底约束。逐缆接口反作用、土体恢复力与锚点惯性分开，不用一个箭头冒充三者。
- 代表帧检查导缆孔、浮体和水线是否重合；全部输入组合检查张力、干舷、转速和模型小变形范围。流线绕行不是CFD，缆形不等于沿缆应力。
- 有限已知时间基、已知方向的低误差不能替代宽频分布载荷或未知方向验收。解析高斯扩散、训练的神经扩散与PINN审计分别标明。
- 主场景优先三个步骤（响应、反推、回放）与两个选择器（工况、场）。其他物理输入放折叠面板，所有可见控件必须引起可核验的状态或结果变化。

现场演示的页面目录默认采用可点击的静态缩略图网格，每页显示实际页面画面、短标题与页码，区分主线和补充，并高亮当前页。缩略图由最终页面在代表性步骤与确定的暂停时刻渲染，保存为本地 asset；不使用无关配图或多个持续运行的三维画布。打开目录不重置当前页的时间、参数或相机；关闭后继续原状态，点击卡片才跳转。长目录可以滚动，打开时让当前页可见，键盘焦点与关闭入口始终可达。

标题、页序、数据或图形变更后重新生成对应缩略图，并与最终离线包或 EXE 一起交付。检查所有缩略图加载、图文与页码对应、补充页跳转、暂停状态保持和离线可用；不得只测试目录按钮能否打开。讲稿按同一页序生成，包含口述、公式的通俗解释、操作时机和页间过渡。

用户要求用最少内容讲清时，优先用一个贯穿例子连接问题、状态、过程、结局与检验；主线每页口述两至四句，再配一次有解释作用的操作。公式用一行白话建立与画面的对应，推导和详细结果保留在补充页或折叠讲稿中。动画中的坐标、数字、滑块与账本必须来自同一时刻和同一模型；教学分位点的连续移动不能冒充随机样本路径。时长随内容决定，不固定套用某个页数。
