先检查实际可用的生图工具；适用的 imagegen 技能可用时按其工具规则执行。需要新栅格图就实际生图，不能把文字排版程序称作已生成场景。已授权的 API 服务可继续使用，例如本项目的百炼北京地域；本技能本身不提供授权。

没有可用工具或已授权替代服务时，先完成文案、构图、提示词，再说明所缺能力。当前会话授权持续生效，不重复询问；新任务不能自动套历史预算。模型、尺寸、地区、价格可能变化，付费前核实官方文档：

- `https://help.aliyun.com/zh/model-studio/qwen-image-api`

## 提交闭环

1. 确认用途、比例、留白、参考图角色和使用权。按目标比例生成，不支持精确尺寸时用同宽高比较大图再缩小，禁止拉伸。
2. 每种构图通常先一个候选，再针对实际缺陷迭代。提交前预留预计最高费用，在途和可能计费失败任务均纳入上限。
3. 保存无凭据参数、模型、地区、种子、任务／请求 ID、状态与时间；没有返回的字段不编造。
4. 未知提交状态先查原任务／结果，不直接重提；异步用 ID 查询。明确失败后才在剩余额度内重试，限流退避，禁止无限重试。
5. 成功后立即保存原始结果，检查主体和留白再排字；改标题不重生底图。
6. 留下选中／弃用原因。预算预留与费用预估不是结算账单。

中文、rainbow鱼、Logo、术语与数值后期精确排版；生成负责物件、材质、空间。查所有留白与边缘，发现乱码先修，不能假称无字。编辑时区分待编辑目标、风格参考、保留主体和品牌资产，明确不变项。

概念封面不能伪造论文、产品界面、模型输出或认证标记。确需真实论文或测量结果时合成原件。优先局部修主要缺陷，不随意重做已确认区域。

## 只换背景时保护既有主角

当用户要求换背景但保留位置，优先沿用已交付的主角像素。若整图重绘使眼睛、体态、大小或位置漂移，停止用更多提示词修整张图；将主角提取为与原底图同尺寸的RGBA，单独生成无角色的新背景，在原位合成。字体与Logo按 [结构规范](series-layout.md) 锁定，不让背景变化带动排版。

- 新背景的机制必须来自本章内容，例如生成章节的噪声／像素成像；避免在背景重新生成主角、陌生动物和重复面部。机制只能作为概念隐喻，不能冒充真实实验输出。
- 模型只用于估计Alpha；主角RGB保留原图，眼睛和主体内部完全不透明。背景可裁切适配比例，主体不能独立缩放／移动。
- 蒙版检查不只看缩图：查看耳尖、头顶、肩背、腹部和底部轮廓。浅色粒子可能粘在肩上，深毛可能被误切成台阶或缺口；要对照原图局部修复，不能靠加黑掩盖。
- 在最终背景上复核毛缘与光线，背景高光低于脸部，避免让像素纹理变成主角的披风。保留同尺寸Alpha、局部修复参数、原图哈希与重建脚本。
