# 图片品牌与可读性

查看以下图片后再设计，学习信息量、层级和空间连续性，不照搬颜色和构图：

- 品牌与文字尺度示例（外部或本机资源，未随公开包收录）：原图 Logo、留白、一个主要问题、短字幕。
- 模型叙述参考（外部或本机资源，未随公开包收录）：同一支架从实体、受力、材料分配到比较，文字服务当前动作。

Logo源为用户提供的 `C:/Users/USER/Desktop/logo/logo.png`。随附原图和去白底 PNG；保持长宽比例347:410，不裁掉边缘、不拉伸、不重新描摹。**图片右边必须放“rainbow鱼”，二者作为整体固定左上角**，不可用文字替代图片，不附小字口号。

位置以短边1080为基准，统一缩放 `s=min(宽,高)/1080`：左64s、上48s、Logo高90s、宽按原图比例计算（约76.17s）；间距20s；rainbow鱼字号44s、字重600或相近，字面垂直居中于Logo。文字与图形之间保留清晰间隔，Logo轮廓不要贴字。

| 1920×1080 视频或封面 | 64 / 48 | 90 / 76 | 20 / 44 |

| 1440×1920 封面 | 85 / 64 | 120 / 102 | 27 / 59 |

小数到像素可四舍五入；关键字与主体从组合下方或右方另起，不与品牌相压。亮背景直接放透明图；暗背景用有余量的浅色承托，保持原始图形。文字颜色与本片对比协调，不规定全片配色。网页与文档采用同一组合及比例，响应式尺寸可缩放；视频和封面严格按画布短边规则。

重要字少而大：一个问题通常4—10字，一个数值带一个短标签。1080p关键字68—100px、字幕44—52px、必要标签36px以上。图表本身放大，不把完整软件截图缩成卡片；去掉不参与讲解的控件、小刻度和重复信息。必要参数完整保存到制作说明，不在角落堆小字。

允许自由选择主题配色：例如生活物件可用自然木色，光学可用深色背景，生物可用柔和明亮色。光线、材质和对比要能看清当前物理现象。参考图不构成固定调色板，也不要求全片“左标题右物体”。

质量检查：整帧、640px缩图和转场各看一次。Logo贯穿但不反复弹出；标题、模型、字幕互不遮挡；数据比较保持相同镜头比例；任何必须阅读的信息都不能依赖放大屏幕。素材制作工具名称无需出现在画面中。
