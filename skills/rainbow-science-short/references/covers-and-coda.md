# 四比例封面与片尾来源

## 封面交付

默认同时交付以下四个独立构图的 JPG，文件名带比例。不是把横版连同文字裁成竖版。

| 比例 | 像素 | 用途布局起点 |
|---|---|---|
| 16:9 | 1920×1080 | 横向主体与短标题 |
| 3:4 | 1440×1920 | 上方悬念、下方主体 |
| 4:3 | 1920×1440 | 更宽裕的物体纵深 |
| 9:16 | 1080×1920 | 竖向阅读，孔洞等关键部位保留 |

JPG / RGB，嵌入 sRGB ICC，质量95、4:4:4采样。不要输出带透明背景或仅修改扩展名的文件。像素是尺寸规范，不规定每个平台都要求同样尺寸。导出后检查格式、比例、像素、Logo位置和缩图可读性，附清单。平台另有裁切或遮挡区时另做适配。

图片 Logo＋rainbow鱼 使用[品牌位置规范](visual-brand.md)，四种比例与视频保持同一短边尺度。标题一般1—2行，每行约4—7字；留出至少48个短边基准像素的边缘余量，主体与文字不相压。颜色和照片不固化；同一作品保持材质和光线关系。

为了兼顾专业观众和第一次接触主题的观众，科普封面默认保持极简：系列胶囊＋一个有趣的大标题＋一条融入背景的过程线。专业原理用实心体的虚线残影、消失粒子、荷载箭头和最终空心路径表达；本片的系列胶囊为“每天5分钟·拓扑优化”。不放公式、论文目录、参数清单或独立信息窗口，完整内容留给视频与发布文案。

拓扑优化的虚线残影应沿承力结构的几何走向，表达“原始实心体正在消失”；避免孤立的矩形选区感。横版标题放在左侧、主体放在右侧，竖版标题放上半部、主体放下半部，先保证手机缩图能读出系列名和主标题。

可编辑模板为 [cover-template.json](../assets/cover-template.json)，脚本为 [render_covers.py](../scripts/render_covers.py)。模板内题材、标题、配色只是本次示例，下次按内容更换；检查照片焦点、裁切和标题坐标。字体路径可配置。图片必须先整理为sRGB，PNG保留原始Logo透明度。

```powershell
python scripts/render_covers.py --image <本片主视觉.png> --config assets/cover-template.json --output <本片封面目录>
```

查看 四比例示例（外部或本机资源，未随公开包收录）；把模板数据复制进项目再改，不让下一部影片覆盖已交付影片的配置。长标题应改写，不能通过缩小字号挤进去。

## 最后约5秒：计算与论文陈列

默认在故事收束后留约5秒，呈现1—2个真正支撑本片的关键公式和1—2篇方法/证据论文。沿用全片的材质、光线、字体和图片Logo＋rainbow鱼。镜头从正文主体自然接到公式/论文，配乐有自然尾音，默认不再加一段旁白争抢阅读。

**形式不统一**：可以是模型旁的公式、工作台上的真实论文、线条关系、留白排版或有明确来源的论文局部；每片根据叙事选择。参考 本片片尾（外部或本机资源，未随公开包收录） 是密度与信息量示例，不是固定版式。不把5秒做成密集参考文献目录。

先核对公式与实际实现、变量定义、单位和约束。画面展示精简式时，完整目标/约束及变量说明保存到交付文档。不能把柔度、强度、承载能力混写。屏幕使用大公式和短论文名＋作者年份；完整题名、作者、期刊、年份、DOI/网址放制作说明。检索验证论文确实存在且支持当前方法，不编造封面、页码或可访问全文的说法。

展示时间按最终导出计量；淡入控制在约0.5—0.7秒内，其余时间保持稳定可读。主要字不小于36px（1080p），引用作者信息约34—40px，不用微型DOI塞满角落。检查第一帧、中帧、最后一帧，字幕不能覆盖公式；全文解码通过后才清旧版。

### 论文页叠放与收束动效

当本片引用多篇论文时，可以把它们处理成同一张工作台上的真实纸页，而不是并排缩成一排卡片。默认使用两到三张纸页：主论文在后，补充论文以小角度错位叠放，页边露出足够的标题区域；每张纸页都要保留可核验的标题、作者、年份和来源标识。纸页可以带轻微旋转、阴影和透明度变化，但不能用旋转遮挡关键文字，也不能把论文页伪装成原始实验数据。

动效按“主文献落下 → 补充页滑入 → 公式覆盖到纸面 → 镜头停住”完成，单页移动距离小于画面短边的 8%，避免像 PPT 翻页。纸页上的文字遵守 1080p 至少 34px 的可读下限；完整 DOI、URL 和访问日期放制作说明，画面只留短 DOI 或期刊名。若没有可公开读取的原始页面，必须标明“元数据卡片”或“根据公开书目信息排版”，不能称为真实论文页。
