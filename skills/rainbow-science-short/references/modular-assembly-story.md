# 统一模型与可拆分叙事

用于建筑、机构或产品拆装科普，不把六段结构强加给所有选题。先读取用户给出的截图和可访问视频；截图流程、实际视频旁白与自己的推断要分别记录。不能将拿到分享页当成看过参考影片。

## 从物体的问题推进

一种可选组织方式是：整体吸引 → 生活问题 → 拆开局部 → 细节机理 → 应用与限制 → 回到整体与来源。每段保存逐句口播、真实音频时长、起止帧、使用零件和镜头意图。保留统一模型与材质；模块化是为了局部重做，不是强行使用章节卡或生硬转场。

用户要求片头拆合时，可在标题出现的6—10秒内完成“整物 → 分层展开 → 合回”的短演示，随后进入日常问题。拆解要能看清结构，并给重组留出停顿；避免开场长时间只剩标题或无关粒子。

## 几何与运动

图生模型先检查是否为整体网格。外观参考和机械可装配模型可以分开保留：无法准确拆分时，在 Blender 重建教学零件，明确来源。不能把切开的外壳当成正确的内部结构。

零件采用稳定名称、局部坐标和明确父级，记录装配基准与退出方向。榫槽必须具有真实空腔；“可以插入”不能自动等于“不能拔出”。用剖切和局部放大解释约束，而不是让实体互相穿透。历史建筑的简化模型需区别于复原和施工方案。

屋顶、外壳等遮住关键接头时，优先抬开相关层、绕到开口侧或做可理解的剖切。转场沿主体、受力点或零件动作交接。力箭头跟随接触点和局部运动，重力方向保持世界竖直；维修示意先承托、再卸载、再取件。

## 视觉与交付检查

抽查装配前、中、后、最大拆解以及镜头交接帧；检验孔洞、阴影、遮挡、标题安全区与箭头位置。模型网页在最大拆解位置也要完整入镜，标题和控件不能挡住观察点。网页交互检查与成片检查分开记录。

保留原生 Blender 工程、语义分组 GLB、统一时间线和独立模块稿。可提供按帧导出的分段脚本，避免默认复制整套影片占用空间。整片导出后再次检查音画长度和片尾：场景区间使用左闭右开且不重叠；若需要恰好5秒的来源展示，30fps对应150帧，前一场景应在同一帧结束。

真实论文页可叠放，但标题、作者年份和解释公式需有明确主次。长英文题目保留在原页与交付说明，画面可配准确的中文概括。公式源保留 LaTeX；基础机理公式不冒充整物的性能计算。
