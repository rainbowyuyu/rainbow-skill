# 按需使用远程 GPU

用户允许本系列在必要时借用其远程 GPU 计算。先根据任务规模和已安装本地工具判断收益；本地计算足够时，直接本地完成，不为增加工具署名连接远程主机。

## 已提供的端点

- 用户原始写法：`192.0.2.10@fusion`。
- 按 SSH 的 `用户@主机` 格式，较可能的含义为 `fusion@192.0.2.10`。这是待核实的解释，尚未验证账号、连通性、主机身份、GPU或可用环境；不能记录成已成功连接。
- 只有确需计算时才检查本地 SSH 配置、端点与服务器身份，再执行小规模资源探测。用户已经授权本系列按需使用；不为已有授权重复索取确认。若实际账号或主机与上述解释不符，先核实再运行，勿盲目尝试一组用户名。
- 密码或其他凭据通过用户授权的安全存储、受控环境变量或交互输入提供。不要把值写入本文件、源码、日志、命令行参数、资产清单或交付包，也不要在响应中回显。环境变量名称与获取方式可以记录，值不记录。

## 计算范围与可复现证据

远程运行只使用本片专用工作目录，按当前主机已有的调度或资源管理方式提交。先查看可用资源，避免占用他人正在使用的 GPU；不终止、修改或清理他人作业，不安装全局依赖或改系统配置。上传仅包含本次求解所需输入和脚本。

记录任务目录、任务标识、GPU型号、驱动和CUDA/求解器版本、关键参数、边界条件、随机种子、输入与输出SHA-256、开始结束状态及必要的数值检查。远程回传文件后核对哈希，保留可在本地复现的入口。连接或状态读取超时不等于任务失败；先核实已有作业状态，避免重复提交。

远程清理只针对已成功回传并验收的本片临时产物，遵守[依赖保护与清理](cleanup.md)。结束自己启动的任务和释放自己的GPU资源，不能清理共享缓存或其他项目。

本次地铁安全线视频使用本地CPU完成二维简化流场，并使用本地RTX完成个人音色合成，不需要远程GPU。这个选择是本次任务记录，不限制后续更大规模计算。

本机浏览器渲染先读取实际 WebGL renderer；机器有独显不代表浏览器正在使用它。本次默认 ANGLE 选到了集成显卡，针对本片独立浏览器运行目录设置高性能设备偏好后，已验证使用 RTX 5060，双并发测试通过。若采用这种临时设置，交付后删除该任务专属设备偏好与浏览器副本，不修改其它应用的设置。
