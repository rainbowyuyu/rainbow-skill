# 人体连续尺度与医学可视化

适用于人体解剖、跨尺度机制与家庭测量镜头。保留本片的品牌、字体、音色和艺术方向；以下约束解决尺度错觉、空间断裂、解剖路线误导与跨句动画重置。用户本轮选定的内容和时长优先，五分钟是默认值，不是压缩讲解或加速声音的理由。

## 一个人体，一条因果链

- 以同一人体图谱为全片的空间基础。先确认长度单位、坐标轴、左右侧、器官边界与源模型的变换；统一转换到实际长度单位后，固定器官之间的相对位置。
- 靠镜头接近、剖切和透明关系让局部占据画面。禁止把胰岛、细胞、血管或蛋白质偷偷放大到器官尺度，也不能把另一个放大的展示台当作原位置的连续近景。为可见性确需夸大的结构，明确其示意性质与倍率，不称其按真实比例呈现。
- 同一主题可以从进食、能量储存、激素信号、血脂运输、血管阻力和肾脏调节相互连接，连接点要有生理依据。转场前交代“为什么接下来要看这里”，让上一镜的物质、血流或调节问题带到下一镜；不要把三个主题做成独立课程后拼接。
- 先说可观察现象，再给必要术语。面向普通观众和老年人，用短句解释每次可见变化；学术准确性由机制、限定条件和来源承担，不靠术语密度。删掉反复的总结、空设问、“不是……而是……”式套话与制作口吻。
- 用户未要求或明确去掉临床效果、获益时，不添加疗效排行榜、减重数字、风险降低图或推销式结论。机制、研究过程与生活管理信息按本片实际范围选择；不把群体研究结论说成个人治疗承诺。

## 尺寸证据与局部模型

在项目记录中保留每个关键对象的来源、实际单位、尺寸范围、所选代表值、父结构、坐标锚点与表现方式。优先记录会改变观众理解的对象，不为所有装饰顶点制造账本。

| 对象来源 | 可以怎样表述 | 不可混淆的边界 |
| --- | --- | --- |
| 人体图谱、公开器官网格 | 对应图谱的解剖参考模型 | 不等于本观众或某位患者的影像 |
| 依据文献尺寸制作的胰岛、细胞、血管壁、肾单位 | 具有代表尺寸的教学模型 | 不能称为该图谱实测的微观组织 |
| 有结构编号的蛋白质、分子 | 对应结构来源及其适用状态 | 示意对接不自动成为分子动力学结果 |
| 人工搭建的调节动画、粒子流或管径变化 | 生理机制示意或预计算结果 | 未运行求解器就不能声称真实流体、应力或患者预测 |

微观模型固定在所属器官或血管的局部锚点，以真实的代表尺寸建立；毫米、微米、纳米之间的单位换算集中处理。宏观到微观的分辨率缺口，用逐级组织背景、局部剖面与空间锚点补足，而不是突然出现一颗巨大的细胞。若没有原图谱可追溯的显微结构，在交付说明和适当的短标记中说明是局部教学放大观察。

每个解剖镜头持续显示可读的比例尺，包括拉远、推进、切换目标与坐姿测量。比例尺从当前摄影机投影、当前观察平面及世界单位计算，标注 m、cm、mm、μm 或 nm；说明它对应焦点平面，不暗示整幅透视图处处同一比例。单位切换时保持屏幕长度与数值一致，不用预先写死的“1 mm”装饰线。允许按镜头换位置，但不能被标签、字幕、裁切或边缘安全区遮掉。

## 让观众看见“它就在这里”

一次深入镜头通常包含定位、接近、母层让开、局部观察；按内容自由安排时长，不强制统一转场样式。

1. 先让目标在母器官中可辨认。用克制的轮廓、光照、局部高亮或短引线保留位置关系，目标锚点绑定世界坐标与实际模型变换。
2. 摄影机沿连续路线接近同一个锚点，逐步调整视角。固定结构留在原位；远处组织、器官边缘或相邻组织提供尺度变化的参照。
3. 前层组织较慢地渐透明或被局部剖切，子结构在其后逐步可见。母层不要在推进刚开始就消失，子结构也不要等到镜头到达后突然生成；相邻层有可辨认的重叠时间，之后再让前层退场。
4. 进入解释距离后减速观察。揭示受体、细胞等结构时，留出认形和听懂因果的时间；持续微移不等于不断大幅绕转。返回整体时反向恢复上下文，再移动到下一器官。

父层透明度应沿同一镜距或机制进度连续变化，不能因下一句切换视图名称而恢复不透明。进场定位环只服务于那一次进入，回拉观察时不能重新盖住结构标签；标签选择依据实际可见结构及其权重，不能仅用一个镜距阈值推断当前对象。对数量级跨度中的空白，先检查相邻层是否交接过早；确需增加中间尺度参照时，使用有生理依据、固定尺寸和位置的结构，并明确其参照用途。

跨数量级推进优先在距离的对数域设计速度，避免线性位移到微观末段骤然冲刺。连续位置并不自动代表观感平滑：检查每秒跨越的数量级、速度峰值、加减速、焦点漂移、朝向与视角变化是否共同造成突然的视觉放大。不要靠拉大 FOV 掩盖过快的推进，也不要边猛拉镜头边反向缩放主体。参数按实际视频阅读速度调节，不把单个项目的速度阈值当成所有题材的统一常数。

透明关系服务于正在讲的机制。讲神经调节时，突出必要神经与靶器官；讲血流时，突出有关血管及流向；讲细胞时，外层组织留下足够定位线索后退到背景。避免所有器官一起半透明形成重影。透明排序、深度写入、近裁剪面、背面与剖切口都要检查，不能只改 opacity 后假定正确。

同色细胞等大量实例在不透明时可批量绘制；进入透明过渡时，要检查是否只能按整批对象排序。若关闭深度写入导致整层突然前置，应使用适合该场景的单体排序或透明渲染方式，保留原实例矩阵和尺寸，并复查推进、回拉及切换边界。不能用一个通用 opacity 阈值认定所有组织都能平滑交接。标注还需等对应结构可见、姿势变换与锚点一致后渐显，避免引线穿过遮挡物或落在未复位的人体上。

## 血管、神经与机制边界

- 保留每条重要路线的来源类别：图谱自带、从网格中心线提取、依据解剖文献约束，或教学简化。由稀疏锚点插值的曲线不能称为患者真实血管或精确追踪神经。检查起点、终点、分支、左右侧及其与器官的空间关系。
- 主动脉、小动脉、毛细血管与静脉具有不同尺度和功能，不为套用一个漂亮镜头互换名称。局部管段要关联到所讲的位置，血流方向与结构用途一致。
- 区分交感神经通路和迷走神经的副交感通路，不用同一根管线换色代表所有自主调节。肾脏交感示意不能画成迷走神经直接取代其路线；复杂分支可简化，但说明简化边界。
- 激素进入组织间隙、毛细血管的释放方向要正确；例如肠道 L 细胞的 GLP-1 释放不应画入肠腔。肾单位滤液与血管内的红细胞分属不同空间，不能让红细胞沿滤液进入肾小管。
- 高盐、交感活动、肾素—血管紧张素—醛固酮系统之间有情境和反馈差异，不能统一画成“盐越多，循环 RAAS 必定越高”。LDL 胆固醇浓度也不能无条件当成 LDL 颗粒数。用本片的实际文献约束动画方向与旁白。

## 字体与跨句状态

片头、字幕、器官标注、实验室数字、比例尺和片尾共享一套字体配置。显式加载字体，检查中文、拉丁字母、数字、希腊字母与 μ 符号的实际回退；不能只看 CSS 字体名相同就认定视觉一致。字号保持清晰层级，重要名词与比例尺读得见，标签避开所指结构、主要运动方向和字幕安全区。

旁白句子是剪辑单位，不是机制状态的重置按钮。粒子沿程位置、受体结合、分泌、管径、压力或积累状态使用连续的机制时间或明确事件起点驱动；换句后保留已发生的过程。需要回放或比较时给观众可理解的触发，不让同一物质每句重新从起点出生。离线非顺序定位与连续播放应得到同一帧状态。

## 家庭血压测量与最终复看

家庭测量继续使用同一人体皮肤和比例。坐姿变形保留上下臂长度与肩—肘—腕连接，不能换成玩具手臂或给单独手掌随意缩放。脚有支撑、背有依靠，上臂袖带中部接近心脏高度；前臂受桌面或软垫支撑，手腕放松。袖带沿实际上臂轴线定位，宽度、包覆和管路合理，不能悬空、穿皮或接错手臂。演示读数明确是演示值，未测状态不捏造患者结果。

按以下证据检查，发现具体问题后修复并重看相关范围，不用大量重复截图替代观看：

- 每个跨尺度转场至少查看定位、母层开始让开、层间重叠、到达与稳定观察的实际渲染帧，并看完整连续短片；单张终点图不能证明过渡平滑。
- 重点检查器官到组织、组织到细胞、细胞到蛋白质的比例尺与锚点，核对实际几何包围盒、相机距离和尺寸记录。使用模型原坐标本身不能证明显微模型或神经路线准确。
- 抽查讲解跨句边界与非顺序跳帧，确认粒子、机制和透明关系不突变；检查移动镜头中标签遮挡、单位切换、字体回退和裁剪。
- 测量姿势至少看实际全景和臂部近景，确认上下臂连续、袖带贴合、软垫接触及监测屏在所需讲解期间可见；不要只凭骨骼锚点数值判定皮肤和支撑面相接。
- 记录看过的帧段、实测尺寸与仍属示意的部分。未完成整段观看、人工听审或求解验证时，不能把抽检、ASR 或示意动画称为已完成对应验证。
