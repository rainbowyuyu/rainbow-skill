# 公式与数学动画

本参考用于正式教学中的公式、矩阵和推导镜头。公式既要数学正确，也要让观众看见每个量在画面中做了什么。它不能只是把一行 TeX 放在左侧，也不能用 Unicode 近似、手写图片或生成模型重绘公式。

## 可复现的 LaTeX 资产链

优先使用本机真实 LaTeX 工具链：

```text
MiKTeX latex  →  dvisvgm --no-fonts  →  SVG glyph outlines  →  Remotion
```

源公式与颜色变体放在项目 `docs/<version>/latex-*.json`，编译脚本写入 `public/latex/<version>/`，同时保存编译日志、工具版本、源文本 SHA 和资产清单。`dvisvgm --no-fonts` 产出的 SVG 是矢量轮廓；不要在运行时用浏览器字体猜测公式，也不要把 PNG 截图当作最终数学资产。字体、宏包或编译器变化后必须重新编译并更新哈希。

首次使用或环境变更时先检查 `latex`、`dvisvgm` 的实际路径与版本；编译失败、缺字形、警告未解释或 SVG viewBox 异常时停止接入成片。编译验证至少包括：源文件成功结束、SVG 文件存在且非空、全部符号有轮廓、颜色变体几何一致、viewBox 与最终合成比例合理。把结果写入 `research/<version>/latex-validation.json`，不把“浏览器显示出来了”当成编译通过。

## 公式登记与数学审计

每个公式登记以下字段：`id`、LaTeX 源、显示文本与朗读文本、语义解释、行／列约定、每个矩阵维度、输入样例、预期中间值和结果、旁白句 ID、全局帧区间、SVG 哈希和来源。独立数学审计逐项核对：

- 点积、矩阵乘法和转置的方向；行向量／列向量约定不可在同一镜头中切换。
- QKV 投影的输入维度、权重形状和累加项；不要把投影图画成抽象的“魔法箭头”。
- 缩放因子 `\sqrt{d_k}`、mask 的 `-\infty` 语义、softmax 分母及概率行和。
- 加权 `V` 的每一项和四舍五入标记；示意数字与真实实验输出分开记录。
- LayerNorm 的归一化轴、均值／方差和 `\epsilon`；自然对数损失与类别／token 数量平滑。

审计文件应列出公式、维度检查、数值检查、编译状态和审阅者／脚本版本。公式的来源是论文或公开教材时，记录 URL、页码和哈希；自制教学数值明确写“示例计算”。

## 逐项动态演示

一个公式镜头按“现象 → 量 → 运算 → 结果 → 回到现象”组织：

1. 先让观众看到 token、向量、网格或曲线的变化，说明要解决的具体问题。
2. 显示一个量，沿同一坐标高亮它在公式中的对应项；不要同时亮起整条长公式。
3. 用共享路径或矩阵单元展示乘法、求和、缩放、归一化和加权，数值由登记的数据驱动。
4. 结果停留并回连到输出 token、注意力连线、概率柱或损失曲线；随后整组有意离场。

以 Q/K/V 为例，先用真实维度的投影矩阵展示六个输入贡献如何累加为两个输出，再进入 `QK^T`、缩放、mask、softmax 和加权 `V`。高亮移动使用连续插值，未来位置的 mask 保持清楚的零概率／不可见状态；不能用随机粒子、闪烁文字卡片替代计算过程。公式出现的时刻应写入 `docs/<version>/formula-navigation.md`，便于复查。

## 公式—旁白时序契约

正式音频先测出句子时长，再把每个公式阶段绑定到全局帧。每个阶段至少记录：`formulaStartFrame`、`termRevealFrames`、`resultCompleteFrame`、`spokenCueFrame`、`holdFrames`。硬性约束是：

```text
resultCompleteFrame <= spokenCueFrame - safetyMarginFrames
```

`safetyMarginFrames` 通常取 2–4 帧，复杂运算可更大。旁白说“二乘二是四”时，4 必须已稳定显示；旁白说“概率归一化”时，柱形和行和必须已经完成。若不满足，优先缩短／重排动画或改写句子并重合成，不把整段声音硬拖速。公式的稳定停留应覆盖读者理解时间，结果完成后不可因阶段取整再次从零播放。

## 防抖与实现约束

公式、中文说明和来源文本使用固定坐标、稳定 React key 和固定 viewBox；不要逐帧测量文本、改变数组排序、用 `floor` 触发整组重挂载或同时用全局帧推进 `Sequence` 与 `startFrom`。矩阵单元、连线、数值和公式共享同一局部坐标系，摄像机缩放只改变父层 transform。字幕换行在阶段开始前确定，不能随数值变化抖动。

所有动画由帧号、登记数据和确定性 easing 驱动。禁止 `Date.now()`、无种子随机和 CSS 实时计时。必要的中间状态是可解释的插值，不得在旁白中宣称为新实测结果。

## 合成后验证

编译成功后仍要在实际 1080p 合成帧中检查公式：至少抽查入场、每个项高亮、结果完成、旁白 cue、稳定停留和退出；再以正常速度看含前后文的短片。检查 SVG 清晰度、基线、上下标、mask、连线端点、字幕／来源遮挡和背景对比。静帧正确不等于动画连续，数学脚本通过不等于观众听懂。

将公式样本、数学审计、时序契约、最终成片 SHA 和修正记录一并写入 `research/<version>/`。若公式镜头因外部模型提供了部分代码，保留原始响应并注明由本工程完成适配和数值校正；不得把外部模型的未运行片段写成已验证证明。
