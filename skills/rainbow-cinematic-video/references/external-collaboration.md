# 外部模型协作与动画迭代

在用户请求使用 Opus 等模型协作，且现有调用配置可用时采用。能力按实际接口区分：代码模型可以编写 Remotion／SVG／Canvas／Three.js 动画；图像或视频模型负责生成媒体。不能把一段动画代码回复说成对方已直接生成并验收了成片。

## 分工与隔离

先给合作方独立组件或镜头任务，主代理维护全局时间线、正式音轨、素材 ID、实验数据和版本。多个代理不要同时编辑同一合成入口、账本或输出路径。使用各自的文件目录和明确集成点；未通过适配的组件不直接覆盖当前可用版。

调用用户配置前检查实际模型 ID、可用接口和响应类型；不要仅凭 UI 别名宣称调用到某个型号。凭据由运行环境读取，不进入提示词或日志。通信失败先定位鉴权、模型名、代理、请求格式或超时；有任务 ID 先查询原请求，不盲目重复付费调用，也不修改无关的全局设置。

## 给自包含的镜头委托

若用户要求“只给详细文本，不让对方读 skill”，把必要规范直接写进提示词，不附带读取技能的强制步骤。每次委托包含：

- 教学目标、相关的正式口播及逐句时间锚点；观众需要看到什么因果变化。
- 真实输入／输出样例、数据字段、单位和不可改写的实测值；声明生成媒体不能承担精确证据。
- 分辨率、fps、准确帧区间、组件 props、包版本、可用资产与允许依赖。
- 稳定对象、摄影机、颜色、文字和字幕安全区；上一镜出点与下一镜入点的共同对象和运动方向。
- 动作阶段：输入如何进入、运算如何发生、输出如何变化、何时停留、怎样离开。每个阶段应有可观察状态，而非只加粒子和文字卡片。
- 可运行代码的目标位置、导出接口、样帧／短预览入口；禁止真实时钟动画与渲染时随机求解。
- 需要重点避免的已发生问题，例如连线穿过主体、圈注坐标漂移、图片被遮挡、相位重置或文字大面积重叠。

提示词用具体的同一对象展开，不要求模型凭“高级、电影感”自行猜完整科学机制。允许其提出更清楚的空间表达，但输入输出、时间和实验含义保持可验证。

## 代码成果的验收循环

1. 先审代码接口、依赖、时钟和数据含义，再运行项目类型检查。
2. 在实际字体、背景、字幕和品牌层下渲染入场、稳定、转换、退出帧；再播放有前后文的局部片段。
3. 核对每句旁白与当前对象／结果。尤其检查曲线轴向、箭头端点、透视、遮挡、mask 与 SVG 坐标，不能只因组件能编译就算适配。
4. 下一轮反馈附具体帧或时间、现象、应保持的不变量，以及一个明确修复目标。例如“第 142 帧的回传光点离开曲线，改为共享同一 Bezier 求值”比“再丝滑一点”有效。
5. 再次渲染受影响区间及接缝，通过后集成。保存实际调用模型、提示词、回复、代码采用范围和验收结果，最终交付仍由主工程完整渲染。

外部协作是改进手段，不是免检来源。模型暂时不可用时继续完成独立的布局、数据、声音或已有组件修复，并如实说明哪些片段未调用对方。

## 部分响应与最终署名

外部服务可能返回部分代码、截断流或上游错误。保存原始响应和错误状态，标注哪些行／组件实际被采用；由本工程补齐的坐标、时序、数值和 LaTeX 适配应写成“外部模型部分生成 + Codex／本工程适配”，不写成 Claude／Opus 独立生成并验收整片。若视频桥接同时包含生成素材与程序匹配 whip-pan、补帧或遮罩，来源记录应逐段拆开，不能笼统称“全 AI 生成”。

整合外部组件前至少运行类型检查、LaTeX／数学审计、前后文短片和最终 1080p 样帧；外部模型没有运行日志或只给提示词时，不能当作技术证据或完成凭据。
