# 本地配音、字幕与声音

## 新配音先做表演编排

语气平淡、情绪单一或自然节奏不足时，先读 [逐句表演与个人音色](../../rainbow-motion-story/assets/style-lab/guides/expressive-voice.md) 及 `D:/projects/tts/EXPRESSIVE_NARRATION.md`。按提问、解释、对照、揭示、蓄势、收束选主语气，保持同一个人音色；每句一至两个重音，音乐窗口放在完整句源之后。实际音长决定镜头与字幕，不统一后期慢放或变调。

2026-10-31 起，新配音默认使用既有本地Qwen3-TTS-0.6B Base与本人参考；先读 [Qwen技能](../../rainbow-qwen-narration/SKILL.md) 和 `D:/projects/tts/QWEN_NARRATION.md`。Base的语气标签仅作编辑/听审意图，不虚构instruction或独立emotion/speed控制。原速完整语义段生成后，再按真实音长组织镜头与字幕。Fish停用，失败不静默换后端；Breeze、历史Qwen试音和已接受音轨保留。下文章节曲目与限制只属于原项目。

## 本地 TTS

新片入口为 `D:/projects/tts/breeze_voice.py`，管理器为 `breeze_manage.py`。本人参考仍在 TTS 工程内，通过 SSH 隧道发送到用户 H100 服务；不复制进通用 Skill。新工程的 score、raw 和成品保存到自己的目录，不直接运行绑定另一部影片输出路径的脚本。先 `plan` 检查导演谱，确认服务可用再 `render`；只改句序/停顿时用 `assemble` 离线重组。

1. 旁白分场景、分句，口语简洁，给观众看图的时间。
2. 区分显示文本与朗读文本。建立语境读音表；不把英文名字任意翻译为中文含义。用户要求英文读音的术语保留英文发音，用支持中英混合的同一声音和完整短句合成，字幕保留标准写法。
3. 用已验证的 TTS 客户端环境，分段串行生成自然语速音频。缓存身份包括正文、表演指令、实际模型 digest、参考 WAV/稿件、种子和输出参数；不要错误复用旧句。409 或断线先检查记录，不自动重发未知请求；需要新尝试时显式 redo，保留旧记录。
4. 先量真实时长，再安排停顿与镜头。默认不做后期变速；改语气或速度时使用已验证的生成指令并重做对应句，或修改句子和镜头时长。已有作品的局部技术校时另行核验，不用统一慢放代替表演。
5. 保存原始合成、清理版本和最终人声，逐句复听术语、停顿、字尾。

## 本系列重点读音与中英衔接

| 显示文本 | 朗读目标／检查重点 |
|---|---|
| AlphaGo | 读英文名字 Alpha Go；不读成“Alpha 围棋”，不改变字幕拼写 |
| AlphaGo Zero | 英文名字连贯，Zero 不突变成另一音色 |
| ReLU | 作为完整术语读，通常按 REE-loo；不拆成“re、L、U” |
| rainbow鱼 | 作者名；rainbow 的英文部分和“鱼”连成自然署名，不逐字母念、不过长停顿、不另插一段陌生声音 |
| CNN、DQN、RGB | 按缩写自然读；首次可先讲中文含义，再给缩写 |
| 行、列 | “三十二行”读 háng，“运行”读 xíng；不要全局把同一个字改为同一读音 |
| 卷积、池化、策略、概率、回传 | 重点检查技术词是否被错断词，声音是否与字幕一致 |

先合成含上下文的短句试听，避免只测孤立单词。中英文接缝不靠硬拼外部音色修复；优先整句重合成。确需同声源拼接，在自然停顿处剪接并轻柔交叉淡化，不能交叉吞掉爆破音／字头。允许配置发音提示或模型支持的语音标记，最终以实际听感为准，不把音标直接送入不支持的 TTS。

## 降噪与自然度

先分辨持续底噪、句首呼吸、TTS 毛刺、接缝咔哒和配乐掩蔽。保留 raw，对受影响部分做适度降噪、去直流／必要低切和短边缘淡化；不一律强门限剪静音。强降噪造成金属声、水声、齿音损伤时退回较轻处理或重新合成。

清理后与 raw 等响度 A/B 复听，特别检查英文尾辅音、轻声字尾、句首和拼接点。机器噪声指标下降不代表声音更自然。纯画面修复无需重新降噪或改变已有配音；新旁白的响度和音色需与上下段一致。

## 截断故障排查

同时检查：模型是否生成完整句子、token 上限、静音修剪、固定音频偏移、场景出点、总音频长度。音量阈值会误切轻声字尾，修剪后留约 0.25–0.35 秒余量；本片使用约 0.32 秒。末词结束后至少保留约 0.15 秒可用尾部，具体按听感调整。

若旁白“动画与实验中展开”等句尾被截断，不能只延长视频却仍播放已损坏音频。复听 raw 与处理后音频，定位在哪一层丢失，再针对该句重做。

## 字幕与对齐

用本地 Whisper 字词时间辅助对齐，目标明显偏差不超过约 150 ms。专有名词识别错误可校正，不直接把 ASR 当最终文字。比较预期句子与识别覆盖率，发现缺句先检查音频而不是强行改字幕。

字幕从正式旁白生成，段落区间不重叠、不超出音轨或时间线。通常一到两行，中文约 15–22 字／行按版面调整，避免人名和术语拆坏。语音校验的字符匹配高不代表发音正确，仍需听审。

## 配乐与混音

使用明确可用的纯音乐或项目内原创声轨，保留授权／创作来源。低频脉冲、轻微环境与持续声床可连接章节；本风格不加入章节撞击、whoosh 或提示铃声。生成视频自带声音默认不进最终混音。

**本系列当前配乐偏好：柔和、克制、连贯的科技电子器乐。** 第二章最新要求全片使用 **V17 的第二首 `Bleeping Demo`**，并用轻微节奏和层次变奏避免单调。不要把它混淆为 V16 的第二首 `Galactic Rap`；同一序号在不同版本指向不同曲目，先用该版本编排记录核实。优先保留已接受的人声清晰度和闪避关系，不因换配乐又改旁白或抬高母带。此前“更活泼”、六首拼盘、两首轮换均已由此反馈细化。其他章节可把这一柔和脉冲与空间感作为风格参考，具体曲目服从该片最新要求。

单曲变奏使用同一节拍时钟、乐句位置和连续相位：让原有织体温和改变密度、重音、频谱和空间层次，避免每段重新起奏、突然变速或重置鼓点。使用同源声轨变体交叠时先检查相关性；相干素材不可机械采用等功率叠加导致中心增益隆起，应采用总权重保持为一的平滑插值，必要时再校正响度。低频、旋律与节奏层来自同一已核实素材时保留相位和共同时间位置，不能把滤波出来的频带冒称独立分轨。节奏变化以轻微重音和稀疏变化为主，不用深幅度门控制造抽吸；自动闪避与变奏包络共同检查。单曲连续扩展不反复插入过门声效，段落变化在乐句中渐进展开。记录原曲许可、实际变奏方法与试听片段，不能把本地重编排称为生成 API 创作。

音乐负责托住好奇心与推理节奏。开场、教学、实验和片尾保持同一音色家族，只适当改变层次和密度；优先少量兼容曲目和较长乐句，不因每个小节切换曲风。不能只提高一个低频正弦长音的音量来代替合适编曲。作者、曲目页、许可、下载原件和选段方式都入台账；他人视频的音乐署名并不授予本片使用权。

**同时保证可听见与可听懂。** 先测独立干人声和未闪避音乐，再决定增益；不要在已极低的底轨上继续机械乘 `0.12`。本系列曾出现音乐约 −72 至 −75 dBFS、人声约 −24 至 −26 dBFS，近 50 dB 的差距让音乐事实上消失。把人声高于音乐约 **14–20 dB** 作为普通讲解的试听起点，使用同一语音活跃区间、同一种测量方法比较两个 stem；RMS dBFS 与 LUFS 不能直接相减。最终以手机扬声器和耳机下的讲述清晰度、音乐存在感调整，不把该区间当固定交付指标。

- 音乐先做必要的低切及 2–4 kHz 约 2–3 dB 宽范围避让，再决定总体电平；已处理过的 stem 不重复均衡。
- 可从未闪避音乐约 −25 LUFS、人声处压低约 6–8 dB 开始试混，密集代码或公式再低约 2 dB。上述绝对值依人声标定而变，必须复核实际相对响度。单声道人声复制到双声道会使声道求和响度约增 3 LU，不能把 mono 测量直接当 stereo 成片测量。
- 闪避用平滑包络，预留约 80–150 ms 提前量，压低约 100–200 ms、恢复约 0.8–1.5 秒作为调试起点；保留短停顿的音乐电平，只在较长停顿和无旁白段明显回升，避免每个字之间抽吸。需要更稳定时增加约 0.2–0.4 秒保持时间。
- 曲目按大段教学弧线编排，避免每个镜头重新起奏。循环在同速度的乐句边界交叠，曲目切换保留自然重叠，不靠突然涨音量制造过渡。
- 衔接先核对节拍、乐句、调性与频谱密度；较长交叉淡化不自动保证自然，也可能叠出双重鼓点。必要时让节奏声部先退出，用兼容的氛围层桥接，再引入下一段节奏。API 生成音乐桥是可选手段，仍需核实许可和实际端点；不能把生成成功当作听感验收。
- 用户要求“说话时音乐再轻一点、人声稍高一点”时，先小幅调整独立声轨并重测，可从口播配乐再降约 2 dB、人声加约 0.5–0.8 dB开始；避免全片直接涨母带。最终归一化可能抵消部分人声提升，需比较最终版本的有效人声电平与语音活跃区间的音乐比例，不能把归一化前增益冒充成片实际变化。
- 抽取开场、长讲解、英文术语、密集推导、句间停顿和片尾，等响度比较干人声、音乐以及最终 AAC 试混；记录音乐/语音比例与峰值。技术测量不能替代实际听审，也不能用整片平均值掩盖某几句被音乐盖住的问题。

旁白开始前轻柔压低配乐，结束后缓慢恢复，避免 pumping。建议 48 kHz 音频，保存 narration、score、premaster、master。双遍测量响度，目标约 −14 LUFS；预留母带峰值约 −1.5 dBTP，最终 AAC 编码后复测，真峰值不高于 −1 dBTP。检查的是最终 MP4 而不只是 WAV。

纯视觉改版且时长未变时复用已检查 master。时长、旁白或停顿改变时重新对齐和混音，避免旧音乐尾段或字幕与新视频错位。

## 长片版本重组与遗留音轨

长片可能由新句源和仍有效的旧独立句源重组；这不等于可以直接复用旧版 master。记录每个句源的版本、文本哈希、实际使用区间和清理状态，先静音检查新片段，再以句源清单重建唯一 master，避免旧旁白叠在新口播下。清理旧音频前确认它没有出现在当前句源 manifest、字幕对齐或任何可复现脚本中；无法确认的独立句源保留并登记。

遇到“前版本声音未消除”，从最终 MP4 和 premaster 分别抽取音轨，对句段做包／波形比对，定位是旧 master、视频自带音轨还是分段拼接残留。生成视频自带声音默认静音；不能只把最终音量压低来掩盖多轨叠加。新版完成后再按 [版本与空间清理](storage-cleanup.md) 处理已确认的可再生音频缓存。

## V8 长片声音验收固化

公式密集段、英文术语和论文聚焦段的音乐闪避应比普通解释更稳定，但不做每字抽吸；保持约 80–150 ms 预留、100–200 ms 压低和 0.8–1.5 s 恢复的平滑包络，再用实际语音活跃区间复核。配乐仍应可感知，不能因过度闪避降到听不见；人声清晰度、人声尾音和背景存在感要在耳机与手机扬声器上各抽查一次。

长片最终交付前抽取开场、公式推导、英文术语、密集字幕、句间停顿和片尾，逐句复听。特别核对“结果”词与公式完成帧、句尾约 0.15–0.32 秒余量、中文多音字和 AlphaGo／ReLU 等专名。机器响度检查（约 −14 LUFS、真峰值不高于 −1 dBTP）只说明电平范围，不代替听审。

若时序修正只改画面且正式音轨未变，可复用已验证 master；若改了口播、停顿或总时长，必须从句源清单重建唯一混音，并清除或登记旧 master，防止前版本人声叠入新片。最终音频的版本哈希、句源清单和混音参数与成片 SHA 一起归档。
