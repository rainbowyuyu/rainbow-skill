# 大气、海面与连续镜头

先确认实际渲染器、单位、时间源和交付尺寸，再按已有工程路线改造。这个技能提供环境渲染方法，不替换项目叙事、品牌或用户指定工具。

## 工作方式

1. 读当前场景入口、材质、相机、合成和导出脚本，记录实际路线：原生 WebGPU、WebGL、离线 Cycles 或混合。辨别物理仿真、程序化可视化、环境素材。WaterPro 的 FFT/Gerstner/SSR 与 Cycles 路径追踪应分别表述。
2. 从现有视频选白天、逆光、水面近景、穿云、实体遮挡五类中实际存在的机位，保存时间码与修改前帧。只针对本次缺陷添加场景，不擅自变更主题。
3. 优先修正单位、法线、深度关系与主光方向，再改云形、水面细节、反射、雾和后期。一次验证一项，保持同机位对比。
4. 固定随机种子，以绝对帧时间驱动天气、水波和相机。渲染跳帧、重跑单帧或分段并行时，结果仍须一致。
5. 在代表帧和相邻帧验证后接入成片；记录实际改善与尚有限制，保留一个可回退结果。

## 必须保持的空间关系

- 云的包围盒或球只是积分范围。不能把透明球体表面当体积云；密度需在体积边缘渐退。穿云时仍能看见内外连续变化。
- 云与实体相交或相机入云时，用最近实体的世界射线距离裁切体积积分；屏幕 depth、视空间 Z 与沿射线距离不能混用。只用背景云时可采用适合该布局的深度测试，但要明确它不能处理嵌云物体，新增镜头前重新检查。
- 云密度与波形留在世界空间。相机移动不应拖着天气走；相机相对坐标方案须补回绝对世界原点。
- 太阳、云边光、物体阴影、水面高光与反射使用一致方向和环境。反射缺失时提供合理环境回退。
- 符合单位的尺度先于效果参数。公里级海景参数不能直接用于几十米的飞行器或室内装置。
- 色彩在场景线性空间计算，输出只进行一次正确的色调映射和显示转换；不复制其他渲染器的 gamma 代码。
