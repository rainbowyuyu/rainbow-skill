# 实现与诊断

## 先统一尺度和时间

记录物理单位、主体包围盒、海平面高度、云底/云顶、相机 near/far、主光方向。相机路径和天气使用 `t = frame / fps`，随机噪声由保存的 seed 与世界坐标决定。模拟状态若必须逐步累积，导出可重复初始化的状态缓存；不要只在浏览器动画循环里推进。

把形状层与细节层分开。大片海浪决定轮廓，细小法线决定水光；大片云团决定构图，噪声侵蚀只塑造边缘。远处高频细节应渐弱，避免压缩后闪烁。

## 体积云

合理路径为：云层/局部体积范围 → 宏观密度 → 高度包络 → 细节侵蚀 → 视线积分 → 太阳方向光学厚度 → 相位/环境填光 → 与实体合成。

- 云团留出大小不同的空隙，不铺成均匀棉絮；底部与顶部密度平滑变化，细节频率不宜盖住整体轮廓。
- 用三维噪声或体积数据，宏观形状与边缘侵蚀使用不同频段。将密度采样锚定世界坐标，风场按绝对时间平移。
- 每步透射率使用 `T_step = exp(-sigma_t * ds)`；改变采样数量而保持相同物理路径时，整体浓度应接近不变。不要把固定 alpha 对每一步相加。
- 朝同一太阳方向采样遮蔽，配合环境填光，保留暗部层次。Henyey–Greenstein 的正负方向依赖向量定义，先验证逆光最亮的位置，再调 g。多重散射近似要如实命名。
- 密度低的空间可跳过；厚云透射率很低时提前终止；主视线、太阳阴影、反射可用不同采样预算。用真实最终镜头确定质量，不固定套用某个步数。

### 深度与边界

设相机为 C，归一化世界射线为 d。由深度缓冲重建最近实体世界位置 P 后，沿射线距离可取 `t_surface = dot(P - C, d)`。按当前投影矩阵处理 reversed-Z、深度范围、正交/透视差异；不要直接把纹理深度当米。

与体积相交得到 t_near、t_far，积分范围为 `max(0, t_near)` 到 `min(t_far, t_surface)`，结束不晚于开始时不积分。无实体命中时使用实际远界。相机在云内时起点应为零附近，不能沿用地面仰视云层的 `rd.y > threshold` 假设。

透明实体不能仅靠不透明深度解决，须按工程合成顺序选择独立深度、分层透明或显式几何交叉处理。火箭、机翼、栏杆、地平线是优先检查的边缘。体积 bounding sphere 不能贡献透明壳层；其表面只用于求交，颜色来自内部积分。进入/离开包围体不应突然整屏变色。

Blender 体积密度受尺度与变换影响。先检查对象缩放及实际体积范围，再调整密度；输出透明/雾通道时检查预乘 alpha、重影和颜色空间。

## 水面与反射

优先保持项目当前水体方案。FFT/Gerstner 是波形方法；SSR 是反射方法；体积云是参与介质方法；它们不等同于流体力学求解。

- 统一波长、振幅、速度与场景米制尺度。水面近景保留几何层起伏，远处收敛高频法线。过大的法线会制造碎玻璃感。
- Fresnel 随观察角变化，低视角反射更强；水的 F0 约 0.02 可作为纯水界面起点，艺术风格仍依镜头调节。
- 浅水底色与深水吸收沿光程变化。颜色衰减和浑浊度是不同因素；不能只把海面染蓝。
- 太阳高光、云影、天空与反射云形必须方向一致。用长而连贯的高光带带动构图，避免零碎满屏白点。
- SSR 只能读取屏内可见信息。遮挡、屏边和离屏物体处平滑切到环境/探针或工程支持的离屏反射；反射中的实体与本体不应一进屏幕就突然出现。不要将 SSR 称为完整场景光线追踪。
- Raymarch 程序场景反射只追踪其定义的几何，未必看见另一个渲染器的网格。验证接入范围。
- 海水接触船体/平台的水线、泡沫和阴影与世界位置相符；需要几何交互时，单独贴一个白色平面通常不能解决。

## 天空、光照、构图、后期

以一个可辨认主光方向组织画面：暖直射光与偏冷天空填光可用于日落，但不要把暖橙色强加给白昼或科学特写。让云边、金属边缘、水面光路指向同一光源；远处通过空气透视降低对比，近处仍保留材质。

先确保主体轮廓与背景分离，再用云层空隙、海平线和光带引导视线。重要解释区域不穿过最亮云边或太阳反射；检查最终字幕和 Logo 打开后的结果。

Three 色彩纹理按用途声明颜色空间：颜色贴图通常是 sRGB，法线/粗糙度/深度是数据，HDR 环境通常是线性。线性光照完成后统一色调映射与输出转换。检查是否将手写 `pow(1/2.2)` 与渲染器输出转换叠加。Bloom 只能服务高光，不应用来掩盖错位、过曝或材质缺失。

景深围绕讲解主体设置，避免把相邻结构全变糊。先看正常播放，再看 100% 单帧和快速跳帧；漂亮静帧不代表运动稳定。
