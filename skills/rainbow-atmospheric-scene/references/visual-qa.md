# 实际画面验收

保存同一尺寸、帧号、相机与时间的 before/after，注明渲染器、seed、单位、关键参数、图像 SHA256。只有实际渲染过的图像能作为“修复后”证据；不要用参考图、插画或手工示意代替。

## 代表镜头

选择本片存在的这些情况：

| 镜头 | 必须看清 | 常见失败 |
|---|---|---|
| 远景/海平线 | 空气透视、主体轮廓、太阳方向 | 远景太锐；云和背景粘成一片 |
| 低机位水面 | 连贯反射带、波形尺度、岸/船接触 | 满屏碎白高光、离屏反射跳变 |
| 云外到云内 | 近云渐入、体积厚度、世界稳定 | 透明球壳、整片白幕、相机拖云 |
| 实体穿云 | 前后遮挡和边缘连续 | 云穿到前景结构上、深度光晕 |
| 转场/环绕 | 运动方向、主体定位、天气连续 | 相机跳变，随机噪声重置 |
| 文字开启 | 解释对象、字幕与 Logo 均可读 | 最亮区域吞字，特效压过主体 |

单帧检查无法发现抖动和闪烁：对每个修复机位输出至少覆盖一次主要运动的短片，查看边界前后相邻帧。实际关键边界适合检查前后 1–3 秒，按任务调整。

## 有意义的自动与手动检查

- 重跑同一帧、乱序渲染同一帧：云形、水波、光照与相机应一致。存在平台浮点差异时记录容差，不冒称逐像素相同。
- 同一路径改变体积采样数量：轮廓/密度整体接近，质量主要体现在噪声与细节。
- 同机位检查 debug depth、world normal、cloud density、transmittance，再看最终合成。诊断层不放入成片。
- 摄像机进入/离开云体，及水面反射物体出入屏边：不可出现突然透明壳、白屏或反射弹出。
- 低分辨率预览过关后，至少检查最终尺寸的细栏杆、格栅、云边和水光，防止缩放预览隐藏锯齿。
- 对成片检查黑帧、时长、音画对齐、字幕安全区域及混音；环境修复不能破坏已有合格交付。

审核记录写“看到什么 → 改了什么 → 哪个帧/片段证明”，保留失败截图帮助下次定位。遇到显著失败先修根因，再增加采样、Bloom 或景深。
