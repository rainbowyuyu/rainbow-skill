# 从空间到完整画面的构建顺序

适用于需要建立海景、天空、飞行器外景，或修复“模型贴在背景上”的实时/离线场景。已有合格层应保留，不为展示步骤重写整套渲染器。室内、纯数据图解、无水场景可跳过不相关层。顺序用于隔离问题，不要求成片按九步教学。

## 先决定观众看哪里

写下该镜头唯一的主角、主光方向、前中远层次：例如前景少量云纱负责遮挡接力，中景火箭负责解释，远景海平线与云层负责尺度。前景不可长期遮住机制；最亮高光不应与字幕或重要零件争抢注意力。暖光/冷阴影是日落方案，不是所有科普的固定配色。

| 层 | 实际动作 | 可以看见的验收 |
|---|---|---|
| 1. 坐标与相机 | 统一米制、up轴、相机near/far。放标尺或网格，确认模型尺寸、视角和海平面。程序raymarch则从逆投影恢复相机射线；使用网格渲染器无需另造raymarch。 | 环绕时地平线与主体位置合理；模型不随相机滑动；靠近不会突然裁掉。 |
| 2. 可选地形/平台 | 先做低频轮廓和主体接触面。海景无岛不强加山，海上平台要有正确水线。需要程序地形时再逐层增加噪声。 | 缩成小图仍有清楚轮廓；脚、岸线、船体确实接触对应表面，没有悬空。 |
| 3. 法线 | 先看world normal debug，再开白色漫反射。高度场用中心差分或可靠导数；网格检查变换、切线和法线贴图方向。 | 同一朝向表面颜色/受光一致；波面没有翻面；镜头移动不改变固定面朝向。 |
| 4. 材质与阴影 | 指定paint/metal/roughness，先低强度细节。一个主光加合理环境填光，核对 shadow pass 与最终 pass 使用相同矩阵。 | 主体阴影落在正确位置；暗面可读；移动结构不带着旧烘焙阴影；无接触闪线。 |
| 5. 大气 | 按场景尺度设置雾与天空。复用HDR或程序大气，统一太阳和天空方向；让远层对比渐弱。 | 远处比近处柔和，海平线没有硬贴片；天空主光与主体边光一致。 |
| 6. 水 | 大波决定轮廓，小法线决定细光。按米制设置波长/振幅，浅深水分别考虑吸收。水不相关则跳过。 | 近水能读出波形，远水没有碎点闪烁；水线稳定，主体不被夸张波浪吞没。 |
| 7. 反射 | 加Fresnel角度关系、太阳光路和环境；SSR在屏边/遮挡处渐退到可用回退。区分HDR反射与真实动态云反射。 | 降低机位反射增强；太阳高光带方向正确；物体移出屏幕时反射不骤然弹灭。 |
| 8. 云 | 先宏观云形与空隙，再细节侵蚀、体积透射、太阳采样和环境填光。背景云与穿云按不同深度方案处理。 | 云有内部明暗与厚度，不像灰色贴片/球壳；主体边缘无遮挡错误；相机移动不拖云。 |
| 9. 后期与文字 | 完成线性光照后统一tone map/output，控制高光、Bloom和景深。最后打开真实Logo/字幕再检查。 | 高光仍有层次，不双gamma发灰；主体/标注清楚，字号和安全区合适；截图与正常播放都成立。 |

## 怎样验证因果而不只堆效果

固定帧号、相机和种子，保存“该层关闭/开启”两张实际帧，注明哪些参数改变。若同时改了几项，只称迭代对比。先比较轮廓、明暗和空间关系，再看微纹理；不要用景深和雾把错误遮掉。

每层先看诊断输出，再看全合成：法线错就停在法线层，云穿模就停在深度合成，SSR离屏反射消失就补回退。最后跑有运动的短片、变速查看关键边界，并重跑相同帧确认确定性。把结果记成“症状—实际原因—修复—帧号/片段证据”，方便下次调用。
