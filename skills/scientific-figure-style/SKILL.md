# 科研绘图样式

以用户指定的漫长午后（读博版）图文为视觉参考，将七色体系用于可复现科研图。原帖是社交平台配色灵感板，不是 Nature 官方规范，也不构成期刊录用保证。出处、转录疑点及采样方法见 [references/source.md](references/source.md)。

## 使用方式

- 优先使用用户已有代码、软件和数据。只询问影响结果的缺失信息；不因缺少 Python/R 偏好阻塞配色任务。无代码环境且需从零绘图时可用 Python 并说明选择；已有 R/Origin/MATLAB 工作流则沿用。
- 先确定比较、趋势、分布或场变量，再选择图型。保留数据、单位、分组、统计定义和结论强度；配色任务不擅自重算或修饰结果。
- 无数据时可给版式、代码模板或标明“合成数据，仅演示样式”的预览，不能写成实验结果。概念图区分假设/机制示意和已验证结果。
- 本技能是样式层，不自动启动 `nature-figure` 等完整工作流。用户同时要求其他技能时读取其规则。目标期刊明确要求优先于本技能默认值。

## 配色规则

读取 [assets/palettes.json](assets/palettes.json) 作为颜色唯一来源。

- 默认 `reference-labels`：转录原图印刷色号。其中 Steel Blue 字符较模糊，暂录 `#6BBCA8`，不宣称精确确定；严格复刻该色号时应先核对清晰原件。
- 用户说“像原图的感觉/照原图色块”时用 `reference-sampled`：从 WebP 色块内部采样的近似颜色，更接近画面中的蓝灰、鼠尾草、赭黄和陶土；不得称为作者原始色号。
- Ocean Blue 为主数据，Steel Blue/Sage Green 为辅助组，Terracotta 为重点或对照，Ochre 少量强调，Ivory 为展示底色，Charcoal 为文字与坐标轴。
- 分类默认最多五种数据色；更多组优先分面或组合点形/线型。Ivory 不用于白底数据线，Charcoal 通常留给文字或基准。
- 同一对象跨面板固定同色，用名称→颜色映射，不靠局部分类顺序。
- 连续量用顺序色带；正负偏差才用发散色带并指定科学中心。不要把七色分类列表拼成彩虹。定量场默认用 `cividis`/`viridis` 等；原帖衍生色带需检查感知均匀性。
- 不宣称七色已通过色盲验证。线图结合点形、线型或直接标注；浅黄/浅绿需检查白底对比，必要时加深并记录变更。浅色不用于小字。

## 输出风格

**论文模式 `paper`（默认）**：白底、深色文字、无衬线字体、轻轴线、少量或无网格、面板字母 a/b/c。工作起点为 90 mm 单栏或 180 mm 双栏、标签 8 pt、面板字母 10 pt、数据线 1.2 pt、轴线 0.6 pt；不是所有期刊通用要求。

**展示模式 `editorial`**：米白底、深蓝标题、可选衬线标题、细边框和留白。适合课题汇报和配色板。原帖的期刊封面、标志、九宫格和装饰图标不自动复制到论文。

具体图型、城市风场和世界模型应用、统计表达及导出检查见 [references/plot-guide.md](references/plot-guide.md)。

## 实现资源

- Python：`scripts/figure_style.py` 提供局部 `style_context`、固定分类映射、显式范围发散色带和精确物理尺寸导出。需要 matplotlib；导入时不修改全局 rcParams。
- Python 与 R/ggplot2 用法见 [references/code-recipes.md](references/code-recipes.md)。R 配方需在实际 R 环境运行后才能报告通过。
- `scripts/render_demo.py --output <目录> --palette reference-labels --mode paper` 生成配色卡与四面板合成演示，不读取或修改实验数据。使用任务专用目录；已有文件不会覆盖。

## 交付与检查

交付绘图源代码、来源数据或路径说明、PDF/SVG 可编辑矢量图和 PNG 预览。位图默认 300 dpi，需要时 600 dpi，按期刊调整。保留最终画布物理尺寸，避免紧裁切改变尺寸。

检查最终尺寸下文字、图例、色条、误差带是否完整可读，检查跨面板映射、单位、色标范围以及灰度区分。保存 palette/mode、映射、软件版本、随机种子（若有）及统计说明。注明未完成的验证；灰度检查不等于完整色盲模拟。
