# 图型与交付规则

| 目标 | 优先形式 | 关键约束 |
|---|---|---|
| 时序、训练曲线、预测 | 折线 + 有定义的区间 | 区分 SD、SEM、CI、预测分位数；标注预测起点；不把任意平滑带当统计不确定性 |
| 独立组比较 | 原始点 + 箱线/小提琴 | 注明独立样本 n 与重复单位；小样本避免只画密度；帧数不能代替独立实验数 |
| 模型指标 | 点区间图、分组点图 | 同色同模型；显示重复与区间；不靠截断纵轴夸大改进 |
| 特征重要性 | 排序水平条/点区间 | 保留排序依据、方向、不确定性；柱形量值轴通常从零起 |
| 相关、残差、差值 | 发散热图 | 以科学基准居中，共用范围；缺失值独立灰色而非填 0 |
| 非负浓度、速率、概率 | 顺序热图/等值图 | 单位、范围明确；跨模型比较固定范围 |
| 散点、PCA、嵌入 | 点 + 形状/分面 | PCA 解释方差来自数据；嵌入距离不能直接解释为物理距离 |
| 相关网络 | 节点/边图 | 记录布局与边阈值；相关边不画成因果箭头 |
| 参数敏感性 | 二维热图 + 等高线 | 三维视角仅在必要时使用；避免遮挡和透视造成读数误差 |

缺失值按语义显示空白、断线或专门色块。对数轴、截断轴、变换、分箱和异常值处理必须明确，样式美化不得悄悄改变。

## 城市风洞、世界模型、扩散预测

- 几何/边界条件、动力学滚动、扩散预测三阶段可用深蓝/鼠尾草绿/陶土色；箭头注明变量。自回归时间步和扩散去噪步分别标记，不混作同一物理时间。
- 风速模长、湍动能、浓度用顺序色带；有符号速度、压力差、误差用发散色带。矢量箭头说明长度与颜色编码。
- CFD、风洞测量、世界模型、扩散样本在同一位置/时刻比较时共用坐标、掩膜、单位与色标。建筑实体中性灰，禁止插值穿过实体。
- 单次生成样本、样本均值、分位数区间分别标注；生成场不能代表真值。无实测/仿真数据时只画概念图。
- 数据规模区分独立几何、边界工况、重复实验、时序长度，不以总像素数暗示独立样本量。

## 排版与导出

按预期刊印尺寸布局，对齐坐标区、标题、图例。中文选实际存在的中文字体并检查缺字；英文选可用无衬线。目标期刊要求优先。

衬线标题、米白底和细框可用于展示模式。论文白底，地图/热图可保留四边框，普通折线/条形通常隐藏上右轴。不为风格删必要边界或图像比例。

导出 PDF + SVG + PNG，保留源码与数据来源，说明聚合与误差计算。生图模型不得生成定量坐标、统计图或实验场来替代数据。概念插图若需生图，按用户工具偏好执行，与数据图分开。

检查最终尺寸和灰度预览：裁切、重叠、线宽、点大小、色条、单位、同色同义、对比度、误差定义。完整色盲模拟未执行则明确未执行，不自动声称“色盲友好”。

本套蓝—米白—陶土发散色带在灰度下不能可靠区分正负两侧。若交付物要黑白打印，应添加带数值标签的等高线、正负符号或分开显示正负区域，不能仅靠原色带。灰度预览用于发现这一限制，不意味着配色通过认证。
