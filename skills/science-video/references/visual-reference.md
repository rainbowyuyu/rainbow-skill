# 看图再设计

根据任务先打开相关图片：光学看光芯与玻璃，算法看数据对应，工程看层次，品牌看明暗。不要只读取文件名。它们是已有工程的学习点，不代表所有镜头均已验收，也不要求照搬字体大小、调色或布局。

先浏览光学/角色/机制拼板（外部或本机资源，未随公开包收录）、算法/工程/封面拼板（外部或本机资源，未随公开包收录），需要细看再开单图。

| 单图 | 学什么 | 继续检查什么 |
|---|---|---|
| 连续光谱（外部或本机资源，未随公开包收录） | 同一界面展开连续颜色；薄玻璃边、少量高光和克制辉光 | 不能把色带宽度当物理比例，字幕/光线在运动中仍需避让 |
| 水滴内反射（外部或本机资源，未随公开包收录） | 标签附着界面，主光路与次光路有主次 | 光线角度来自数值，发光不替代验证；最终压缩后细线仍可读 |
| 空间与鱼（外部或本机资源，未随公开包收录） | 柔和鱼色、地面关系、前中远景 | 本帧只是空间参考，鱼偏低；新片字幕、竖裁与角色朝向重设计 |
| 恢复关系（外部或本机资源，未随公开包收录） | 色义、物体、公式一一对应 | 两行公式可按cue逐条解释，不能一起抢焦点 |
| 算法网格（外部或本机资源，未随公开包收录） | 数据指针、状态与实体序列对应 | 网格是教学例，不是所有算法的统一模板；手机要能读关键格 |
| 工程受力（外部或本机资源，未随公开包收录） | 透明层露出构件，力与原模型绑定 | 继承小字需放大/删减；区别应力与位移，不能遮住受力点 |
| 封面（外部或本机资源，未随公开包收录） | 一个问题、一个拆解主体、短栏目条 | 各比例独立构图，不统一强制留白，也不照搬无关主题 |

镜头连续性图（外部或本机资源，未随公开包收录）说明锚点、显隐和出画顺序；它是原理示意，不是影片的卡片式排版模板。品牌明暗对照图（外部或本机资源，未随公开包收录）用于识别原件：白色浙大横标放深底，蓝色学院标识不要压在同色背景。
