# 验收、交付与清理

验收对象是**当前渲染入口、实际采用的资产及最终编码**。源码编译成功、生成任务成功和下载成功，都不能代替画面检查。先打开 [视觉参考](visual-reference.md) 的质量要点，再按镜头契约检查本片；参考图不限定全片配色。

## 冻结检查对象

- 记录入口、锁文件、求解数据、原始素材、字体、旁白句源、时间线、渲染设置及最终MP4的SHA256。检查脚本也记录版本/哈希。
- 核对实际依赖图：名为 `check-world` 的旧脚本可能仍导入旧场景，旧版PASS不能批准新片。确认入口确实采用新相机、模型、字幕与生成片段。
- 有合法目录连接/junction的继承素材，可只读按文件哈希核实；默认越界检查若报警，查明真实目标并单独记录继承关系，不能直接忽略。写入和删除不沿连接操作共享资产。
- 检查后若修改影响画面的源码、输入或配置，只重做受影响检查并刷新证据；正式成片必须绑定最终哈希。不要将旧审阅结果自动贴到新版本。

## 分层检查，分别报告

| 层次 | 必须实际做什么 | 不代表什么 |
|---|---|---|
| 科学/来源 | 单位、方向、边界、残差、许可、模型及任务来源 | 已验证所有现实条件 |
| 源码/运动 | 当前入口编译，逐帧相机/骨骼/锚点，乱序seek | GPU材质/透明正确 |
| 编码结构 | ffprobe与全片解码，音视频时长、黑帧/静音检测 | 画面好看、听感自然 |
| 静态视觉 | 主场景、每个接点及动作峰值的实际看图 | 正常速度全片流畅 |
| 连续视觉 | 接点短片与完整影片正常速度观看 | 音频读音/尾音正确 |
| 声音 | 最终AAC测量、实际听审、字幕与句源核对 | ASR自动结果等同听审 |

记录检查人/工具、时间、帧范围、文件哈希、发现和修复。没有正常速度全片观看或听审时，明确留下未完成项，不写“全片人工验收通过”。

- 排查卡顿时分清生成错帧、文件帧序与播放器丢帧：检查生产截图帧门、最终解码帧及PTS，再记录1倍速播放的掉帧和回调。H.264的B帧解码顺序不等于呈现倒序；浏览器掉帧不能直接归咎文件，也不能从检查记录中删除。
- 图像差异尖峰是复查入口，不能直接判定退帧。水面穿越等处要打开连续邻帧，核对物体运动和介质变化；如仍有明显折射边界，写明可见限制，不把“无时间回退”说成“完全无痕”。

## 每个镜头与每处接点

1. 检查入点、动作中段、出点及前后邻帧；每次主模型、相机、透明层或字幕变化都算接点。对相机速度/转角/FOV、骨骼姿态与图像差异尖峰额外抽样。
2. 看关键机制是否一眼可见：受力点、真实眼睛/手接触点、器官位置、光线交点、装配孔轴与热力图必须跟随变形后几何；角度/尺寸数据与显示放大分离。
3. 查穿模与遮挡：手/衣物/桌面、内外表面、透明物前后排序、力箭头/标签、反射/阴影；CPU坐标正确仍须看GPU像素。
4. 旧物体先出画或被合理前景遮挡，再卸载；新物体由可追踪位置进入。连带的投影、阴影、反光和文字也不能留在原地或突然消失。
5. 接力点对齐构图、屏幕锚点、主体尺寸、运动方向、相机速度、曝光和色温。微融合只修残差；双轮廓、半边天空或场景熔化应回修素材/轨道。
6. 正常速度看至少一个完整“入→讲解→出”动作；静帧漂亮但连续时迷失、眩晕、急停也要改。跨尺度镜头保留母层位置与比例参照，不凭空放大局部。
7. 文字逐镜检查：统一字体/有限字号，字幕留字尾，标签不压主物体/字幕/Logo；移动中也检查。实际缩到手机宽度复看，中央9:16预览不能代替正式竖版独立排版。

## Qwen 原生序列与真实使用

- 保存首尾净帧哈希、prompt、模型/参数、任务ID、原始视频、fps/帧数及provenance；不保存key或临时签名URL。生成源和最终合成分别审。
- 原片完整解码，查看密集联系表和正常速度片段，检查身份漂移、复制、物体融化、忽明忽暗、错误光路和末帧偏离。拒收记录不改写为成功。
- 核对合成采样器遵循记录的时间映射：同fps原生播放连续向前；异fps可按已声明方案重采样，必要插帧/调速有记录并重新审阅。禁止越界、偷偷倒播或端点冻结填时长；正常帧率转换的重复/丢帧不能一概判为失败。
- 检查接点前后原图、源片和编码后的像素效果。短淡混时间由接点决定，不把某次6帧或24帧当通用标准。
- 工具使用分成“资产存在→导入→代码采用→最终可见→审阅通过”。例如加载高斯但渲染层最终有效alpha始终为0，不能写成片采用了高斯泼溅；不要将PLY原始opacity字段的logit=0误判为透明。Opus超时未采用也不算完成协作。

## 声音和字幕

- 以真实逐句音频时长生成旁白、字幕和镜头时间线。核对数字、单位、多音字、英文缩写的第一次解释及读音；机器ASR只作辅助。
- 每段听字头/字尾与连接处，尤其片尾、重合成句、呼吸和转场。不得截音节、硬门限切尾或压整轨时长伪造逐句同步。
- 检查最终AAC的综合响度/真峰值，约-16 LUFS、≤-1 dBTP可作起点，按发布平台和听感调整。检测原WAV不能替代检测最终AAC。
- 音乐在人声区适度避让，循环落在乐句/和声处；检查突变、抽吸、异常长静音、左右声道与首尾收束。别把调速/改名当作一首新BGM。
- 从句源/母带与最终音轨抽取开头、中段、接点、片尾窗口，核对时长与相关性偏移；最终音画同步以实际编码为准。

## 包内只读辅助脚本

在当前工程运行；将下方脚本路径替换为本技能的实际路径。输出使用新目录，保留旧检查证据。

```powershell
python C:/Users/USER/.codex/skills/science-video/scripts/review_video.py video.mp4 --out work/review-unique --cuts 480,1020 --portrait
python C:/Users/USER/.codex/skills/science-video/scripts/audit_assets.py PROJECT_ROOT manifest.json
```

`review_video.py` 用于抽帧、接点联系表与中央竖裁预览；需实际打开结果看图。它不自动判定美感、机制正确或连续播放丝滑。`audit_assets.py` 只读核对清单中的文件、SHA256与路径范围；许可、科学意义、动态加载依赖和视觉质量仍需审阅。运行前可用`--help`确认当前参数及清单格式。

## 每版自动清理

用户已明确授权：每次生成新版本后，自动清理本项目不再需要的文件和中间版本。每轮收尾执行一次，不拖到整个项目结束，不重复询问已授权的清理。“审过的清单”指代理完成依赖/恢复核查，不另设用户批准步骤。清理范围仅限本次项目；引用不明的候选先保留并说明。

1. 交付最终MP4、字幕、来源/许可及必要说明、可恢复源码和原始关键资产；包含原始模型/求解数据、句源、生成provenance。说明艺术化/放大/插值范围及未完成检查。
2. 生成依赖清单及恢复包；核对ZIP的CRC、文件数量与SHA256，抽取或验证恢复所需入口。压缩包存在不等于可恢复。
3. 新版通过相应验收后，枚举明确退役缓存。查入口、public、JSON清单、脚本拼接路径和活动任务，不能以“未搜索到名字”断定素材无用；保留当前全部依赖和至少一个可恢复的上一可用版。小范围修订仅重查受影响部分，未变部分凭哈希继承已有有效证据，不能伪造未执行的看听审。
4. 删除前验证每个解析后的绝对路径在本片目录内；拒绝连接、共享目录和活动任务输出。Windows用同一PowerShell/Python流程处理，不跨shell拼删除命令。
5. 只按审过的清单删除，记录实际文件/字节及保留原因；删除后复核依赖、入口和成片哈希。释放运行内存还需结束本任务进程、dispose GPU资源，不能把磁盘清理描述成显存释放。

优先清理：已被正式编码替代且可重建的逐帧序列、失败渲染分块、重复导出、旧预览、无引用贴图、临时下载和本项目废弃浏览器profile。未采用的生成素材先保留任务/provenance和拒收原因，确认无当前/回退依赖后再删不需要的大文件。保留当前/回退需要的唯一原始生成素材、模型、求解结果、句源、品牌原件、许可与来源记录；不能按“v1/v2”或修改时间整目录扫删。

新版失败或验收未完成时，仍清理确定可丢弃的失败临时文件，保留前一可用版本与排障证据。没有安全候选就记录释放0字节及原因，不能为了完成清理指标冒险删除。清理记录至少含候选路径、用途、依赖判断、恢复包、删除结果、实际字节与保留理由；大文件优先，不反复压缩保存多份完整重复恢复包。
