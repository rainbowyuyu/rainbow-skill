# 科普视频

用可看懂的变化讲清一个问题。默认约5分钟、1920×1080、30fps、rainbow鱼中文解说；用户指定的时长、品牌、画幅与工具优先。只整理技能、文案或封面时，不启动成片或付费生成。

## 工作入口

1. 每次收到本技能范围内的制作或修改需求，按[案例检索与技能应用](references/research-and-skills.md)实际上网查相关优秀案例和适合当前问题的技能；看原画面/演示，把借鉴点落实到本轮设计并记录。小修改做小范围检索，不为找参考重做无关内容。同步查看当前工程、上一版及本包[视觉参考](references/visual-reference.md)，保留已认可部分，不固定配色或构图。
2. 按[故事与声音](references/story-audio.md)检索主题，建立“看见现象→预测→试验→机制→回到生活”的因果链。逐句对应可见动作、证据和镜头；先合成旁白测真实时长，再排最终时间线。
3. 先做一个代表镜头和相邻接力短片，检查材质、运动、字幕与声音，再扩展全片。用[镜头契约](assets/templates/shot-contract.json)记录坐标、尺度、锚点、入出速度、层次和验收点。无需为常规实现重新索取已给授权。
4. 依据下表及检索结果按需组合工具与技能。阅读选中的SKILL.md及必要示例，实际应用能改善当前镜头的方法并检验效果；已安装适用技能优先，不为堆工具盲装新包。不可用时保留证据，采用合适替代方案。
5. 按[验收与交付](references/qa-delivery.md)检查最终编码。每次生成新版后自动执行本轮清理：通过检查后删除明确无用的中间渲染、重复素材和退役版本，保留当前依赖与一个可恢复回退；未通过时只清理确定可丢弃的临时文件。用户已授权这类清理，无须每版重复确认；报告实际释放空间与保留项。

后续视频默认将成片、封面和交付包写入 D 盘对应项目的 `output/`，中间渲染与缓存写入同项目 `work/`；保持路径相对项目根目录，避免写入 `C:/Users/USER/Videos`，用户明确指定其他位置时除外。

## 全片必须成立的关系

- 每句话带来新的观察或解释；从生活/工程困惑引入，术语在现象之后出现。删除重复设问、制作口吻和“不是……而是……”式空转，不承诺流量。
- 同一主体沿同一坐标与因果链贯穿。局部从主体准确位置抽出/放大，解释后回到关系中；母层渐透明、剖切和比例尺帮助跨尺度理解。相机运动服务观察，避免反复整人→细胞→整人的无关拉远。
- 转场有接力物：水滴、光线、构件、轮廓或前景。旧物体离开可见范围/被合理遮挡后才卸载，新物体从可追踪的位置进入；检查阴影、反射、标签也不突然跳变。合理微融合可修接缝，不用全场淡黑掩盖空间断裂。
- 文字少、大、统一。一个镜头一个视觉焦点；标签绑定三维锚点并避主物体、字幕和Logo。不要用小字堆满工具名或边界条件。品牌按任务选定，浙大标志不混同院标。
- 科学数字、方向、结论有可核查来源。示意可艺术化，动画形变/粒子/热力图不能冒充已运行的求解结果；有真实仿真则保存输入、单位、边界和原始输出。
- 离线动画由帧号、固定种子与保存的数据决定；乱序定位仍一致。生成片段按原生帧序前进，不靠冻结/倒放掩盖失败。资产存在、任务成功、代码采用、最终可见、画面通过分别记录。
- 字幕、旁白、镜头共用实际句源时间线，保留字头字尾。数值检测、抽帧视觉审查、正常速度观看、实际听审分别记录，未做的检查不能写“通过”。

## 海洋新能源与工程模型增补

海上风机或海岸校园镜头另读[海洋场景渲染](references/ocean-scene-rendering.md)：按近/中/远三层统一水面、天空、陆地与设备的光照和绝对时间；用真实吃水、系泊、泡沫、倒影和接触阴影建立重量感；玻璃态三维标题必须与世界空间、太阳高光和水面倒影同帧更新。近景树木、云和地表采用有许可的LOD实例，固定帧号排查闪烁与z-fighting；标签、风线、受力箭头绑定真实节点并避开字幕和Logo。该页的场景QA（固定帧重渲染、手机缩小、入水/出水接力、音效与水线交点）是本节的补充检查，不把兼容水面或艺术化泡沫写成FFT/SSR/CFD结果。

- 故事从一个可见的生活或工程观察起步，再沿同一条能量路径进入设备。浙大海洋新能源系列默认用中立介绍者口吻，介绍公开团队、成果与基础知识，不自称学生或团队成员；研究名称在对应部件讲到时才出现，不在开场堆列整季目录。教学模型不写成官方原型或成果。
- 风机模型要记录来源、单位、比例、节点层级和已知限制。优先使用有轮毂、叶片、轴系、发电机、变流器、塔筒、基础与海缆关系的整机层级资产，避免玩具式孤立零件；近景只放大真实节点，不随意改变相对位置。
- 机舱剖切沿同一坐标系连续推进：母层先渐透明，内部件再获得焦点，镜头沿轴线或电能路径移动；使用固定时间驱动的 smoothstep 过渡，禁止突然出现、消失或无依据的跳尺度。人体/解剖类 skill 只借用“连续尺度、空间锚点、母层透明”的方法，不把人体资产或术语套到工程设备上。
- 水面必须说明实现层级：完整商业 WaterPro、已有 licensed WebGL adapter 和自写 Gerstner fallback 分开记录。若使用本地 adapter，不声称已运行 FFT、SSR、WebGPU 或真实海况求解；帧更新只接受绝对秒数和固定参数，保留 provenance、许可证与版本。
- 每句旁白都要能在画面中找到对应动作、结构或测量量。术语后立即给生活化解释；视觉示意可以艺术化，但力、功率、电压、比例和机构关系不能被装饰性动画改写。
- 指定音乐保存源文件哈希、处理链、授权状态和最终响度；旁白与音乐用真实时长混音，检查字头、字尾、断句、长静音和尾音截断。字幕统一字体、字号和安全区，避免把工具名、来源或小字压在主体上。
- 新版通过 `npm run check`、静帧/正常速度抽查、ffprobe、响度和字幕遮挡检查后，再清理本片可重建的 bundle、重复中间渲染和退役音轨；保留一个可恢复回退、模型源文件、旁白 raw/clean、WaterPro 依赖、Qwen provenance、物理验证和来源清单。
