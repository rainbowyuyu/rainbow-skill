## 真正的呼吸需要停止运动

为一个信息对象给出五个绝对帧点：`start < prepared < arrived < release < end`。在 `arrived…release` 内，它的位置、比例和文字完全不再变；退出才交给下一对象。不要把持续正弦摆动称为停留，也不要给所有文字套同一弹簧。

```ts
const clamp01 = (x:number) => Math.max(0, Math.min(1, x));
const ease = (x:number) => { const q=clamp01(x); return q*q*q*(q*(6*q-15)+10); };
const u = (f:number,a:number,b:number) => ease((f-a)/(b-a));
const visibility = u(frame,start,prepared) * (1-u(frame,release,end));
const travel = u(frame,prepared,arrived); // 到达后严格等于1
```

这些曲线在查询时直接计算，乱序定位与正序播放得到相同状态。时长应按真实句源和对象复杂度决定。强拍可以决定抵达点，不能挤掉理解一条新公式所需的停留。

## 让一个符号承担接力

把实体投影坐标和公式槽位放在同一个画幅坐标系。移动符号即将到达时先退出，槽位稍后出现，避免两个同样的符号同时抢眼。V05使用：

```ts
const movingAlpha = visibility * (1-ease((travel-.70)/.12));
const slotAlpha = visibility * ease((travel-.82)/.18);
const x = fromX + (toX-fromX)*travel;
const y = fromY + (toY-fromY)*travel - 4*travel*(1-travel)*arcHeight;
```

`.70/.82`是本案例调度，不是通用最优值。关键是不重复、到达后稳定、实体—符号—公式的数据身份一致。字体随画幅缩放时重新核对投影和公式槽位；不能只把符号的终点缩小而忘记公式文字。

## 大动作的速率曲线

“缓动进度”不是速度；若希望中段匀速，先设计速度再积分成路程。V05的 `cruiseProgress(q,edge)` 在两侧平滑启动和停止，中段为常速。令 `F(u)=u⁶−3u⁵+2.5u⁴`、`e=edge`：

```text
q < e      : e·F(q/e)/(1-e)
q > 1-e    : 1-e·F((1-q)/e)/(1-e)
其余        : (q-e/2)/(1-e)
```

参数要求 `0<e<0.5`，q钳位到0…1。路程包络应接弧长参数，不能把任意样条t当距离。当前Film使用它驱动闭环指示点；摄影机采用单独的连续姿态路径，不要把所有镜头都宣称使用同一函数。

## 回放时钟与真实状态

编辑时钟继续向前，源实验时钟可以显式倒放或冻结。V05实际开场使用 `openingClock`：先展示保存的PID实验，再回到共同初态，切到P实验的失败，沿同一P轨迹倒回，停住后进入讲解。它是叙事回放，不是逆向物理求解。通用 `rewindClock`已实现并通过纯函数检查，但未被该片开场调用。

相机时间独立；根节点、关节、轮角、液面和物体材质时间读取同一个源状态。冻结时景物视角相关反射可以变化，物体不能偷偷继续模拟。若存在两个冻结段，应逐个连续区间验证，不能要求不同时间的两次冻结具有相同状态；孤立抽样点也不能证明“整段冻结”。

一个实际故障：片头倒回已经接到18°初态，下一章节的复位却读取旧开场时间映射，于是单帧跳了19.5°。修复是在边界读取真正的上一镜状态。只验相机连续抓不到这个错误，应同时检查物体角度、位移和状态来源。V05加入0.10rad/帧的腕角瞬跳警戒；这只是本片的异常检测门限，不是审美或动力学证明。

另一个故障风险：章节复位只混合θ/ω，公式和曲线仍显示新实验的原始P/I/D。这会出现实体在回位、曲线端点却指向另一角度。把复位记成独立表现阶段，复位期间让定量标签退场；恢复到保存数据后再显示。不要把插值后的漂亮姿态伪装成新求解结果。

## 动作对齐词句，不对齐整段百分比

镜头说“拉远”时，应以该字幕/音素片段的时间作为动作入口，不能等下一章节固定加三秒。候选成形、几何淘汰、锁定执行也使用不同进度；保存新候选批次不等于已经选好。若未确认的路径提前金色加粗，即使内部 `selectionLocked=false`，视觉上仍泄露了结果。

相机、文字和数据有各自时钟，却必须通过同一事件契约交接。反复采样事件前后完整邻帧，尤其检查接入后的第一帧，而不只看“动作中间最漂亮”的单帧。

对已经完成的长片，可只重渲染受影响段，但必须保留依赖证据：旧源码快照、唯一改动、旧分段哈希、改动最早生效帧、重渲染范围，以及重新拼合后的整片和音轨检查。本例只改 HUD 透明度，改动前的帧上因子严格为 1；这不能推广成“只改了一行，所以旧片都能复用”。
