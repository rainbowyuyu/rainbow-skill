# 音乐与动作包络

## 分析和对齐

保留用户音乐原件。以单声道低采样率分析 onset strength、候选 BPM、节拍位置和乐句能量，回到完整立体声音频剪辑。节拍检测可能半速或倍速，候选网格与鼓点的吻合程度要比较；仅凭文件标签不能确定实际 BPM。

导出 `beat-grid.json`，明确时间单位、源文件、分析采样率、置信度和乐句接点。成片裁接或循环后生成新的成片时间映射，不能把源曲节拍直接错用在新时间线上。

用自然整句合成旁白，留足字头字尾。可把整句开始位置移动少量时间落在乐句附近，不能把句中每个字强行对齐拍子。情绪来自措辞、重音和真实合成语气，不靠整体变调或拉速。

## 三个时间层

- 叙述层：问题、试验、解释、下一问。一个变化没看懂前不再引入第二个重点。
- 乐句层：章节的蓄力与释放；优先在乐句边界切换总体密度或机位尺度。
- 动作层：预备、主动作、回落、观察停留；事件落点可吸附到附近强拍，保持前后速度连续。

呼吸感不是所有参数都做正弦波。相机接近结果时减速，图线完成后停一会儿，声音短暂让开，观众才能感到释放。灯光脉动限于弱装饰层，不让主物体曝光闪烁。

## 音效

先建立事件表 `frame / object / action / intensity / soundSource`，物体运动确定后再生成音效。滑动用较长轻擦声，部件落位用短接触声，结果显现可用克制低频或和声点；同一帧避免多层重击堆叠。音效应来自有权使用的素材或原创合成，不从参考原片抽取再发布。

循环尽量跨完整乐句且和声相容，在跨点检查波形连续、短时能量与实际听感。对话区平滑让音，过快释放会产生抽吸。源 WAV 和最终 AAC 分别测综合响度与真峰值，验证字尾与跨段音画偏移。约 −16 LUFS、峰值不高于 −1 dBTP 可作起点，最终以人声可辨和听感为准。
