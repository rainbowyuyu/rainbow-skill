# 公开版说明

本目录是个人工作流的公开整理版。

本机用户名、工作目录、内网地址与聊天标识已改为示例。机器专用配置、声音参考、原始参考网页和媒体、生成缓存未收录。需要的工具必须按当前项目实际定位；文档中的示例路径不代表已部署。

来源：本地整理；未核实独立上游地址。

许可：没有在本目录新增统一开源许可；依赖和引用遵守各自条款。

## 实验室的运行范围

`assets/style-lab` 保留学习手册和独立源模块，原始参考视频、抽帧、音频、部分品牌图和生成 bundle 未收录。实验室页面可能引用这些外部资源，不能将本包当作无需素材即可启动的完整应用。先阅读所选模块的资源清单，并使用你有权使用的素材。

玻璃金属案例使用生成文件 `lab/glass-package.bundle.js`。其源代码在 `lab/modules/`，构建入口为 `assets/style-lab/scripts/build_glass_package.mjs`。该脚本保留历史共享 Node 目录结构，使用前须适配 `MOTION_SHARED_NODE` 与其中 Three.js、esbuild 的实际路径，再运行构建；本次没有把旧环境的构建成功当作公开包的跨平台验证。其他页面缺少的 `brand.png` 等图像应按当前作品品牌补齐，不应用空白素材掩盖缺项。
