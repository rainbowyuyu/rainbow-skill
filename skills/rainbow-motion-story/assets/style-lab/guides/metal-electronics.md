# 金属与电子：让高光、层级和通路各自讲清一件事

用于芯片封装、电子互连、精密金属和局部工艺的科普画面。先看[源片研究](../studies/redknot-glass.md)，需要核对玻璃芯、TGV和材质模型时读[技术依据](../studies/redknot-technical.md)。原创代码与原片模型无关；三种候选在[金属与电子研究室](../lab/glass-metal.html)比较。

## 先选观察任务，再选镜头

| 观众正在问什么 | 可运行候选 | 留给观众看的变化 |
|---|---|---|
| 为什么它看起来是金属，表面有什么细节？ | `metal` 金属近景 | 整体靠近，少量铜线与倒角接住反射，再回到整体 |
| 芯片、布线与基板各在哪里？ | `stack` 原位拆层 | 沿同一装配轴分离，中心不漂移，稳定看清后沿原路装回 |
| 信号怎样从这一面到另一面？ | `route` 互连追踪 | 先看完整通路，再沿上层铜线、TGV、下层铜线连续追踪 |

当前三种候选均为24秒，只是便于对比的原创长度。接入成片后应按自然旁白和观察任务重排，不把候选时长当作剪辑模板。

## 金属：先搭环境，再调材质

**已实现：** 铜、金色接触面、焊点使用金属PBR；环境由宽窄棚拍光板生成并经PMREM过滤。环境固定，相机运动让反射经过表面。小倒角负责接住轮廓光，粗糙度负责展开高光；当前铜材质使用各向同性反射；各向异性需要有效切线与UV，须独立核对。代码没有用随时间变化的噪声伪造金属纹路。

**可选调试方法：** 先只留一块宽反射和一块窄反射，转动物体检查暗侧、面与边的区别，再增加填光。金属一片白时先降低过强环境或曝光、扩大高光过渡；金属像塑料时核对金属度、环境反射和几何倒角。用同一相机比较材质参数，避免同时改变灯、镜头与颜色而不知道哪项有效。

`roughness` 控件在本例中调整铜与金色接触面，工作台范围为0.12–0.65（底层API允许到0.68），并不同时改变所有材质。硅片表面使用带金属感的艺术参数以区分表面，没有测定硅的光学常数。实际影片若强调工艺材料，应重新选用具体材料依据；不能把这组艺术参数标成实测。

铜、银色焊点、深色芯片与低饱和介质已经形成材料分工。可换成暖铜／冷银、灰银／深蓝等配色，但先保留导体、支撑与重点的稳定含义。荧光色留给需要追踪的信号，避免把所有铜线都变成发光灯带。

## 玻璃：看得见边界，也看得见内部

**已实现：** 玻璃有挤出厚度、倒角和孔，采用 `MeshPhysicalMaterial` 的透射；没有用低opacity代替玻璃。透明效果是实时近似，当前场景使用WebGL光栅PBR和PCF阴影，不能称为光线追踪。

**可选调试方法：** 先让一条清楚边缘解释厚度，再让内部金属提供尺度。玻璃发绿过重，检查色彩、吸收距离和世界单位；走线看不清，先调整观察角度、减少可见层或提供剖视，再调整透射。不要为了显示内部而忽略前后遮挡。面板越薄，边缘和厚度应越克制，避免出现厚重水族箱的质感。

本例 `ior=1.48`、`thickness=.72` 等是示意场景参数，不是原片反推或真实基板材料测量。换到毫米或微米尺寸的工程时须统一几何、厚度、吸收距离与灯光尺度。

## 拆解：同一实体分开，也能回去

**已实现：** 四组部件从装配状态沿y轴分离，保留初始中心、方向和层间顺序；8–18秒是固定相机与部件的观察窗。通孔位置和铜柱从共享规格生成。玻璃的前部剖视模型是预先移除几何的专门候选，尚未提供连续移动剖切面。

**可选编排：** 先抬起观众需要辨认的一层，说明它的作用，再打开下一层。想增加复杂度时，可以“全局建立 → 一层展开 → 局部工艺 → 返回装配”。切换尺度时保留一个孔、焊点或铜线拐角作为锚点，避免每段重新出现一个陌生模型。

接触关系应使用最终几何的实际表面核对。圆角、挤出倒角和焊球缩放都会改变占据空间，名义厚度不一定等于包围盒边界。把球放在两个名义平面之间仍可能穿入倒角底面；装配、刚开始分离、中途和回装末尾都要检查。

## 局部工艺：用前后状态说明发生了什么

以下是**后续可制作的编排食谱，当前三候选尚未实现这些工艺动画**：

| 需要解释的过程 | 可以采用的画面 | 必须保留的因果关系 |
|---|---|---|
| 开孔 | 保留相邻孔作尺度，只在当前孔位推进剖面或材料移除 | 孔的位置、深度与最终导体一致；具体加工机理按所选工艺核对 |
| 金属化／沉积 | 从裸露表面到覆盖，再到可连接结构；局部放大展示前后区别 | 不把“孔壁覆铜”和“完全填充”混为一种结构 |
| 焊点连接 | 对准端子、接近、接触、停留，必要时用局部剖视说明连接面 | 接触完成才亮起连接状态，不让悬空球提前导通 |
| 层间对齐 | 从两个已知标记出发，显示偏差及对齐结果 | 如果显示数值，偏差必须来自明确数据，不随审美缓动编造 |

当前入口 `render(t, options)` 只接收已定义的候选与参数，没有工艺事件注入接口。新增工艺应建立自己的几何状态与时间映射，并把它们接入同一实体状态；不能只传入一个不存在的 `process` 参数期待自动生成。

## 信号：沿导体解释关系，保留示意边界

**已实现：** `routePoints` 同时生成铜段和移动标记；标记按路径总弧长采样，经过上层、垂直通孔、下层，再回到上层。标记淡入淡出，只有一个当前关注点。玻璃与导体职责分开，信号不会穿越没有铜路的区域。

这里的发光球是“正在解释的信号位置”，不代表电子的实际尺寸、漂移速度、传播时延或电流大小。代码没有电磁计算。需要解释差分信号、串扰、损耗或热分布时，先引入对应计算或有来源的数据，再决定亮度、线宽、颜色怎样映射，不能把装饰流光当作结果。

标签的锚点必须落在仍存在的实体上。转向后被遮住的部件可暂时隐藏标签或移到侧栏；透明光环不应遮住它。文字保持清晰、靠近对象，避免把短名字做成长连线横穿整个封装。

## 接入与检查

实际接口、构建方法和共享依赖见[API](../examples/glass-package/API.md)。典型用法：

```js
import {createScene} from './glass-package.bundle.js';
const scene = createScene(canvas);
scene.resize(1600, 900);
const frame = scene.render(12, {id:'stack', roughness:.27, orbit:0});
// 将 frame.labels 投影到独立文字层，并处理 visible / occluded。
// 片段结束且无需复用时：scene.dispose();
```

`sample`与`render`由绝对时刻驱动，可任意跳转；工作台不要求为每种候选复制依赖。材质、结构和路径的状态检查各有作用：状态测试能确认时间与坐标关系，浏览器中仍要看反射、遮挡和文字。当前没有音轨。

| 看见的问题 | 先检查什么 |
|---|---|
| 金属像塑料或一块亮白贴纸 | 环境里是否有可反射的明暗结构；倒角、金属度、粗糙度与曝光是否匹配 |
| 细线闪动或摩尔纹 | 最终输出尺寸下的线宽与密度；减少重复微细纹路、改变距离，保留解释必要细节 |
| 拆开后像几张飘浮卡片 | 部件厚度、原装配坐标、深度遮挡、接触界面与移动轴 |
| 信号突然跳层或脱离铜线 | 路径点、实体铜段和孔位是否来自同一规格 |
| 标签闪现或指向空处 | 锚点是否仍在实体；透明效果物是否错误参与遮挡 |
| 材质精致但不知讲什么 | 当前观察任务是否唯一；是否先建立整体，再进入局部，最后给出可见结果 |

将选定方案、修改参数、实体规格与实际检查结论放进工程。此处是可复用的视觉与解释方法，不是工业CAD模型、制程仿真或电学求解器。
