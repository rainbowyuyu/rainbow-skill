# 为同一个内容选择视觉方向

先写下一镜要让人看懂什么，再比较画风。这个工作台提供同一个圆环的三套 14 秒候选：纸白剖面、黑场微距和暖色尺度回收。几何与事实一致，构图和观察距离各不相同，便于选择后接入当前影片。

[打开三方案工作台](../lab/aesthetic-direction.html) · [接口与边界](../examples/aesthetic-direction/API.md) · [设计资料核对](../studies/aesthetic-design-principles.md) · [参考片深入观察](../studies/aesthetic-deep.md) · [初步研究](../studies/aesthetic.md)

## 按观察任务选择

| 目标 | 候选 | 适合放在何处 | 取舍 |
|---|---|---|---|
| 看清整体和拆开的部分 | `look-editorial-cutaway` | 结构说明、机制比较、需要阅读的公式段 | 纸白左右分栏与朱砂小焦点；运动幅度收敛，保留完整形体 |
| 看清边缘和材料细节 | `look-industrial-focus` | 加工过程、精密机构、材料章节 | 顶部横排标题、右下斜向近景、左下说明；宽幅高光随局部推进出现 |
| 从巨大曲面回到一个具体物件 | `look-orbital-return` | 短片头、高潮后的收束、章节交接 | 上方标题、中央曲面与底部收束句沿中轴排列；尺度变化大，图形圆弧只营造空间感 |

三套的版式分别服务于结构比较、材料近看和尺度收束。纸白左右分栏；工业版将标题放在上方，右下斜向近景配左下说明；暖色版沿中轴布置物件，标题与结论分别在上方和下方。不要只截图挑配色：看完从认识对象到停住阅读的完整动作，再决定是否适合当前内容。若段落要解释严格数值关系，优先保证对象完整和标签稳定。

## 共用的故事与对象

| 时间 | 观察阶段 | 编排用途 |
|---|---|---|
| 0–2.1 s | 认识圆环 | 让主体先被认出来 |
| 2.1–4.5 s | 轮廓聚焦 | 交代接下来要看的位置 |
| 4.5–8.4 s | 材料与结构 | 展示局部或分离扇区 |
| 8.4–11.4 s | 尺度收回 | 回到已认识的完整对象 |
| 11.4–14 s | 停下来，看清 | 让结论有稳定阅读时间 |

这些时长是当前样例参数，长片应按实际中文旁白与观察复杂度调整。几何和相机在 11.1 秒后已经保持稳定，末段不会自动循环。重要标签不跟随高光不断闪动。

对象身份固定为 `ring-01`。外径 2.4、内径 1.28、厚度 0.32，八枚固定件与 60°扇区使用设计单位。这些参数属于原创示意模型；换到真实机器人或发动机时，先接入核对过的模型和参数，再保留合适的呈现动作。

## 在工作台中作决定

先把时间停在一个共同阶段，切换三套方案；切换会保留时间。需要整体比较时，开启三套并排，观察同一阶段各自引导视线的位置。播放、逐帧与拖动可以检查进出场，0.5 倍速适合核对剖块离开时的前后关系，正常速度用来判断阅读时间。

灰度开关帮助检查主体和背景的亮度层次。它不能替代实际色彩、手机缩图或压缩后的检查。导出的 PNG 保留当前灰度状态，决策 JSON 记录当前候选、时间和设计理由，并保留代码入口与参考来源。文档可在工作台内阅读，打开文档会暂停播放。

选方案时至少留下一句具体理由，例如“本段需要认出厚度，纸白剖面能同时保留整体与剖块”。如果理由只有“更高级”或“更炫”，再确认要让观众看到的内容。选择应随主题变化，同一套画风不必覆盖整片。

## 代码接入

```js
import {
  candidates, sampleEditorial, drawEditorial,
  FACTS, STAGE_TIMES
} from '../lab/modules/aesthetic-direction.js';

const time = frame / fps;
const selected = candidates.find(c => c.variant === 'industrial');
selected.draw(ctx, time, 1920, 1080);
const state = selected.sample(time);

// 或使用单个方案；状态只依赖绝对时间，可以乱序定位。
drawEditorial(ctx, time, 1920, 1080);
const editorialState = sampleEditorial(time);
```

`sample` 提供对象身份、组件状态和 `pose`；渲染接口为 `draw(ctx,time,width,height,options)`。每个候选关闭通用色板及强度控件，避免出现切换后实际不生效的选择。修改主题配色或渲染器时应明确改动的角色，不改这些设计单位为未经证实的工程尺寸。

时间大于 14 秒保持末态，非有限值或负时间回到 0。当前样例对表现动作使用五次缓动，大尺度变化采用对数插值。工程数据接入后，应把物理状态和观看节奏分开，不能为了缓动把计算出的突变偷偷平滑掉。

## 内容、文字和颜色怎样配合

当前目标先由物件建立，文字解释刚刚出现的关系。三套主标题与说明使用同一内容，但位置按各自构图安排；正式影片再改成当前问题。工业和暖色方案在只剩材料曲面的阶段淡出尺寸标签，完整物件回收后再显示。可继续使用[文字与色彩](type-color.md)中的实体标注或公式身份候选，避免一个量在不同镜头中反复换色。

留白不只靠浅色大底。低细节暗场可以承接文字，纸白空间则要检查高光和轮廓是否融在一起。原片的暖色材料可以作为一个方向，真实水体或机构的颜色仍由当前主题决定。配色与材料的基本选择见[材质与视觉](look.md)。

三套均使用解析光照、投影深度排序和示意软影。黑场高光不能证明真实粗糙度，暖色圆弧也没有计算轨道或受力。它们用于比较构图和解释节奏；需要光追或物理仿真时再接入相应渲染和求解管线。

## 可继续试做的结构

以下是尚未新增代码的延展方向，可按内容选择试做：

- **轮廓匹配**：前镜出口与后镜入口先对齐同一个可辨认轮廓，再改变材料或尺度。适合短转场，保留隐喻的说明边界。
- **密集到留白**：先显示系统，再让无关背景退为上下文，为一个机制留出阅读位置。实体身份应继续可追踪。
- **群组中的一次改变**：保持其他条件与视觉编码不变，只改变当前对象。适合说明因果对照，需注明哪些条件确实被控制。

## 接入后的检查

比较完整动作和手机大小预览，检查近景裁切是否遮住正在解释的部位。逐帧查看扇区离开与归位，确认固定件仍属于正确组件。文字出现前，观众应已认出对应物件；结论段保留稳定的形体和标签。

执行 `node research/motion_atelier/scripts/test_aesthetic_direction.mjs` 可检查对象参数、任意定位及阶段连续性，结果写入 `qa/aesthetic-direction.json`。它不评判美感，也不证明长片中所有遮挡和阅读问题都已解决。把实际审阅范围写入当前工程，保留选用理由和未完成的检查。
