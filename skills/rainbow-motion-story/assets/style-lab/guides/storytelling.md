# 编排与悬念

参考汽车飞行的同车接力、MOFs的方框操作→重复排列→尺度穿越→化学映射→术语揭晓，以及洗牌的快变→结果停留。MOFs的吸引力由简单操作逐步带出复杂对象，名称与奖项稍后进入；具体样本见[文案研究](../studies/mofs-script.md)，不把原作口播或标题当模板。

| 可运行候选 | 适用情况 | 动作重点 |
|---|---|---|
| [先失败，再倒回原因](../lab/#story-failure-rewind) · `story-failure-rewind` | 适合先展示失败，再沿同一因果时间线解释改进。 | 0–2.6秒建立失败，保持滑块身份。 |
| [只揭开一个问题](../lab/#story-question-reveal) · `story-question-reveal` | 适合让抽象量从实体测量中出现。 | 先留下“看似到位但仍晃”的具体疑问。 |
| [一个节点，接到整个网络](../lab/#story-scale-relay) · `story-scale-relay` | 适合从局部结构拓展到整体系统，再收回尺度。 | 以节点圆心作为三个尺度共同锚点。 |
| [只改一个条件](../lab/#story-counterfactual) · `story-counterfactual` | 适合对照实验、变量解释、材料和算法比较。 | 把目标和初始条件锁定。 |
| [先看结果](../lab/#story-mofs-result) · `story-mofs-result` | 结果可见，原因能沿同一个对象回看。 | 从完成的结果开始，回看有明确提示。 |
| [先搭一个结构](../lab/#story-mofs-build) · `story-mofs-build` | 需要先认识组成，局部连接能形成可解释的整体。 | 已建立的端点继续生长，结构清楚后再命名。 |
| [先做一次预测](../lab/#story-mofs-predict) · `story-mofs-predict` | 预测依据能在同场比较，稍后可用相同条件验证。 | 判断窗口不透露结果，动作完成后才报结果。 |

写一个“观众现在要判断什么”，再决定形态。术语进入前，画面应能指认其对象。开场先给结果时，下一段给可验证条件；不靠惊叹词延后解释。

贯穿对象保留ID、世界锚点、屏幕锚点和颜色身份。实体变为公式时，保留位置或轮廓，再出现符号，最后移除旧表示。短重叠可接力，但不要让同义标签长期并存。

建立对象、改变条件、看清结果、交给新问题是四种不同时间任务。停留应为恒定状态，不是把整段减速。样例时间是设计起点，不是参考统计。复杂结构多留观察时间，已读懂的结果可以迅速释放。

代码：[storytelling.js](../lab/modules/storytelling.js)。使用 `sample(t)` 查阶段，替换为当前主题对象，不把示例字幕照搬。

验收：无声看开场仍能理解发生了什么；只听旁白因果完整；每段有新增判断。并列实验共享坐标和时间，曲线插值不能冒充重新求解。去AI味按用户指定规则清理，不编造口语经历。

三套MOFs候选在[文案工作台](../lab/mofs-writing.html)共用同一孔隙示意与12秒后的解释链，各38秒。可逐句定位、对照画面依据、本机改写并导出原稿和修改稿；当前没有配音，时间是计划值。它们迁移原片的对象建立与动作推进，不是逐镜结构复刻。[指南](mofs-writing.md)给出选用方法，[接口](../examples/mofs-explanation/API.md)保留状态与来源，科学边界见[资料核对](../studies/mofs-writing-principles.md)。两球过孔只解释几何通行，内表面停留没有进行吸附计算。
