# 速率曲线：同一个动作，为什么会换一种性格

[打开同画面对照工作台](../lab/rate-curves.html) · [动画与设计研究](../studies/rate-curves.md) · [代码接口](../examples/rate-curves/API.md)

曲线决定一个动作怎样分配时间：哪一刻还在蓄力，哪一刻突然兑现，哪一刻值得停下来。先选观众需要感受到的动作，再调曲线；“全部换成更顺滑的缓动”通常不能解决节奏。

同一条曲线也没有固定情绪。一个小标签在短时间内减速入场，可以显得敏捷；一栋楼用同样时长横移半个画面，可能显得失重。路径、距离、时长、物体尺度、接触、镜头和声音共同决定观感。下表中的“表达”都是制作候选，不是心理学定律。

## 先分清三张图和三个时钟

常见缓动编辑器显示的是**进度/属性值曲线**，并不是速度曲线。横轴是时间，纵轴是位置或属性；线越陡，变化越快。图上很高却水平的一段，表示已经到了那里并且停住，不是正在高速移动。

设动作位移为 Δ，时长为 T，归一化时间 `u=t/T`，归一化进度 `p(u)`：

```text
位置          x(t) = x₀ + Δ p(u)
有符号速度    v(t) = Δ/T   · p′(u)
加速度        a(t) = Δ/T²  · p″(u)
加加速度      j(t) = Δ/T³  · p‴(u)
一维速率      speed = |v|
```

同一条曲线、同一段距离，时长减半，速度变为2倍，加速度4倍，加加速度8倍。因此“只快一点”可能让镜头突然猛烈。向左运动的速度可以为负，速率不能为负；轨道上回弹意味着速度换号，而不是画面倒放。空间速率是速度向量三个分量的平方和开根号，不等于任意一个坐标的导数。

另一张图是素材的**播放倍率** `r(t)`。它决定成片时刻读取原素材的哪个时刻：

```text
sourceTime(t) = sourceStart + ∫ r(s) ds
```

倍率曲线下面的面积才是消耗的源素材时长。`sourceTime=t*r(t)` 在倍率变化时是错的，甚至会造成回跳。相机运动曲线、物体物理时间与素材重映射分别保存；子弹时刻中相机可以继续绕行，世界只前进一点。整段视频变慢不等于只让摄影机变慢，更不应顺带拖慢个人旁白。

工作台三图显示 `p(u)`、`p′(u)`、`p″(u)`，旁边再把数值换算为逻辑像素/秒。观察图例的轴和单位，不能把图形外观相似当成同一种运动。

## 12种速率安排，各自擅长什么

| 曲线 / 代码ID | 动作怎样发生 | 可试的表达与用途 | 容易失效的地方 |
|---|---|---|---|
| 匀速 `linear` | 等时间走等距离 | 持续输送、扫描、节拍基准、客观比较；有时冷静、有时机械 | 静止直接接匀速会跳速度；不适合靠一条直线解释重物落地 |
| 先慢后快 `ease-in` | 起步克制，后半段加速离开 | 积蓄、决心、逃离、被吸向目标；视线快速离开已解释对象 | 结束时仍快，硬停会像撞墙；进入正文后还加速，观众来不及阅读 |
| 先快后慢 `ease-out` | 迅速回应，长一些的收尾 | 标签及时到位、结果揭示、轻巧而确定的响应 | 起点可能非零速度；慢尾拖太长像页面卡住，并不自动代表有重量 |
| 慢—快—慢 `ease-in-out` | 温和出发，中途推进，抵达时稳定 | 一个完整搬运、平静观察、场景关系建立 | 每个关键帧都归零会一顿一顿；不能全片所有动作都套同一S形 |
| 最小跃度 `minimum-jerk` | 两端速度和加速度归零，中间连续推进 | 镜头抵达观察位、精密拆解、需要稳定读数的交接 | 它不是“最自然”的通用证明；越平滑不代表越有性格，也不保证三维相机舒适 |
| 反向预备后释放 `anticipate-release` | 先离开目标一点，再向目标推进 | 蓄力、投掷、抽拉机构、标题准备切入 | 真实装配轴不一定允许反拉；数值/概率/进度不能为了好看随意为负 |
| 越界再回收 `overshoot-settle` | 经过目标，轻微返回落定 | 轻快、机灵、一次着重的确认；表现有弹性或未完全刹住 | 大体量金属或相机随意弹动容易像玩具；字幕正文不能一直回摆 |
| 欠阻尼弹簧 `spring-underdamped` | 多次越过目标，幅度逐渐衰减 | 柔性、活泼、余振、受扰后的回稳 | 弹性不能替代真实结构动力学；尾巴未结束时不可硬设为1 |
| 临界阻尼 `spring-critical` | 在本模型零初速度条件下，不超调地接近目标 | 干净、克制、有响应但不卖萌；参数控件、读数框架、相机微调 | “最快不振荡”只是在同一二阶模型与相应条件下；有很大初速时不能一概保证不越界 |
| 走一下、停一下、再决定 `hesitate-commit` | 小幅试探，留出明确的停顿，再完成 | 搜索、犹豫、计算确认前的等待、反事实比较 | 没有任务动机会像掉帧；停顿不能用来掩盖模型没算完 |
| 接触后回弹 `impact-rebound` | 到达约束面后反向，后续回弹减弱 | 重量落定、碰撞、扣合后的短余振 | 有接触才有反弹；理想碰撞速度不连续，不能称整段C²光滑或真实材料仿真 |
| 快速交接—停住—再推进 `rush-hold-release` | 快速给出新状态，留观察窗，再交给下个动作 | 多状态快剪后揭示关系、音乐高潮到解释、公式分步阅读 | 停住必须真的保持值；只把速度降到很小会让文字仍漂移 |

预备、过冲和碰撞的空间意义不同：预备在行动前反向；过冲在越过目标后纠正；碰撞在约束面改变速度方向。它们不能因为都带“弹”就互换。

## 怎样选，能直接用于下一段视频

先把这句话补完整：“观众要先看到____，随后明白____，最后注意力交给____。”再把动作分成预备、推进、观察、交接。并非每次都要四段齐全；直接反馈可以没有预备，持续扫描可以不在每个刻度停顿。

- **想表现重量**：先看力、距离与接触。可延长启动、减少不必要的弹跳、让主结构与附件有合理迟滞；落地让接触点明确，声音与接触同步。一个高幂ease-out并不等于重。
- **想表现敏捷**：尽快完成主要位移，随后短而稳地落定；次要部件稍后跟上。若目标是阅读，抵达之后让字体稳定，别靠不断抖动维持注意力。
- **想表现紧张或决心**：预备时减少信息，中段或末段集中加速；快段过后给出可辨识结果。把启动等待、加速和切镜的动机连起来，不能只把全片速度调高。
- **想表现浪漫或宏大**：让尺度变化与视差逐渐显露，在开阔视野保持一段运动，再缓缓抵达。长而稳定的移动配合音乐乐句，通常比每个拍点猛烈变速更能建立空间。
- **想表现生命力**：有动机的启动、一次适量超调、不同部件的时间差，以及真正停下来观察。不要给所有对象套相同正弦函数或反复弹簧。
- **想表现确定与精密**：共享装配轴和状态，末端速度可控，位置和读数准确落定。让误差真的减小，不能用装饰弹跳代替正确的最终值。

先固定同一个物体、同一段距离和同一总时长，只换曲线做A/B。选出方向后再调时长，最后加材质、景深、音效；否则很容易把更亮的颜色误认为更好的速率。

## 读者能跟住的“呼吸”

标题可以快进慢收，正文需要稳定阅读；公式的一个项可以先响应实体，再进入固定位置；标注可以等待实体停稳再出现。三者不必同时起动，也不必同时结束。

例如展示一次机械拆解：先让壳体退开，核心结构稳定露出；再沿真正轴线抽出转子；零件到位后标签出现；说明完再依相反次序回装。调不同曲线的意义是告诉观众“现在看哪个”，不是增加动画数量。

需要延长观察窗口，就延长实际的hold或镜头，不去压慢整条配音。需要让音乐高潮释放，就把已经讲明的动作做得更开阔，进入下一句前收住关键对象。配合[音乐与呼吸](rhythm.md)和[音效时机](sound-design.md)，接触帧、听觉重心和观察停顿使用同一事件表。

## 三维运镜：只改缓动还不够

1. **路径参数不等于距离。** `curve.getPoint(u)` 的u等增量不一定产生匀速。先按弧长查表，再对弧长进度缓动；Three中可核对 `getPointAt` 与 `getUtoTmapping`。弧长表精度需要按弯曲程度验证，不只增加一个看起来很大的采样数。
2. **世界匀速不等于屏幕匀速。** 同样每秒前进一米，靠近物体时其屏幕膨胀会更快。检查主体屏幕中心、面积、角速度和前景视差，必要时调整路径、焦点或时长。
3. **平移、看向和滚转共同决定观感。** 相机轨迹光滑，target若突然换点仍会甩头。转弯可有合理bank，阅读位逐渐归正；旋转用连续方向或四元数插值，避开欧拉角跨±180°的意外长转。
4. **接力镜头不必每段都停。** 比较边界位置、速度方向和速度大小。只有C⁰会不跳位置却突然换速；C¹保持速度；需要更柔和的控制再看C²。镜头切换可以故意不连续，但应有可读的剪辑理由。
5. **主体物理状态不由缓动伪造。** 控制仿真里的位置/速度读真实数据，表现曲线只决定镜头、展开量、注意力和时间映射。修改物理时间时所有相关层同步取样。

三维沿路径运动 `X(t)=R(p(t))` 的加速度还包含路径曲率项：`R″(p)·ṗ² + R′(p)·p̈`。所以图上进度曲线很柔和，遇到急转弯依然可能有剧烈横向加速。

本库弧长采样函数将路径分数限定在0…1。预备和超调有意越界时，先扩展实际路径或单独安排预备段；直接传给被夹紧的路径会丢失回撤/越界，不能宣称仍展示了原曲线。

## 剪辑里的速率坡道

速度重映射通常在“动作开始—关键瞬间—动作完成”之间安排。较快进入，关键接触或姿态附近变慢，看清后恢复；或者平稳蓄势，动作兑现时切到更快速率。只在需要观众看清细节时变慢，不是每个转场都重复快慢快。

先标源片关键事件，再根据倍率积分求它在成片中的落点；音乐重拍对准这个落点，而不是对准一条手画曲线的中心。允许声音提前引入或延续，但接触声仍要与最终画面的接触对齐。

普通30fps素材被放到0.25×时，每秒只提供7.5个原始独特画面；输出30fps不会凭空增加真实动作采样。帧重复、混帧、光流各有代价；运动模糊也不能恢复没有拍下的信息。程序场景可在新的世界时刻重新渲染，真实素材则要检查插帧在手指、轮廓、遮挡和粒子处的错误。

已录旁白维持自然语速。若只是让解说段中的画面慢下来，分别重排画面、语音与字幕；不要把人声一并压成低沉拖长的声音。

## 曲线与代码的关键细节

CSS `cubic-bezier(x1,y1,x2,y2)` 的横轴是输入时间，纵轴是输出进度。实现时先求使 `Bx(s)=u` 的参数s，再取 `By(s)`；直接把u塞给By不是同一种曲线。x控制点必须在0…1，y可以越界，属性本身是否允许越界要另外判断。详见[W3C](https://www.w3.org/TR/css-easing-1/)与[MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function/cubic-bezier)。

常用的五次最小跃度进度是 `p(u)=10u³−15u⁴+6u⁵`。它在归一化0…1内端点的一阶与二阶导数为零；接静止段可达C²，三阶导数并不同时为零。它是在一维、固定时长和端点静止/零加速度条件下的标准最小跃度解，不是对任意曲线路径或人物感受的保证。

物理弹簧的参数彼此相关：`ωₙ=√(k/m)`、`ζ=c/(2√(km))`。只改变质量，同时保持k/c不变，会一起改变频率和阻尼比。不要把“调一个质量滑块”直接翻译成“更高级”。本库预设以ω和ζ控制归一化响应，实际时长缩放的含义见API。

解析弹簧会渐近衰减，T通常是参考时长而非精确结束。可以在位置误差和速度都足够小时按显式容差结束，或者另做连续收尾；直接在T把位置设为1，会截断正在运动的尾巴。工作台允许查看T以后的响应。

运动中改目标要带上当下的位置与速度。重新从零速度启动一个普通ease，即使位置接上也可能顿一下。可用保留状态的弹簧，或按当前速度边界求Hermite/多项式过渡；不是只有弹簧才能做到速度连续。

```js
import {sampleMotion, buildTimeRemap} from './rate-curves.js';

// 离线渲染按绝对时间求值，倒序定位也一致。
const time = frame / fps;
const move = sampleMotion('minimum-jerk', time, {
  duration: 2.4, distance: 480, origin: 0
});
// 用move.position映射到自己的物体/标签；单位由distance定义。

// 播放倍率必须积分，以下三个关键点消耗5秒源素材。
const remap = buildTimeRemap([
  {time: 0, speed: 1},
  {time: 2, speed: .25},
  {time: 4, speed: 3.5}
], {sourceOffset: 10});
const sourceTime = remap.sample(time).sourceTime;
// 关键事件、字幕、音效均使用最终映射后的成片时间。
```

[核心API和运行示例](../examples/rate-curves/API.md)包含贝塞尔反解、弹簧边界、分段速率积分和弧长采样；测试入口为 `node scripts/test_rate_curves.mjs`。数值测试能发现错误的时钟、导数和接缝，不负责证明“有趣”或“浪漫”。

## 到成片时怎么检查

先静音看同一动作能否辨认，再加音乐和音效。稳定段能否读完，落点是否明确，重物是否轻飘，镜头是否只在需要时加速，速度改变有没有实际动机。然后以正常播放速度看连续镜头，不能只看曲线截图。

数值方面检查端点位置、速度、加速度、分段边界、时间映射单调性、实际源片范围和随机定位一致性；有意反向或碰撞分别记录。画面方面检查屏幕空间速度、透视变化、遮挡、字幕读窗与动态模糊。最终音视频编码后再查事件同步，保持实际检查范围记录。

资料支持、实践推论和原创样例分别记录：主研究在[研究记录](../studies/rate-curves.md)，补充技术文档在技术来源（外部或本机资源，未随公开包收录）。网页正文读取不等于看过其中嵌入视频；这些风格形容词是供比较的制作假设，不是统一感知量表。
