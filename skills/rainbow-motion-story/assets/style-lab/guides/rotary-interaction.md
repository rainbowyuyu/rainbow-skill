# 转子剖切交互的复用方法

适用问题：观众需要同时理解“这是哪一件物体”“里面什么在动”“操作改变了什么”。参考证据见 [原片观察](../studies/rotary-cutaway.md)，几何依据和模型边界见 [运动学核验](../studies/rotary-kinematics.md)。原片交互手法与原创示例的实现分开记录。

## 让每次操作只有一个明确结果

先保留整机轮廓，再打开前盖或剖面，给观众时间看清转子与偏心轴；最后才改变视角或展示轴角关系。端盖退出、剖面变化、机构转动各自采样，切开不会重置旋转相位。回装从部件初始矩阵计算，避免连续点击后位移累积。

|观察任务|可迁移动作|验收点|
|---|---|---|
|识别外壳与内部位置|整体姿态先落定，再打开前面|底座、轴线、转子位置保持连续|
|区别公转与自转|标出固定轴心和偏心中心，附着一个有编号的顶点|轴三圈、标记顶点一圈；不是两个独立动画|
|追踪剖切过程|切面或轴向盖板移动，转动继续|截面有实体厚度，标签不挡接触界面|
|解释前后层次|移开前盖，保留有厚度的壳体，再缓慢改变视角|内外壁和转子按深度遮挡；标记应被前盖正常挡住|
|查看装配关系|沿轴向拆开，再恢复初始变换|变换可逆；爆炸距离不改变转子偏心距|

当前原创示例采用完整实体前盖：先沿轴退出，再移到侧边，没有透明擦除或任意切面。壳体端面是有内外边界的环带网格。Canvas 多边形使用背面剔除和全局面深度排序，支持的是明确限定的观察域；它不具备通用三维剖切或路径追踪能力。

## 一个运动状态供所有视图共用

建议把状态分成独立量：未取模的 `shaftAngle`、开盖比例、拆解距离、相机方位与俯仰角。所有视图、顶点标记和读数都取同一份 `sampleRotaryState` 结果。拖动时间条应按目标时间重新采样，不能靠逐帧累积位置。

固定速度示例可用 `shaftAngle=6π·t/18`，18 秒为三个轴圈及一个带标签转子周期。这个示意时间对应轴每分钟 10 圈，仅为看清动作而设计，不是发动机工作转速。暂停时冻结机构角，镜头或剖切仍可单独操作；继续播放从暂停相位开始。

如果提供运行中调速，应累积角度或分段记录速度变化：以当前角为新起点继续积分。直接把 `shaftAngle=speedSlider×elapsedTime` 重算，会在调速瞬间跳位。导出确定性动画时，应保存这些速度段或显式给出每帧轴角。

## 工作台的操作顺序

打开 [机构工作台](../lab/rotary-interaction.html)，选择“打开观察口”或“沿轴拆解”。两套分镜共用同一运动学对象与电机事件，演示时长均为 18 秒。

1. 先播放默认分镜。前盖退出后观察 A/B/C 三个固定色点；轴累计圈数是转子累计圈数的三倍。
2. 暂停并选择“手动检查结构”。滑动“观察开口”只移动完整前盖，滑动“零件拆离”改变装配轴上的分离距离；二者不重置角度。切入手动时采用当前画面的两个值，不先跳回零。
3. 调整“演示轴速”或点“冻结机构”。操作会暂停播放器，并在当前时间写入速度事件。再次播放后，分镜时间继续推进；若轴速为 0，转子保持相位，开盖和拆解仍可按分镜继续。恢复机构运动使用该时间之前最近的非零速度，没有记录时使用默认 10 rpm。
4. 拖动画面或使用视角滑杆、预设检查层次。水平角限制在 −0.65 至 0.65 rad，俯视角限制在 0.2 至 0.8 rad；这是有限观察域，不是任意环绕相机。“近正面”预设保留 0.2 rad 的轻微俯视以便看到厚度；“右侧观察”也只到指定的斜侧角度，不绕到背面。
5. 点阶段按钮回到指定分镜节点。此操作退出手动开口/拆解模式，恢复该时刻的分镜姿态，保留电机速度事件、观察视角和标注设置。拖动时间条则只改变时间，不自动退出手动模式。
6. 用“恢复分镜与默认转速”清除速度改动和手动观察设置，恢复默认视角与标注。此按钮保留当前时间；需要完整重看时再点“从头播放”。

上一帧/下一帧以 `1/30 s` 移动；画布获得焦点后，左右方向键也逐帧移动，空格播放或暂停。播放到 18 秒停住，再点播放从头开始。播放倍率只改变播放时钟与实际等待时间，不重写电机速度事件，也不改变 JSON 中的 30 fps。

## 调速是编辑之后的计划

[rotary-session.js](../lab/modules/rotary-session.js) 用分段恒定速度事件记录运动。每个事件是 `{time, rpm, angle}`：`time` 为演示秒数，`rpm` 为该时间之后的轴速，`angle` 为事件发生时连续的未取模轴角。默认只有 `{time:0, rpm:10, angle:0}`。

在 8 秒调速会保留 8 秒之前的事件和当前角度，并重写 8 秒之后的计划；原来位于 8 秒或之后的事件会被替换。若之后回到 4 秒调速，4 秒之后原有的调速和冻结计划都会被覆盖。这是对剩余运动的重新编排，不是追加一个不影响未来的临时速度。

`motorAt(events,t)` 从事件确定性地求角度与当前速度，再将 `angle` 作为 `shaftAngle` 传给机构模块。速度取自电机事件，不能由单个机构采样的角度推断。0–30 rpm 是便于观察的演示范围；不会给出发动机功率、扭矩或额定转速。

## 导出什么，如何复现

“导出机构与操作 JSON”保存当前候选、电机事件、观察方式、开口/拆解值、视角与标注开关，并以 30 Hz 采样完整的 0–18 秒计划。导出含 **541 个状态点**：编号 0–540，最后一点为 `t=18 s`，用于终点验证。18 秒、30 fps 的视频只使用 **540 帧**，即 `renderFrameRange: [0,539]`；不要把终点再当作第 541 个视频帧追加，否则时长会多一帧。

每点包含轴角、转子角、开口、拆解、零件位置和实际绘制使用的 `camera`。该相机已根据所有实体的投影边界完成取景；`baseCamera` 保留采样时的原始相机参数。复现时直接使用导出的实际 `camera`，或对同一状态执行 `frameRotaryState(state)`。这个轻量接口使用与实体生成相同的全部顶点，结果与 `frameRotaryScene(state, buildRotaryScene(state))` 逐值一致，省去导出时的面、法向和材质数据构造。只使用原始比例和画面中心会与工作台取景不同。

JSON 保存的是当前计划，不是每次鼠标拖动的录像。速度变化会保留为 `motorEvents`；手动模式下，当前开口和拆解值用于全段；当前视角和标注设置也用于全段。分镜模式则按候选的时间线计算开口与拆解。切换视角的历史、开口滑杆的手势轨迹及播放倍率不作为动画关键帧导出。

“保存当前画面 PNG”保存暂停后的当前 1600×900 图像。JSON 和 PNG 都是浏览器下载；工作台不会自动生成视频或上传文件。具体字段与接入示例见 [机构 API](../examples/rotary-interaction/API.md)。

## 几何 API

ES 模块位于 [rotary-geometry.js](../lab/modules/rotary-geometry.js)，不依赖 Three.js、DOM 或额外 npm 包。点使用 `{x,y}`；坐标为 `+Y` 向上，轴沿 `Z`。所有长度使用同一单位。

|导出|约定|
|---|---|
|`ROTARY_DEFAULTS`|`{eccentricity:0.22, rotorRadius:1}`，冻结对象|
|`ROTARY_TAGGED_PERIOD`|`6π`，轴角的带标签周期|
|`rotaryParameters(options)`|补默认值并验证 `R>0, 0≤e≤R/4`|
|`sampleRotaryState(shaftAngle, options)`|返回轴角、转子角、圈数、`center` 与三点 `apices`|
|`housingPoint(phi, options)`|外旋轮线单点，`phi` 为转子/尖端参数角|
|`sampleHousing(options, segments=720)`|逆时针壳体边界，不重复首点；绘制时闭合|
|`sampleRotorBoundary(shaftAngle, options, pointsPerEdge=24)`|直边三角形采样，同样不重复首点|
|`housingRadialClearance(point, options)`|沿原点射线到解析壳体的径向间隙，正值在内；不是最短距离|
|`pointInHousing(point, options, tolerance)`|默认容差 `1e−9 R` 的解析曲线内外检查|

```js
import { sampleHousing, sampleRotaryState, sampleRotorBoundary } from './rotary-geometry.js';
const options = { eccentricity: 0.22, rotorRadius: 1 };
const shaftAngle = 6 * Math.PI * (timeSeconds / 18);
const state = sampleRotaryState(shaftAngle, options);
const housing = sampleHousing(options, 720);
const rotor = sampleRotorBoundary(shaftAngle, options, 24);
// renderer 将 XY 点映射到同一模型空间，另加轴向厚度和观察状态。
```

任意缩放要同时作用于 `e`、`R` 和附属几何。不要把原本正确的尖端轨迹再加弹簧、独立旋转缓动或不一致的缩放。视觉强调可施加在光线、标签或镜头上；机构坐标保持几何关系。

当前直边转子不适合补画貌似真实的内齿圈：默认情况下内齿节圆半径 `3e=0.66R` 大于该三角形内切半径 `R/2`。若要演示齿轮，需要同时设计可容纳齿圈的真实曲边轮廓并验证齿数、中心距和避让，不能只装饰一圈齿。

## 必须分开的读数

轴角、转子角与圈数是几何模型的结果。功率、扭矩、燃烧压力、效率和排放需要别的物理模型或实测数据；不从演示速度、油门滑杆或着色面积推断。工作区颜色若仅用于区分身份，应标为示意，不暗示准确的进排气口时序。

验收可运行 `node scripts/test_rotary_geometry.mjs`。它覆盖带标签全周期、多圈连续性、三尖端贴合，以及直边与内部采样点不穿壳。交互层仍需另测暂停/继续、反复切换、时间拖动、回装、极端视角和窗口尺寸；几何测试通过不代表这些 UI 行为已经通过。
