# 根据要解释的问题选择画面风格

AI绘图参考片用了白纸空间、金色点群和绿色黑板。每次换风格，都接着回答同一个问题。选用时先写下观众要看懂哪种关系，再决定用纸面、粒子还是箭头；一次交接留住一个可追踪的对象。

本指南依据原帧清单（外部或本机资源，未随公开包收录）及后半段观察（外部或本机资源，未随公开包收录）。全片有1fps概览，三个局部窗口有5fps联系表，另有三个逐帧窗口；静态审阅范围写在清单中。图像能确认表现形式，无法确认原作者使用的模拟器、材质节点或生成算法。

## 视觉问题 → 风格选择 → 不能照搬

| 视觉问题 | 可以选的风格与顺序 | 不能照搬的部分 |
|---|---|---|
| 平面图里有很多对象，观众看不出它们属于同一个空间 | **白纸空间**。先把卡片放在同一张网格纸上，再让纸面弯曲或收拢，留住共同坐标的参照。参考33–54秒；39.8–44.4秒（外部或本机资源，未随公开包收录）能看到卡片离场、纸面变形、三轴出现的次序。 | 纸张变形只是教学隐喻，不能据此宣称恢复了真实高维流形，也不能从成片猜测原作者用了布料模拟。原片卡图与房间资产不进入原创候选。 |
| 两种结果有区别，但观众不知道比较什么 | **工程测量面板**。先给两件对象相同的尺度与观察角度，用卡尺或同一游标对照，再引入衡量差异的式子。参考55–85秒：几何比较后才出现 KL 公式，随后进入损失曲面。 | 画面中的长度、形状只是类比。接入具体算法时，应显示实际损失值，不能把纸团外形差别当成已计算的 KL 散度。 |
| 状态变化看起来只是一个数在减小 | **金色粒子**。保留点群的中心和范围，换背景后继续显示同一群点，再让它们接近一条可辨认的曲线。参考116–129秒；逐帧换风格（外部或本机资源，未随公开包收录）与结果概览（外部或本机资源，未随公开包收录）可以对照。 | 点群收拢不自动等于扩散反演；程序化路径应明确为示意。有计算结果时，轨迹与读数必须读取同一组数据，不能为视觉效果改变结果。 |
| 推导越讲越满，但换整页又丢了前文 | **局部擦除黑板**。让板擦只经过已讲完的内容，保留曲线和当前样本，随后在空位放新样本。参考170.2–171.4秒逐帧（外部或本机资源，未随公开包收录）。 | 不能一边擦上方一边让下方公式凭空消失。内容遮罩要跟随板擦接触区；纸面污迹和粉笔颗粒保持固定，避免逐帧随机造成闪烁。 |
| 一对多关系只剩一束杂乱连线 | **先单方向，再多方向，最后合并**。从同一点出发，逐项出现样本方向；颜色和线宽先让关系可读，再把结果方向交给公式。参考165–179秒（外部或本机资源，未随公开包收录）和168–191秒概览（外部或本机资源，未随公开包收录）。 | 多条线的视觉平均不能冒充网络预测。示例若计算均值，应写明权重、向量定义与归一化；把一束线随意收成漂亮箭头会改变要解释的关系。 |

## 三种原创候选怎样分工

本轮三种新候选用于比较表现方法，模块为 [paper-space.js](../lab/modules/paper-space.js) 与 [generative-flow.js](../lab/modules/generative-flow.js)。它们使用原创几何和教学数据，没有取得或重建原作者源码。

- [**纸面进入空间**](../lab/#visualization-paper-space)：先看共同平面，再进入有深度的观察位置。固定 UV 随纸面走，读数时停止大幅运镜；[接口](../examples/ai-draw/paper-space-api.md)。
- [**点群、方向与轨迹**](../lab/#visualization-directed-flow)：同一批点先展开为曲线带，再显示局部方向，之后才执行运动。箭头与运动共用解析曲线；[接口](../examples/ai-draw/generative-flow-api.md)。
- [**黑板局部擦除与一对多来源**](../lab/#visualization-observation-fan)：上层换演算，下层保持曲线与观测点；三张卡片依次接到共同观测。本候选未计算方向均值或概率权重；[接口](../examples/ai-draw/generative-flow-api.md)。

三种方法可单独使用。纸面适合解释组织关系，粒子适合显示大量状态的变化，黑板适合逐步推导。换到新风格前，先让观众认清当前对象；进入新风格后留出读数时间。强对比配色可以标记段落变化，文字的字号层级和语义颜色应保持一致。

## 接入时检查完整的一次交接

检查入场、状态变化、停留和离场，不只看最漂亮的静帧。逐帧定位时，对象ID与遮罩结果应相同；倒序拖动也不能留下上一帧的擦除痕迹。纸面及卡片要检查遮挡顺序，粒子要检查轮廓与字幕的距离，方向合并要核对显示值和实际计算值。

这些候选的声音由项目另行编排。本次静态证据不支持原片音效或配乐卡点的听感结论；接入旁白后仍需原速复看与试听。
