# 给连续动作配声音

适用情况：一个对象经历多次变化，动作与音效越加越满，观众却来不及看清结果。

[三方案工作台](../lab/shuffle-rhythm.html) · [原片观察](../studies/shuffle-rhythm.md) · [代码接口](../examples/shuffle-rhythm/API.md)

## 先画出动作阶段

先列“准备、推进、接触、结果可读、下一步”。同一物体可能有很多次微接触，但只有几个叙事落点。声音预算按观众需要辨认的变化分配。

洗牌的“逐张交织”可以是一段连续过程，合拢是一次整体收束；接下来读顺序时，把密集声音退下去。拆装机构也可以这样安排，但金属锁定与纸面摩擦需要不同音色。动作分相可借用，材料不能混用。

## 三种配法先固定画面再比较

| 选择 | 做法 | 适合 | 容易出的问题 |
|---|---|---|---|
| 精选落点 `restrained` | 选关键接触，过程辅以低层运动声 | 有讲解的机制段，结果需要看清 | 选择过少可能失去逐次推进的线索。 |
| 逐个轻触 `dense` | 每个抵达一个短音，降低单次增益 | 短时展示离散密度、计数或多状态 | 声音过密可能遮住弱字；降低峰值不能保证听感不拥挤。 |
| 连续过程 `legato` | 摩擦包络跟随运动速率，少量落定提示 | 连续滑移、展开与分批交接 | 长尾音可能覆盖结果阅读；声音须随动作真正收住。 |

工作台三方案未做感知等响度匹配。切换保持当前时间，只改变声音；先判断配法，再在目标成片里校准音量。不要用“更响”代替“更准确”。

## 同一个事件表驱动声画

每个动作锚点至少有 `id/time/kind/cardId`，音效计划保存 `eventId/start/end/anchorTime`。接触声绑定抵达时刻；运动声覆盖路径的有效区间。尾音结束点必须早于需要干净阅读的窗口。

```js
import {sample, draw, buildPlan, renderAudio} from '../lab/shuffle-rhythm.js';

const plan = buildPlan('restrained');
const state = sample(3.7); // 与从零播放到此处相同
draw(ctx, 3.7, 1600, 900);
const pcm = renderAudio('restrained', 48000);
// plan.cues保留声音起止；pcm与画面都使用绝对时间。
```

这段是示例目录相对路径；在独立工程中改为实际模块路径。浏览器播放用AudioContext时钟推进画面，导出按绝对时间采样。不要在requestAnimationFrame里遇到某个卡片就临时play一次；掉帧和拖动会造成重复触发或漏声。

跨方案切换使用35毫秒短交叉淡化，保留旧时间基准。快速连续切换时，按未来音源启动时刻计算读取位置，不能每切一次都额外给内容时间加35毫秒。暂停、重新定位和离开页面时，旧音源要停止并断开。

## 分别控制密度、能量与尾音

事件数决定声音有多密，增益决定幅度，尾音决定上一动作占用下一时刻多久。三者分别调整。连续运动允许有底层声音，同时减少瞬态；相对低能量也不等于完全静音。

原创示例故意在6.95–8.45秒和16.4–18秒设无音效窗口，用来比较退场效果。实际成片可保留环境声、音乐延音或旁白，窗口长度按阅读任务安排，不直接照搬这两个时长。

解释复杂关系时，字幕和关键术语先获得稳定阅读时间。一个清楚的落点之后让音量释放，比所有对象一起放大、所有声音一起撞击更容易分出层次。语音无需填满每段运动；也不要因为画面停住就切断一句话。

## 迁移前检查

1. 静音看动作，能否辨认每次变化与最终结果；身份和数据是否一直对应。
2. 同画面试听三种配法，比较过程是否连贯、关键接触是否清楚，结果是否留得住。
3. 接入实际旁白与音乐，检查弱字和句尾；仅靠峰值或总响度无法证明听得清。
4. 拖动到运动中途、反向定位、快速切换方案；检查音源是否叠加，画面是否提前。
5. 对导出的音轨检查时长与边界，确认尾音没有伸入预留窗口，再做主观听审。

`scripts/test_shuffle_rhythm.mjs`检查确定性状态、固定牌ID和声音事件契约；`scripts/export_shuffle_rhythm.mjs`导出三套48kHz WAV与JSON并验证PCM。网页也可以单独下载当前方案，导出音量跟随滑块，静音按钮只控制试听。

## 看参考时保留证据边界

先核对音视频的解码PTS。此次AAC首包存在负PTS和Skip Samples，解码后两轨首帧均为0；再平移161毫秒反而会破坏对应。保存原哈希与时间基，不能只看容器时长。

混合音轨的频谱峰可帮助定位复看，不能自动命名为鼓点、纸牌声或音效。画面逐帧边界与信号窗口都有误差，记录区间；不要选一个最近的峰就宣布卡点准确。只有真正试听后才能补音色、对白清晰度和听感结论。
