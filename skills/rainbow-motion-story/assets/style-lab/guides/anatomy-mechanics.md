# 从一个动作解释一套机械结构

打开 [按键机构工作台](../lab/switch-anatomy.html)，先用一个问题确定画面：“按下到哪一步，两触点才接触？”完整按键、移开外壳、触点近景和拆解图都应回答这个问题，使用同一套零件和机构状态。参考方法与源代码阅读边界见 [Anatomy 研究记录](../studies/anatomy-mechanics.md)。

本例是**原创、常开、线性弹性教学机构**，尺寸与参数不对应任何品牌。按压轨迹由程序指定，力是准静态弹性估计；没有真实动力学、触点抖动、迟滞、突跳、摩擦、惯性或电气负载模型。释放动画不能用来推断真实回弹时间，拆开后的触点状态也不代表可工作的电路。

## 先画出因果链，再设计镜头

本例的链条是：键帽与轴心下降 → 斜面推动随动件 → 动触片靠近定触片 → 表面间隙归零 → 后续行程压缩串联弹性件。回位弹簧随轴心下降而缩短。镜头先让观众认出整件，再移开遮挡，最后靠近真正发生接触的位置。

每个读数都从同一状态计算。不要为“按压量”“弹簧长度”“通断指示”分别写三段缓动；否则看起来同步，也可能在临界点互相矛盾。

|职责|本例入口|复用时保留的约束|
|---|---|---|
|机构、接触与单位|[switch-mechanism.js](../lab/modules/switch-mechanism.js)|毫米、牛顿；`+Y` 向上，按压沿 `−Y`；一个位移决定几何与读数|
|外壳、拆解、镜头与绘制|[switch-anatomy.js](../lab/modules/switch-anatomy.js)|显示变换不修改机构；近景继续使用原来的触点实体|
|可中断的操作顺序|[switch-session.js](../lab/modules/switch-session.js)|按压前完成回装，拆解前完成释放；反向操作从当前状态开始|

核心内置动作是有限的 12 秒周期；两套观察分镜均为 18 秒，并显式传入 `press` 覆盖核心周期。接入时先决定由哪一层提供按压量，不要同时运行两个时钟。

## 把接触条件写成可以检查的关系

`press` 的范围为 0–1。默认行程为 4 mm，接触阈值为 2 mm，初始表面间隙为 0.6 mm，因此传动增益为 `0.6 / 2 = 0.3`。若按压行程为 `x`，则：

```text
弹簧长度 = 10 − x                      mm
弹簧压缩量 = 12 − 弹簧长度              mm
触点表面间隙 = max(0, 0.6 − 0.3 × x)   mm
接触后弹性变形 = 0.3 × max(0, x − 2)   mm
```

默认弹簧含 2 mm 预压：未按下时长度为 10 mm、弹簧力为 0.16 N；全行程时长度为 6 mm、弹簧力为 0.48 N。总按压力还包含接触后弹性件折算到轴心的力，不能把触点处的力直接相加；代码按虚功关系乘以传动增益。

`fixedTip` 与 `movingTip` 是两接触面的点，不是球形触点的中心。到阈值时表面接触；继续按下时表面不相互穿过，额外行程由串联弹性件吸收。更换触点形状时，必须一起更新表面位置、几何与间隙计算。弹簧中心线长度保持不变是本例的几何近似，不包含端圈、应力或失稳求解。

## 先确定零件归属，再做拆解

同一零件需要区分静止位置、工作位置和展示偏移：`restPosition`、`operatingPosition`、`displayOffset`。显示位置由工作位置加展示偏移得到；反复拆装始终从原位求值，不能逐次累加位移。

本例将凸轮斜面及支撑归属于轴心，将随动件和串联弹性件归属于动触片；外壳的加强筋与紧固件跟随各自半壳移动。复制到其他机构时，先列出“谁携带谁”，再决定点击选中谁。一个可选部件不一定等于一个运动装配体。

渲染器调用核心时使用 `explode: 0`，随后自行计算展示偏移。不要再把核心的拆解偏移叠加一次。两触片在本例中使用相同的展示偏移，保留它们的相对间隙；拆解量不参与通断判断、弹簧力或按压行程计算。

## 移开遮挡、拆开与回装各有目的

“开壳”移走前／左侧的 L 形实体盖板，保留后／右侧壳壁与厚度。这是为观察设计的两片式教学外壳，不是任意网格的布尔剖切。拆解则沿装配方向分离键帽、轴心、弹簧、外壳与触点组，让观众看清归属；回装沿相同关系返回，然后再演示按压。

两套候选分别强调因果与装配：

- `mechanics-switch-section`：完整按键 → 外壳让开 → 键轴下行 → 触点局部 → 释放 → 回到整体。
- `mechanics-switch-explode`：装配原位 → 外壳让开 → 沿轴拆开 → 部件对应 → 回装按压 → 释放回位。

近景通过连续改变相机目标与正交比例靠近实际触点中点，不替换成另一个放大模型。当前视角限于前左等距观察域；Canvas 使用背面剔除与平均面深度排序，不具备通用深度缓冲。扩展到背面、任意环绕或复杂相交网格时，需要重新检查遮挡，必要时换用具备深度缓冲的渲染器。

## 交互需要明确的先后条件

操作可以随时反向，但机构不能边拆开边按压。`planSwitchTransition` 将请求拆成必要的前置段：拆解状态下请求按压，先使 `explode` 回到 0；按下状态下请求拆解，先使 `press` 回到 0。开壳与靠近触点属于观察控制，可以独立调整。

重定向时先采样旧计划在当前时间的值，再以此为新起点。以下时间单位保持一致；若使用 `performance.now()`，先除以 1000：

```js
import { planSwitchTransition, sampleSwitchTransition, switchControls }
  from './modules/switch-session.js';

const current = plan
  ? sampleSwitchTransition(plan, nowSeconds)
  : switchControls(renderedState);
plan = planSwitchTransition(current, { press: 1 }, nowSeconds);
// 每帧重新采样，并把结果作为 sampleSwitchAnatomy 的显示/按压选项。
```

这样可保持反复点击时的位置连续；它不承诺真实速度、加速度或动量连续。缓动用于操作反馈，不能解释为机构动力学。减弱动态模式可跳过过渡时长，仍应落到满足装配条件的最终状态。

## 导出与验收要能复现同一画面

导出应先固定一次状态快照：分镜变体、采样时间、按压、开壳、拆解、聚焦、视角、标注以及实际使用的相机。保留机构参数与单位。若需要重放交互过程，还要记录请求时间与过渡计划；只保存最终滑杆值不能还原之前的操作轨迹。PNG 对应这一快照，不能在异步保存完成时重新取另一个“当前值”。

视频按绝对时间逐帧采样，不依赖浏览器上一帧运行了多久。18 秒、30 fps 是 540 个视频帧；可另保存 `t=18` 的终点状态用于检查，但不要将它追加成多余的视频帧。

以下是接入或修改后的验收要求，**不是本指南宣称已通过的结果**：

- 检查未按下、全行程、阈值前后与阈值本身：读数一致，接触面不穿透，弹簧始终高于并圈长度。
- 固定 `press` 后改变开壳和拆解量，确认物理间隙、力与通断不变；所有附属件跟随正确的装配体。
- 在回装中请求拆解、释放中请求按压，并快速反复切换；检查位置连续和操作先后条件，不能只测两个端点。
- 检查默认分镜、最大拆解、触点近景和允许视角边界；实际打开图像查看遮挡、画幅、标签与细小间隙。
- 用同一快照重复采样，核对导出数据与画面；检查暂停、继续、拖动时间以及末帧。静态帧检查不能替代完整视频播放或音轨审听。

Anatomy 中可借鉴的是共享状态、部件与承载装配体分离、世界空间拆解方向，以及中途反向和实际图像检查。它的墙钟循环、状态式弹簧积分和个别引擎示例参数不能直接移入本项目的绝对时间采样器。源代码中写有审计结果，也不等于本项目执行过该审计；复制第三方代码时另行保留其 MIT 许可声明。

## 可复制的制作任务书

```text
制作一个原创常开按键的 18 秒交互教学演示，回答“按下到哪一步，两触点才接触？”

交付：机构采样模块、实体渲染模块、可中断交互控制器、独立工作台、状态导出说明，以及注明范围的验收记录。

因果与模型：毫米/牛顿，+Y 向上；一份按压状态同时驱动键帽、轴心、回位弹簧、凸轮/随动件、触点几何与读数。默认行程 4 mm、接触阈值 2 mm、初始表面间隙 0.6 mm。明确为原创线性准静态教学模型，不对应品牌，不宣称真实动力学或电气性能。

装配与画面：先展示完整轮廓，再移开有厚度的半壳；按压后连续靠近原来的触点。另一套分镜展示轴向拆解、部件对应、回装与按压。工作位置与展示偏移分开，附属件跟随所属装配体，拆解不改物理状态。

交互：支持按压/释放、开壳、拆解/回装、聚焦和有限视角调整。按压前完成回装，拆解前完成释放；新请求从旧计划的当前采样值开始。支持减弱动态，不使用每帧累积变换。

复现与检查：按绝对时间渲染；冻结快照后导出 PNG/JSON。检查阈值前后、接触表面、弹簧长度、装配归属、快速反向、近景和视角边界。打开生成图片作视觉检查；分别记录源码阅读、数值检查、浏览器操作、静态图像与完整视频/音频检查的实际完成范围。
```
