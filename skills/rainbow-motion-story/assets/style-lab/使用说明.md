# 镜头与节奏方法库

这是独立的研究和代码库。基础六模块提供58个原创候选，后续研究以专题工作台继续扩展；示例使用几何、转子、晶格、纸牌、机构和界面，不依赖某一期视频。

在本目录运行 `python serve.py`，打开 http://localhost:8000/ 。也可双击 `打开方法库.cmd`。网页使用浏览器原生 Canvas 和 Web Audio，不需要安装 node_modules，不请求外部模型。

## 选用一个方法

新增 [线与界面工作台](lab/ui-line-studio.html)：研究 MAX 的 UI 连续动效与沁雨莲的线稿表达，提供两种 UI 交接及黑场雕刻、纸白机构拆装，共四个原创短段。可以播放、逐帧、阶段定位、导出选用说明与 PNG；[UI 指南](guides/ui-continuity.md)和[线稿指南](guides/linework-language.md)说明怎么接入工程。两条来源合计255个唯一源帧的联系表观察，完整连续主观观看和声音听审尚未完成；具体范围见逐段研究。

左侧选择模块，中间点击候选。播放或拖动时间条查看完整动作，左右箭头逐帧检查。阶段按钮用于快速定位，具体动作时间以候选代码中的状态函数为准。

「并排比较」允许选任意两个候选，按各自总时长的相同比例对照。右侧可调整动作幅度和三种配色，加入选用清单后保留这些参数。「导出选用清单」可下载 JSON 或复制制作指令；刷新后保留选择。它不会自动修改视频工程。

「8 条参考研究」内可以看密集联系表、阅读逐条拆解，或重播本地原片研究窗口。原片仍在原研究目录中；本库只按需读取，不复制视频。复制本库到别的电脑后，原创候选仍可运行；原片复看需要 `python serve.py --references 原参考根目录`。

## 六个模块怎么选

| 需要解决的问题 | 模块 | 先看什么 |
|---|---|---|
| 开场没兴趣，解释像目录 | 编排与悬念 | 失败或反直觉结果、因果接力、局部到整体 |
| 动作太满，音乐抢话 | 音乐与呼吸 | 乐句留白、预让位、动作落点、快变后的停留 |
| 镜头只会绕 Y 轴 | 运镜与景深 | 三轴视差、过前景、焦点交接、稳定观察位 |
| 拆开之后看不懂 | 机构与拆解 | 装配轴、对应位置、剖面、回装顺序 |
| 公式像贴上去的字幕 | 公式与可视化 | 实体量到符号、逐项进入、粒子到关系、局部到网格 |
| 颜色和效果越堆越乱 | 材质与视觉 | 明暗层次、有限配色、轮廓接力、曝光采样 |

这些候选是方法演示，演示中的物理轨迹和几何不冒充真实设备或计算结果。用于科普时，实体运动和数据必须接入自己的解算结果；时间包络只决定何时展示。

[查看离线渲染样片](examples/video/index.html)：原创方法视频及六段12秒特种运镜样例，可对照交互候选。

## 代码接口

顶部「速率曲线」打开 [同画面对照工作台](lab/rate-curves.html)。12种动作安排可用于物体、文字和透视推进对照；调整时长、距离与实际曲线参数，看位置/速度/加速度及等时间间隔点。可以暂停、逐帧定位、导出JSON和接入代码。弹簧尾巴继续计算，不在参考时长处硬截；[选择指南](guides/rate-curves.md)说明每种安排的表达与误用，[API](examples/rate-curves/API.md)提供Bezier反解、速率积分与弧长查表。

每个模块都是 ES module，公共函数在 `lab/modules/common.js`，候选入口在 `lab/modules/index.js`。引用模块文件时，一并保留它的依赖文件。代码面板可以直接查看和下载当前模块。

```js
import {candidates} from './modules/index.js';
const shot = candidates.find(item => item.id === selectedId);
const options = {intensity: 0.7, palette: 'titanium'};
const seconds = frame / fps;
shot.draw(canvas.getContext('2d'), seconds, width, height, options);
const state = shot.sample(seconds, options);
```

`sample` 与 `draw` 以绝对时间求值。相同时间、参数与尺寸得到相同画面，倒序定位不依赖上一帧。候选的 `referenceIds` 追溯研究来源，`usage`、`recipe`、`stages` 说明如何安排动作。

在 Remotion 中用 `useCurrentFrame()/fps` 传时间；在 Three.js 中把 `sample` 的位置、旋转、焦点和拆解进度映射到真实节点。Canvas 的投影与材质是原创表现代码，不能称为路径追踪或真实流体求解。

[原创音乐与让位 A/B 试听](examples/audio/index.html) 提供直接切换/交叉淡化、无遮盖保护/预让位四个合成样例。

顶部「音效时机」打开 [声音工作台](lab/sound-design.html)。同一画面可以切换同步/延迟、堆满/精选、长尾/短尾、固定/随速度变化、占满/给讲解让位五组 A/B，并调节时间偏移与音量。点击后才播放音频，可导出声音计划 JSON 和原创 WAV。静音查看、定位到声音中途、切换后继续比较均使用同一时间线。源文件是 `lab/sound-design.js`；[音效指南](guides/sound-design.md)解释何时使用和何时留白。

音效示例使用原创合成，包含木质/金属接触、气流、确认、伺服、低频冲击和环境底等八类声音。可选占位声不说话，只用于显示能量与时间占用；检验旁白是否清楚时需要替换为真实讲解并复听。生产用 [音效表样例](examples/sound-design/production-cue-sheet.json)把来源许可、画面锚点和保护窗口放在一起。

### MOFs 文案：操作带着解释往前走

[文案工作台](lab/mofs-writing.html)把同一套孔隙示意做成三种38秒原创开场：先看结果、先搭结构、先做预测。12秒后共用解释链，观察节点、配体、孔隙，再区分通过孔口与内表面停留。三项均在主库「编排与悬念」，可以像其他候选一样加入选用清单。

### 转子机构：控制变化，保留运动身份

[机构工作台](lab/rotary-interaction.html)提供两种18秒原创示例：[打开观察口](lab/#mechanics-rotary-section)与[沿轴拆解](lab/#mechanics-rotary-explode)。两项加入「机构与拆解」，该模块从5项增至7项，全库58项。切换候选保留观察时刻和转速事件；可逐帧定位、调整切开与拆离进度、拖动机位、冻结或恢复机构，导出当前PNG及30fps状态JSON。

转速调整从当前时刻生效并保留当前轴角；在更早时间修改会替换后续转速方案。冻结期间仍可观察结构，恢复速度来自该时刻之前的运行历史。JSON包含541个状态点（含18秒端点），正式18秒/30fps渲染使用0–539帧。

[交互研究](studies/rotary-interaction.md)保留四张实际查看的联系表（含90个密集采样）及三段额外1×静音播放：0–11.966667、121–127.966667、144–149.966667秒。播放配有终点截图，不代表全片逐帧审阅；参考音轨未实听。旧观察仍在[初次记录](studies/rotary-cutaway.md)。[复用指南](guides/rotary-interaction.md)与[运动学核对](studies/rotary-kinematics.md)说明理想单转子、3:1相位关系和适用边界；样例不计算原片功率，也不冒充马自达生产模型。

来源固定于LemoLab仓库提交 `3961ddb3d24d8876e0e2754f7790d66908acee51`。全部157项均有中文分析，157张来源缩略帧已观察；原片完整播放和主观听审仍为0。详细阅读范围保留在各项verification，关键源码阅读不等于整套上游实现已运行。原创试作按绝对时间求状态，没有复制原影片、角色、音乐或声音。正式创作继续使用用户的TTS、音乐和共享依赖。
