# 象牙线稿机构：有限几何与真实投影

本模块是原创风格试作，借鉴已查看的沁雨莲参考联系表中“深色背景、象牙实体面、表面等高/排线、少量金色强调”的层次。它不复刻原片的 AI 工厂、人物、文字或商标。本次读取的是 `evidence/qinyulian-linework/overview-01.jpg` 至 `overview-03.jpg` 的三秒采样静帧；不能据此声称完整连续观看或听审。

## 接口

```js
import {candidates,sample,draw} from './lab/modules/engraved-mechanism.js';
const state=sample(6.3,{id:'engraved-flow-path'});
draw(ctx,6.3,1600,900,{id:'engraved-flow-path'});
// 另一候选：engraved-orthographic-assembly
```

| ID | 时长 | 动作与观察窗口 |
|---|---:|---|
| `engraved-flow-path` | 14秒 | 轮廓→排线→流路→开盖→回装；12.7秒后机位停稳，流路退场，供整体阅读 |
| `engraved-orthographic-assembly` | 15秒 | 0–2.5秒结构；2.7–4.8秒排线；5.3–7.1秒开盖；8.25–10秒回装；10–14.1秒拉远；最后稳定 |

`candidates` 包含 `{id,title,description,duration}`。`sample` 返回 `phase`、`parts`、`faces`、`camera`、`drawProgress`、`hatchProgress`、`dimsProgress`、`flow`、`particles`、`callout`、`readWindow` 和 `occlusion`。时间为秒，负数和超尾时刻夹紧；非法 ID 或非有限时间会抛错。返回对象可直接用于研究和采样，状态不依赖前一帧。

`parts` 的25个 ID 在两种候选和全部时刻保持一致。机盖与入口管是同一可拆卸组件组；它们沿安装轴移动，泵壳、支座和电机保留原位置。体积由箱体与圆柱的实体面、统一光向和相机投影给出，不是只画一层透视线框。

## 线条和遮挡约定

- 实体面使用背面剔除与按相机深度从远到近绘制。轮廓强，面间结构弱，尺寸线另有细层级；隐藏线默认关闭。
- 叶轮不能仅靠平均深度排序：大盖板的中心深度会让后画的叶片错误穿到盖板前。本例对叶轮面另外计算壳体、盖板、入口管的几何遮挡。只有叶轮面的全部顶点位于遮挡面背面时，才把该遮挡面的真实投影加入裁切；填充、排线和轮廓一同裁掉被挡住的像素。开盖后只显露投影中真正露出的部分，壳体继续遮住其余部分。未按时间或开盖进度直接隐藏叶轮。
- 盖板螺栓标记属于盖板面的绘制过程，使用面内圆的投影；前景实体仍可遮挡它们，不在所有几何画完后叠加屏幕圆点。
- 排线在每个面的局部坐标生成，随实体和相机移动；绘制时还使用该面投影多边形裁切，防止越过轮廓。
- 线距低于约1.7屏幕像素时不画，1.7–5像素平滑衰减。拉远时不会把密线硬塞成摩尔纹。这个门限是本试作的候选值，生产输出仍需复看。
- 轮廓和路线采用 `revealPath(points,progress)` 按实际折线弧长截取，不按点的数量均分时间。多段独立线之间没有抬笔连线。
- 纸纹固定种子、低对比、低频；无逐帧随机。这里的纸张是固定画布上的背景，未模拟可弯曲纸张或 UV 展开。
- 金色仅用于显式的剖面流向覆盖层和示意粒子；路线采用虚线，旁边写“流向示意”。它不表示真实速度、压力、质量流率或 CFD 结果。

## 实现边界

这是有限、手工布置的几何2.5D预演。相机进行真实透视/正交数学投影，外部渲染采用凸面平均深度排序，叶轮额外使用由前后平面关系确定的投影遮挡裁切；**这不是通用 Z-buffer，也不能保证任意相交网格的遮挡正确**。几何适用于当前固定相机范围，不能直接换任意视角后认领完整3D渲染器。有限样例使用的表面填充与影调不称光追。

转子叶片是原创示意结构，转动由时间函数驱动，没有求解转矩、叶片受力、流场或真实泵性能。机盖开合为解释动作，不能当作运行中的实际泵可以拆开。产品型号与工程尺寸未标注；尺寸线只表明相对构造，原片技术名词不进入本例。

要接入正式三维影片，保留部件 ID、局部排线和绘制顺序，使用正式渲染器深度、材质、碰撞与单位；读数从工程实际计算源取值。关闭流向层也不影响装配关系。

## 检查

运行 `node scripts/test_engraved_mechanism.mjs`。测试覆盖有限投影、近裁面、背面剔除、远近排序、部件身份、任意 seek、回装端点、排线密度、结构先于排线以及按弧长揭示。遮挡回归在闭合画面采样叶轮面，验证全部被壳体/盖板遮住；开盖时同时验证有露出部分和仍被遮住的部分。标注改为进水管上方留白中的“沿轴开盖”，短引线指向机盖，避免字压住联轴器。

脚本检查对应状态与渲染约定，不能替代真实 Canvas 绘制、连续观看、任意视角碰撞检查或成片美感验收。本模块静音，没有推断原片配乐或音效。
