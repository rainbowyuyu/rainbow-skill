# syy 参考片：声音节奏的可核对测量

本页研究 [宇宙编辑客｜syy 的参考片](https://www.douyin.com/video/7699491920908651785)，对应短链 `https://v.douyin.com/nOxHUvQmW38/`。分析的是公开播放器提供的独立视频轨与独立 AAC 混合音轨。以下是信号测量和由此提出的复核问题；没有进行主观听审，不能据此认定某一个峰值是鼓点、转场音效或旁白重音。

## 先把时间对齐

| 项目 | 实测 |
|---|---:|
| 视频 | HEVC，1280 × 720，30 fps |
| 第一张解码视频帧 PTS | 0.033008 s |
| 第一包压缩音频 PTS | −0.161134 s |
| 第一包 Skip Samples | 7106 samples |
| 第一段解码音频 PTS | 0 s |
| 解码采样率 | 44100 Hz，双声道 |
| 每声道解码样本数 | 7,326,782 |
| 解码音频时长 | 166.140181 s |
| 以第一张视频帧为零点时的音频起点 | −0.033008 s |

解码器已经处理 AAC 的 Skip Samples。不能看到第一包的 −161 ms 就再把音频挪动一次。逐个解码音频帧核对 PTS，未发现超过两采样点容差的间断；ffprobe 的样本总数和 ffmpeg 实际 PCM 样本数一致。

本页所有分析图和事件时刻都采用：

```text
分析时刻 = 音频采样点 / 44100 + 音频第一解码 PTS − 视频第一解码 PTS
         = 音频采样点 / 44100 − 0.033008
```

如果视觉标注采用源文件绝对 PTS，先减去 `0.033008` 再与本页比较。不要把浏览器显示时刻、文件包时刻和归零后的逐帧时刻混用。

## 可测到的节奏层次

全片能量、频谱变化和频段能量（外部或本机资源，未随公开包收录）

采用左右声道功率平均，避免先转单声道时相位抵消。全片立体声 RMS 为 −15.33 dBFS；单声道下混结果为 −15.34 dBFS。这里两者相近，只说明本素材的整体下混能量损失很小，不代表所有素材都可以先转单声道。

64 ms 的 STFT 窗、10 ms 的步长下，计算正向对数频谱变化，再以全片统一阈值提取候选。80 分位阈值获得 **659 个混轨瞬态候选**；75、90 分位分别为 671、610 个。候选数量随阈值变化，不能把 659 当成音效数量，也不应把候选全部变成切镜点。每个候选时间指后一个分析窗的中心，不是精确声学起音。

对候选的底层 flux 序列计算自相关，最强几个重复间隔为：

| 重复间隔 | 换算周期数/分钟 | 归一化自相关 |
|---|---:|---:|
| 0.94 s | 63.83 | 0.8732 |
| 0.47 s | 127.66 | 0.7109 |
| 1.41 s | 42.55 | 0.6843 |
| 0.70 s | 85.71 | 0.5645 |
| 1.17 s | 51.28 | 0.5575 |

0.47、0.94、1.41 s 呈约一、二、三倍关系，在多数 12 秒窗口内都能复现。它支持“有持续的周期骨架”这个判断，但不唯一确定音乐拍速、拍号、重拍或小节边界。本次搜索间隔限定为 0.25–1.5 s，因此更短的细分周期没有被这一表格评估。若原创例子选择 128 BPM，应明确它是原创编排参数，不写成原片已测准的 BPM。

开头较强候选出现在 **0.579、1.049、1.499、1.989、2.439、2.919、3.379 s**。这些位置适合让观看者逐个核对：声音变化之前是否有蓄势、当时是落位还是变形、之后是否保留阅读时间。不能只看最接近的几帧就宣称全片逐拍同步。

## “呼吸”不是必须静音

| 视频归零窗口 | 候选数 | 100 ms RMS 中位数 |
|---|---:|---:|
| 0–12 s | 36 | −16.27 dBFS |
| 24–36 s | 52 | −15.38 dBFS |
| 84–96 s | 52 | −15.01 dBFS |
| 96–108 s | 50 | −16.60 dBFS |
| 108–120 s | 51 | −19.23 dBFS |
| 120–132 s | 39 | −18.78 dBFS |
| 132–144 s | 45 | −15.71 dBFS |
| 144–156 s | 52 | −15.88 dBFS |

108–120 s 的整体能量比 84–96 s 低约 4.22 dB，但检测到的候选数几乎相同。**声音的能量、瞬态疏密、画面的动作幅度可以分开控制。** 这是一条由测量启发的原创编排方法：解释段可以保留节奏脉冲，同时缩小动作幅度、降低视觉对比或减少同时出现的对象。是否正是原作者的主观做法，还要结合连续画面和听审确认。

本次以 10 ms RMS 小于 −45 dBFS、持续至少 250 ms 为绝对低能量窗，结果为 0 个；这不等于“全片没有停顿”。以 100 ms RMS 的全片下四分位 −19.70 dBFS 为相对阈值、持续至少 300 ms，可找到 23 段。较有代表性的窗口：

- 43.767–44.167 s：0.4 s。
- 102.767–103.467 s：0.7 s。
- 112.667–113.267 s：0.6 s。
- 117.467–118.167 s：0.7 s。
- 125.967–126.667 s：0.7 s。
- 162.567–163.467 s：0.9 s。

这些是相对低能量区间，不是旁白休止或无音乐区间。完整区间在 `timeline.json`，应与视觉事件表对照后再决定怎样用于原创创作。

## 用来指导实际复核的窗口

1. **0–12 s：** 检查稳定周期之上哪些动作真的落在强候选，哪些延迟到结果可读时才结束；避免把持续运动误看成连续硬切。
2. **24–36 s：** 29.169、29.879、30.109、30.809 s 有较大频谱变化。检查附近是否伴随镜头、文字或对象身份的明显交接。
3. **96–108 s：** 103.469、103.939、104.169、104.879 s 的候选较强，与后面的低能量窗口相邻，适合核对强弱转换。
4. **108–132 s：** 比较能量较低但重复瞬态仍在的段落；关注阅读任务与连续运动是否因此更清晰。
5. **132–144 s：** 检查能量恢复时的画面幅度和对象数量如何变化。

29.169/104.169 s 和 29.879/104.879 s 各相差 75 s，值得进一步检查音乐结构是否重复；仅凭两组峰值不认定它们是同一音效或音乐循环。

混合音轨频谱（外部或本机资源，未随公开包收录）

频谱图与四个频段（40–250、250–1000、1000–4000、4000–7900 Hz）描述频率能量，没有分离出音乐、人声或音效。谱图颜色是相对 STFT 功率，不是响度或人声可懂度。PCM 峰值约 1.0408；压缩音频解码后的重建过冲可能高于 1，不能据此断言源混音削波。没有进行 LUFS、真峰值或对白遮蔽听审。
