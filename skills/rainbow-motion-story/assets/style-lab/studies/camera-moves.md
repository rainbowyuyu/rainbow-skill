# 从穿梭到定格：六种有明确观察任务的运镜

以下六个ID现已在工作台实现为12秒候选。下文10秒时间表是推导阶段的可调整配方，不是代码实际时间码；实际阶段以各候选的stageTimes为准。轨迹、时间、配色和动作幅度是本库的原创设计建议，不是从原视频反求出的摄影机参数。

## 来源能支持什么

| 来源 | 已核实的文字内容 | 用在这里的范围 |

| [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html) | `fov`为垂直视场角；`getEffectiveFOV()`考虑zoom；修改投影属性后须更新投影矩阵 | 明确FOV口径，制作移动与变焦联动；`focus`属性本身不会让普通渲染自动出现景深 |
| [Curve](https://threejs.org/docs/pages/Curve.html)、[CatmullRomCurve3](https://threejs.org/docs/pages/CatmullRomCurve3.html) | `getPointAt/getTangentAt`按弧长参数采样；曲线变化后更新弧长缓存；Catmull-Rom支持centripetal等类型 | 先设计路径，再按路程安排快慢；不把样条参数均匀变化误当匀速飞行 |
| [Quaternion](https://threejs.org/docs/pages/Quaternion.html) | 需要归一化；提供四元数球面线性插值 | 过顶俯冲、视角交接和回到第一人称时保持朝向连续 |
| [PointerLockControls](https://threejs.org/docs/pages/PointerLockControls.html) | 面向第一人称交互；`moveForward`平行XZ平面且假定Y向上 | 区分人的视角和自由飞行；它是交互工具，不是离线视频的时间线求值器 |
| [DJI Avata 2官方参数](https://www.dji.com/cn/avata-2/specs) | 单轴机械云台为俯仰轴；有RockSteady、HorizonSteady电子增稳选项 | 说明FPV的机身倾侧和画面地平线稳定是可分开的选择；不能声称所有FPV镜头都必须翻滚 |
| [ASC：The Matrix: Welcome to the Machine](https://theasc.com/articles/flashback-the-matrix) | 创作者希望场景极慢动作而摄影机表观保持正常速度；正文及图片说明提到Bullet Time相机阵列 | 支持将场景时间与观察视角时间分开；不从文章推出本库镜头是实际相机阵列拍摄 |
| [StudioBinder：Dolly Zoom](https://www.studiobinder.com/blog/best-dolly-zoom-vertigo-effect/) | 摄影机靠近/远离主体，同时反向改变变焦，制造空间伸缩感 | 希区柯克变焦必须同时移动与变焦，不能只拉FOV |
| [Bullet time](https://en.wikipedia.org/wiki/Bullet_time)、[Dolly zoom](https://en.wikipedia.org/wiki/Dolly_zoom) | 二级资料解释相机阵列同时/顺序触发，以及保持主体画面尺寸的推拉变焦 | 作为技术定义补充；电影史与器材数量没有作为本库验收参数 |

DJI所列155°镜头视角没有在该条参数里说明与Three.js垂直FOV一一对应，因此不直接把155填入渲染器。下面FOV是16:9针孔演示的自定垂直角度，不是复制真实镜头标定。

## 共用的镜头契约

状态接口建议为 `sampleCamera(t) -> {position, quaternion, target, fovY, focusDistance, worldTime, phase, anchorIn, anchorOut}`。相机位姿与世界运动分别由绝对时间求值；不使用每帧累加的 `lerp` 作为最终导出轨迹。

用五次缓动 `S(u)=6u⁵−15u⁴+10u³`（u夹到0–1）处理静止到静止的阶段，端点速度和加速度为零。需要连续飞过的接点，应给相邻段相同的端点速度，而不是每个路径控制点都停一下。`getPointAt(s/L)`给位置，`getTangentAt(s/L)`给切线；弧长表是离散近似，要用更密采样复核高速和急转处。

前视锚点取路径前方一段路程，不能只盯无限远：`target = C(min(s+lookAhead,L))`。路径尽头改用预先保存的出镜目标，避免position与target重合。需要向下经过竖直方向时，固定世界up会退化；采用预计算的连续姿态或平行运输参考框架，并让四元数符号连续，再做插值。该处理是摄影机几何，不是飞行动力学证明。

## 1. `camera-fpv-slalom`：穿过结构，最后读懂一个接口

**画面任务：** 先让观众感觉空间足够大，再把它带到一个可解释的机械接口。近处门框提供速度，远处主件提供稳定方向。与普通环绕相比，轨迹真正穿过前后遮挡和左右间隙。

**原创10秒节奏：** 0–1秒认出第一道门；1–6秒依次左、右、左穿行；6–8秒从门框掠过抵达转子；8–10秒收横滚、停在侧前方观察位。示意控制点可用 `[(0,2,14),(2,2.7,9),(-2,1.8,4),(2,3,-1),(0,2,-6)]`，单位随真实模型缩放。门洞位置必须由同一路径布置并验碰撞，不先摆一排门再强行穿过去。

**姿态：** 用前视切线定朝向。倾侧与转弯方向关联，可从水平投影的有符号曲率κ设计 `roll=clamp(atan(v²κ/g),±18°)`，再在解释位平滑归零。这只是类似协调转弯的视觉启发；真实多旋翼还需推力、阻力和控制器计算。水平投影接近零时不使用该曲率式。垂直FOV约62–72°，首尾不突然改变。

**变化方案：** 工程白模+琥珀接口突出结构；黑色走廊+少量青色引导灯突出速度；户外桁架+暖侧光突出空气纵深。以近物视差制造快感，避免叠加不相关的随机抖动。强度较低版减少侧移和roll，保留穿门关系。

## 2. `camera-fpv-dive`：越过顶部，贴侧面俯冲，再拉平

**画面任务：** 展示物体的高度和纵向结构，从全貌进入内部的一个层级。与slalom不同，主变化是高差和俯仰，左右蛇形不占主导。

**原创10秒节奏：** 0–1.5秒顶端建立位置；1.5–3秒越过顶部并压低视线；3–6秒沿建筑/机构外侧下降；6–8秒沿有半径的弧线拉平；8–10秒停在剖面观察位。可用高度从10降到1.8的侧面路径，保持距外壁的固定下限；路径底部不做尖折角。

**姿态与限制：** 摄影机方向跟随路径前视点，但以四元数跨过陡俯角；不要在90°附近硬换up。拉平弧线半径越小、速度越高，所需向心加速度 `v²/r` 越大。需要称为真实无人机飞行时，应给可验证速度和加速度；这里只把它作为镜头设计。近裁切面、门框和天空都要纳入相机扫掠包络。FOV约68°，roll只作10°以内的侧倾，避免俯冲同时叠满360°翻滚。

**变化方案：** 沿塔身外侧俯冲看楼层；沿透明容器外侧下潜看液层；从机械外壳顶部落到剖开腔体。入水或穿壳需要真正的介质/剖切事件，不能只让相机穿过不透明面。

## 3. `camera-first-person`：站在物体身边，用视线完成解释

**画面任务：** 让观众知道“我在这里，看见那个动作”。这不是FPV换一个名字：机位受角色/载体约束，观察方向可以与前进方向不同，近处手持物或机体边缘提供身体参照。

**原创10秒节奏：** 0–2秒从约1.65米眼高建立走廊；2–5秒前进并看向侧边机构；5–7秒停步看清一次转动；7–10秒视线回到前方，走向下个观察点。若是机器人视角，眼高取模型传感器节点，不固定套成人高度。

**实现：** `position=actorWorldTransform*eyeLocal`；朝向由载体朝向与眼部观察旋转组合。步行的微小上下运动用已保存的步态相位，静止时幅度归零；脚步频率和前进速度相关，不能全程无目的摇晃。默认roll为0，FOV约55–65°。离线录制可借PointerLockControls寻找机位，但必须把选择转换为保存的关键帧/轨迹；最终成片不读用户鼠标或实时状态。

**变化方案：** 行走、坐在载具内、跟随机械臂末端三种载体。三者应有不同的高度、视线约束和近景参照，不能只是背景换色。近景HUD避开需要观察的接触点，旁白重点时关闭步态起伏。

## 4. `camera-soul-drift`：第一人称离体，绕看自身，再回到原位

“灵魂漂移/离体”不是本研究核实过的标准电影术语。这里明确把它定义为一段原创的 **POV→离体→第三人称弧移→回到POV**。技术依据是刚体变换、样条轨迹、四元数插值与连续锚点，不借用不存在的权威分类。

**画面任务：** 原来只能看见手里的装置，离体后发现操作者、装置和环境的完整关系；回到身体后继续操作。与bullet time不同，世界默认继续运动，改变的是观看位置。

**原创10秒节奏：** 0–1.5秒建立POV；1.5–2.5秒从肩侧斜上方迅速退出；2.5–5.5秒绕过身体约120–180°；5.5–8秒返回肩侧入口；8–10秒准确对齐眼部锚点并继续POV。出口走肩侧空隙，不从可见面部或头壳中央穿出去。离体时先让近处身体边缘经过视野，给空间转换一个解释。

**实现：** 开始记录眼部世界位姿 `P0,Q0`，路径中间点相对同一个角色锚点；返回时取该时刻角色眼部位姿 `P1,Q1`，而非把镜头送回早已过期的P0。角色移动时可在角色局部空间设计偏移，再经它的世界变换映射；镜头切换两种跟随方式时匹配速度。quat采用最短路径插值，但需要大于180°的绕行时须插入中间关键帧，不能期望一次slerp保留整圈意图。

**变化方案：** 冷静的检查版只抬高1米、绕120°；高潮版快速退出后绕180°并短停；微观版从机器人传感器退到完整机体。画面自身的速度变化承担效果，不用白闪或鬼影掩盖位姿跳变。

## 5. `camera-bullet-time`：世界慢下来，观察者继续转

**画面任务：** 在接触、液滴飞散或机构即将啮合的一刻，让观众从另一侧看清几何关系。ASC资料支持的关键是相机运动与场景时间分离；本库用虚拟镜头实现，不声称实际使用多相机拍摄。

**两个时钟：** 成片时间为t，相机路径依t推进，世界状态依τ(t)求值。不能把导出帧率降低后把全片一起放慢，那会把镜头也拖慢。

一种原创10秒映射：0–2秒 `dτ/dt=1`；2–3秒从1降到0；3–7秒世界冻结；7–8秒从0升到1；8–10秒恢复正常。令 `I(u)=u⁶−3u⁵+2.5u⁴`，它是S的积分，则：

```text
τ(t) = t                              0 ≤ t < 2
       2 + u - I(u), u=t-2            2 ≤ t < 3
       2.5                            3 ≤ t < 7
       2.5 + I(u), u=t-7              7 ≤ t < 8
       3 + (t-8)                      8 ≤ t ≤ 10
```

该τ单调且速率平滑接上，10秒画面对应5秒世界运动。相机可在3–7秒围绕冲击点走140°弧线并略抬升，首尾切线对齐原跟随方向。完全冻结版、0.05倍慢流版和局部机制慢放版是不同选择；局部冻结若违背周围物理运动，必须明确为讲解隔离。

**容易漏掉的东西：** 粒子、布料、骨骼、灯光动画和阴影中的施影物都应取同一个τ；贴图噪声不能偷读t，否则冻结时仍在沸腾。镜头变化产生的反射/高光视角变化仍然合理。景深和运动模糊每个子样本都要分别计算相机t与世界τ(t)，不要在世界停住后保留上一帧的飞行拖尾。可同时显示“世界速率”和“观察视角”，比贴“子弹时间”标题更能解释效果。

## 6. `camera-hitchcock-zoom`：主体不动大小，背景骤然打开

**画面任务：** 显示“熟悉的物体，背后竟有这么大的空间”。已有 `camera-dolly-zoom` 是克制的循环对照；新候选应做明确的强空间揭示，而不是复制同一动作再改颜色。可用近处静止人物/机器人、后方重复门框和更远的城市构成三层。

**公式：** 对垂直光轴的目标平面，目标屏幕高度正比于 `H/[d*tan(fovY/2)]`。保持主体大小应保持 **`d*tan(fovY/2)=K`**，不是 `d/tan(fovY/2)`。固定zoom=1时 `fovY(t)=2*atan(K/d(t))`。若使用camera.zoom，必须按有效FOV计算，不能重复应用缩放。距离d是目标沿观察轴的深度；主体有大幅旋转或很厚时，要验证投影包围盒，不能只锁住一个中心点。

**原创10秒节奏：** 0–1秒主体建立；1–6秒相机由距离12推进到5.5，同时垂直FOV从28°增至约57°；6–8秒停留看背景被打开；8–10秒按接下来镜头的目标离开，或另做明确回收段。目标全程居中，roll保持0，避免把空间伸缩与横滚混到无法辨认。

**变化方案：** 推近+广角让背景向外展开；拉远+长焦让远景压近；侧置主体用投影约束维持其屏幕锚点。不能把真实距离变化说成建筑被缩放；这是一种透视与取景协同效果。主角旁边的文字独立排版，不能随着FOV涨缩得无法阅读。

## 接入制作与验收

1. 先决定观察问题，再选择候选；同一机制不同时叠FPV、离体、冻结和推拉变焦。可以让一次穿梭抵达明确锚点，下一段在那个锚点用bullet time读机制。
2. 每条轨迹记录版本、单位、anchorIn/anchorOut、位置与朝向、FOV和世界时钟。有限镜头并不自动循环；如果工作台循环播放，需做真正闭合路径或注明预览重播边界，不能将末帧瞬移包装成无缝接力。
3. Three.js中位置映射到position、姿态映射到归一化quaternion；FOV变化后更新projectionMatrix。景深需要实际渲染通道，单改camera.focus不等于完成光学散焦。Blender中保持同一投影口径、传感器尺寸和位姿采样。
4. 先用简化碰撞包围体计算镜头的扫掠净距，再查门洞、地面、头部、剖切盖面与近裁切面。大幅俯冲和近景掠过应查看至少前后各0.5秒的密集邻帧及原速，不只挑漂亮静帧。
5. Dolly zoom验目标投影高度；bullet time验τ单调与冻结期间世界状态恒定；离体验入场与回到POV的位姿/速度；FPV验前视点不退化和横滚回收。数据正确与观感检查分开记录。
6. 先保留稳定地平线、少量FOV变化和一个明确注视点，观众不舒服时降低角速度、侧向幅度和头部摆动。这些是设计上的舒适度选择，不是医疗或所有观看设备通用的安全阈值。

实现与技术验收记录在 qa/camera-expansion.json、qa/camera-adapter.json、qa/camera-time-invariants.json 及飞行模块的检查报告；样例的真实播放、静帧和数值验证分别记录，不相互代替。
