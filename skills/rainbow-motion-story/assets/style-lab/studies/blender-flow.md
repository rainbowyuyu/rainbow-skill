# 流水建模：先让水走得通，再让光把水照清楚

研究对象为柳疯衫·awa的[《Blend建模动画分享一流水》](https://v.douyin.com/85SXSqesAFI/)，[原页](https://www.douyin.com/video/7699790483135972799)。实测片长 **8.336 秒**，1280×720、24 fps、200 帧；分享文字中的“7.48”不是视频时长。

本次从浏览器实际加载的公开视频取得研究副本，每四帧抽一张，覆盖全片的 50 张样帧已经逐张检查接触表。源帧 PTS、图片哈希和查看范围见素材记录（外部或本机资源，未随公开包收录）与采样清单（外部或本机资源，未随公开包收录）。未完成原片连续播放审查或主观听审；这里的时间点是采样观察，不是作者的工程时间线。

## 画面怎样说明水的去向

| 源片时间（约） | 实际画面 | 可复用的安排 |
|---|---|---|
| 0–1.0 秒 | 水从上方落入浅青色长斜槽，槽的侧边说明流动方向 | 先展示水源与承载面，观众知道水从哪里来；不让镜头先钻进一片无法定位的波纹 |
| 1.0–1.5 秒 | 水向出口推进，前唇出现初始滴落 | 出口保留观察窗，让“蓄水到出流”有因果次序 |
| 1.5–4.0 秒 | 水从槽口自由落下，在下方方盆中飞溅、积聚；斜上方镜头靠近接水区域 | 同时保留槽口、落差、撞击点，水的运动本身就是解释 |
| 4.17–6.0 秒 | 正面水帘映出亮天空和暖黄色环境 | 透明材质需要可反射的明暗结构；颜色与明度变化帮助观众认出薄水帘边界 |
| 6.17–7.67 秒 | 较低侧面近景中，盆壁遮住大部分水 | 近景不一定更清楚。要讲流路时，提高机位或改变观察方向；不要靠透视错误把盆壁隐藏 |
| 7.83–8.33 秒 | 回到较宽的整体视角 | 局部观察后回收整体关系，给下一镜留下可追踪的空间锚点 |

最有用的结构是 **供水 → 导流 → 自由下落 → 承接**。浅青实体给水提供边界，环境反射让透明曲面显形。制作时应分别检查运动、接触和反射，不能用闪亮材质掩盖不合理的流路。

## 从观察变成可操作的 Blender 制作

源片没有公开工程、插件、求解器、材质节点或渲染设置。不能凭外观断言作者使用 Mantaflow、FLIP 插件或 Cycles。本次原创选择 **Mantaflow 液体仿真 + Cycles 路径追踪**，目的是在用户的 Blender 中落实建模、碰撞、材质和渲染这一整条流程。

- **几何先行。** 槽底、槽壁和出口有厚度；可见模型与碰撞体一致。倒角后的最薄处也要相对计算网格足够厚。
- **三类对象分工。** Domain 指定求解范围，Flow 提供初始水量与持续流入，Effector 定义实体碰撞。水帘来自仿真后的液面网格。
- **保持物理次序。** 先烘焙 Data，再烘焙 Mesh；换几何和流量后重烘。改灯光、相机可直接重放缓存。
- **材质有依据。** 清水从 `Transmission Weight=1`、`IOR≈1.333` 开始，用宽区域光与有明暗差的环境读形；透明度不能代替折射。
- **摄影服务观察。** 全貌用于建立流路，近景用于看槽口与撞击。先关景深、运动模糊检查碰撞，之后才用它们组织注意力。
- **失败也记录。** 初轮流唇侧边缺口令出流偏向细流；修正后形成更连续水帘。v1 下盆外侧的异常水膜也没有被当作“自然飞溅”：v2 调整碰撞实体、表面距离、网格重建半径及入口，复看第 60/96 帧，外壁与盆底一圈异常水膜已消失。多项联合修改不能归因于某个单独参数，过程见 runtime（外部或本机资源，未随公开包收录）。

完整方法与官方依据见[Blender 建模与动画指南](../guides/blender-model-motion.md)。原创建模、烘焙、渲染入口在 [build_waterfall.py](../examples/blender-flow/build_waterfall.py)，使用方法见 [API](../examples/blender-flow/API.md)，可查看[流水研究室](../lab/blender-flow.html)。

### 运动曲线是这次最有价值的发现

用 Farneback 光流与相位相关（`cv2.phaseCorrelate`）逐帧量相机位移，S3 不是均速横移，而是一条**先横后竖的弧**：

- 6.083 秒：dx = −78.9 px/帧（横向全速），dy = +0.6
- 6.500 秒：dx = −37.7，dy = −4.8
- 7.000 秒：dx = −9.1，dy = −25.0
- 7.333 秒：dx = +0.2（横向刹停并反向微回），dy = −46.8（竖向加速到峰值）
- 7.458 秒：dy = −55.3，为全片最大瞬时位移

横向量在 1.375 秒内衰减到约 1/400（78.9 → 0.2 px/帧），竖向量同期反向加速到约 90 倍（0.6 → 55.3 px/帧），两者在第 164 帧（6.833 秒）以 16.6 / 16.6 px/帧交叉。相加后的合成速度在 6.833 秒有个谷（23.5 px/帧），说明这是**两段不同方向的摇镜在中间交接**，不是一条缓动曲线。手感上像“甩过去、顿一下、再甩下去”。这也是 S3 像素差（13.76）约为 S1（4.12）三倍多的直接原因。

S4 的收尾用同一方法量出的不是运动而是**静止**：第 188 帧之后 pix_diff 固定在 0.38–0.49，帧间灰度绝对差 0.53–0.67（0–255 标度）持续 0.54 秒——是一张完全定帧的“落款”。出画比例（饱和像素包围盒高度）从 455 px → 695 → 911 → 935 px，用 4 帧完成，之后锁死。

### 切点与声音的关系：跟事件，不跟拍

音轨没有静音段（`silence_ratio = 0.0`），56 个 onset 中 55 个被判为 noise，质心中位数 4078 Hz，平坦度中位数 0.12——是水流噪声床，不是配乐。tempo 检测给出的 117.5 BPM 值得怀疑：onset 间隔中位数 0.139 秒（约 7.2 次/秒），远短于 117.5 BPM 的 0.511 秒拍长；把 onset 对 1/2 拍、1/4 拍网格做相位拟合，最佳中位相对误差 0.184，随机相位基线 0.252，改善有限。**不能据此宣称这片卡点。**

但切点附近确实有可测的对齐：

- 4.156 秒 onset（strength 2.92）距切点 4.167 秒仅 **−0.011 秒**（不到 1 帧）
- 6.130 秒 onset（strength 6.96，全片第二强）距切点 6.083 秒 **+0.047 秒**（约 1 帧）
- 7.663 秒 onset（strength 4.13）距切点 7.542 秒 +0.121 秒（约 3 帧，但 7.542 后是白闪+快速拉出，声音落在新镜头的落定处而非切入处）

结论更保守也更有用：**声画同步是按水体事件（入水、撞击、水舌拍盆）排的，不是按音乐拍点排的。** 0.070 秒那个 strength 10.57 的全片最强 onset、以及 RMS 在 0.279 秒冲到 −1.8 dB、0.464 秒到峰值 −1.6 dB，都是水落入槽的撞击；随后 1.5 秒 0–120 Hz 频段掉到 −41.6 dB，低频只服务于开场那一下。

分镜 RMS 均值：S1 −16.8 dB、S2 −21.7、S3 −21.4、S4 −20.7。开场最响，之后一路压平——声音的“先给一个大事件，再退成背景”与画面“先给完整流路，再给特写”的结构一致。

- S1 水色 `#85bcd6`（占比 0.53–0.55）、槽体暗面 `#407ab0`（0.25–0.29）、环境灰 `#56707f`（0.17–0.21）；val 从 154.8 升到 190.9、sat 从 92.2 升到 114.2，中途只有 ±0.5 量级的来回（非严格单调）——机位抬升带来的曝光爬升是渐进的，没有跳变
- S2 换成逆光配方：`#e8f0f2` 天光（0.41）、`#97c0d1` 水面（0.50）、`#cbad5d` 暖黄灌木（0.08–0.13）。sat 骤降到 52–55（比 S1 低 60 左右），val 升到 217–223（全片最亮）。**一个 0.08 占比的暖色小面积，撑住了整段冷色的可信度**，这是最容易抄的一个动作
- S3 又切回冷调但更暗更饱和：`#a1b8c3` / `#74adcb` / `#62798c`，edges 从 S2 的 0.082–0.102 升到 0.113–0.188（全片最锐），对应白桦林的细密高频

### 可执行参数

1. **四镜时长 4.17 / 1.92 / 1.46 / 0.79 秒**（占比 50 / 23 / 17.5 / 9.5）。来源：`cuts` 三点 + 总时长 8.333 秒。若目标片长不同，按比例缩放，但**开场镜头不要低于总长的 35%**——本片用一半时长只为把 供水→导流→下落→承接 讲完。
2. **切点与最近水体事件的偏差控制在 ≤ 2 帧（≤ 0.083 秒）**。来源：4.156 s onset 对切点 −0.011 秒、6.130 s onset 对切点 +0.047 秒。做法是先在音轨上标出真实撞击点，再让剪辑点贴上去，而不是先定 BPM 再切。
3. **甩镜用“双向交接”而非单条缓动：横向速度 1.375 秒内衰减到 1/400，竖向同期加速到 90 倍，两条曲线在第 164 帧等速交叉**。来源：S3 逐帧 dx/dy（−78.9 → +0.2 / +0.6 → −55.3）。实现上给相机 X 和 Y 两条独立曲线，在 S3 的 52% 处交叉，合成速度会出现一个约 23 px/帧的谷，顿感就是它。
4. **收尾定帧 ≥ 0.5 秒**。来源：S4 第 188–199 帧 pix_diff 0.38–0.49、帧间灰度差 0.53–0.67（0–255）。定帧长度约占总长 6%，用于让观众看清整体关系；前 6 帧留给白闪和拉出。
5. **白闪 2 帧（0.083 秒），饱和度塌到 31.6、亮度落在 meanV 156–181**。来源：第 182–183 帧（7.583–7.625 秒）edges 从 0.128 掉到 0.030 / 0.011（接近无细节），同两帧 meanS 31.6 / 56.5、meanV 181.1 / 156.3、stdV 20.3。是一次“洗白”过渡而不是纯白闪白：保留蓝灰底，所以亮度反而比前一帧的 187 更低。
6. **冷暖反转只需 8% 面积的暖色**。来源：S2 色板 `#cbad5d` 占比 0.08–0.13，配合 sat 从 114 降到 53 即完成整段气质切换。不要整屏调暖。
7. **音轨底噪频段：主能量 1200–3000 Hz（占全带 −0.7 至 −6.8 dB，全程领先其他频带），0–120 Hz 仅开场 0.5 秒内有用（−8.5 dB，1.5 秒后掉到 −41.6 dB）**。来源：6 段频带能量表（0–120 / 120–400 / 400–1200 / 1200–3000 / 3000–8000 / 8000–16000 Hz，0.1 秒步长）。做水体音效时，低频只给第一次撞击，其余时间保持在中频噪声带，避免整片轰头。
8. **运动模糊强度按镜头分档**：S1/S2/S4 的梯度各向异性 gx/gy = 0.73 / 0.55 / 0.71，S3 为 1.42。来源：全片 Sobel 梯度比。即前三镜是横平竖直的结构边缘主导（低快门/低模糊也能读），S3 因摇镜产生大量斜向拉伸边缘，必须开运动模糊才不会闪。

### 不能断言的内容

- 没有工程文件，无法确认 Blender 版本、渲染器（Cycles / EEVEE）、采样数、是否用了 Mantaflow。上文已声明 Mantaflow+Cycles 是**本笔记的原创选择**，不是对作者做法的还原。

- 未验证 S2 水帘的透射/折射是否为真实路径追踪；逆光亮度（val 217–223）可能来自环境贴图或合成，无法从画面区分。
