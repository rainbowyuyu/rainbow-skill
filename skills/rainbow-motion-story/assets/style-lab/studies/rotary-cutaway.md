## 代码实现建议

1. part记录restMatrix/pivot/axis，explode位移在局部轴计算，回装恢复原矩阵。

2. clipPlane用实体截面封口或专门剖面几何，不能只是半透明叠层；运动用kinematics(t)独立采样。

3. 环绕验收投影包围盒与深度顺序，透明排序不能用depthTest=false解决；有齿轮时关系用齿数/轴约束求解。

这些是原创实现路线，不是对原作者源码或所用引擎的还原。表现动画应以时间/帧号采样；求解数据与表现缓动分开。

## 2026-10-26 量化补充

本节全部数字来自 `research/douyin-batch2/analysis/rotor/` 的解码成品（`frames.json` 5100 帧 / 30fps / 170.000000s / 1920×1080；`rotor-audio.json` 169.9s / 920 个 onset）。这是**帧级像素差与音频事件统计**，不是原速主观复看结论。上文三窗的定性描述与本节冲突处，以本节实测为准；上文对动作的**判断**（切开不重置转动相位、剖切/旋转/相机三个时钟独立）本轮数据无法证实也无法证伪，仍属下文的观察性描述。

测量口径：`pix_diff` 为相邻帧像素差均值（0–255 量纲的百分比均值），`hist_diff` 为直方图差，`grid` 为 8 列×5 行共 40 格的分格差分（格子约 240×216px），`sumgrid` 为 40 格之和。所有时间取帧 PTS 本身，不做插值。

### 1. 三处切换的实测时长（纠正上文"5.500–5.833s"）

| 窗 | 变化起始 | 峰值帧 | 回落帧 | 有效时长 | 峰值 pix_diff | 平稳段中位数 | 峰/稳比 |
|---|---|---|---|---|---|---|---|
| A 整机变剖面 | 5.500 | 5.600 | 5.633 | **0.133s**（4 帧） | 9.06 | 1.290 | 7.0× |
| B 按钮驱动切开 | 121.400 | 121.467 | 121.667 | **0.267s**（8 帧） | 5.82 | 0.540 | 10.8× |
| C 透明化 | 145.267 | 145.267 | 145.733 | **单帧尖峰**，0.467s 内落定 | 33.36 | 0.590 | 56.5× |

上文记 A 窗为 5.500–5.833s（0.333s）。逐帧数据显示 5.633s 已回落到 1.94（基线 1.23–1.33），5.833s 之后**没有**任何超过 2.0 的帧。0.333s 是采样格点间距造成的上界，不是动作时长。真正的一次性位移发生在 5.500–5.633，约 0.133s，即 **4 帧内完成**。

A 窗是"两拍"结构而不是一段匀加速：5.500(4.06) → 5.533(6.84) → 5.567(3.92，回落) → 5.600(9.06，最高) → 5.633(1.94)。第一个小峰在 5.533，低谷在 5.567，第二峰在 5.600，峰间 0.067s。同一位置上文只写成一个连续动作；这里能量的双峰更像"外壳先退、内部再显"两段各自收尾，但仅凭像素差不能判定是哪一段先动。

**边密度（`edges`）在 A 窗是"先降后回"，不是"先升后回"**：5.467s 基线 0.083 → 5.500 0.082 → 5.533 0.080 → 5.600 **0.077**（全窗最低）→ 5.633 0.076 → 5.733 0.087（高于基线）。B 窗则相反：121.333 基线 0.107 → 121.467 **0.128** → 121.667 回落到 0.108，第二脉冲 122.200 0.113 → 122.333 **0.130**。两种方向对应两种做法——A 是**端盖退去后结构被大块面覆盖**（细节变少），B 是**剖面边缘被画出来**（细节变多）。判断切开动画属于哪一类，看 `edges` 峰值出现在位移峰之前还是之后即可。

**B 窗实测是两组脉冲而不是一组**：第一组 121.400–121.667（4 帧，峰 121.467 = 5.82），回落 121.733–122.067（pix_diff 0.26–0.52，接近静止），第二组 122.133–122.267（3 帧，峰 122.200 = 6.54）。**两组之间隔 0.467s 的静态间隙**，且第二组的 `val` 从 105 冲到 141.5 并停在那里（第一组只到 126.4 又跌回 104.9）。这说明是"点一下 → 等一下 → 结构落定并提亮"，而不是一次连续过渡。上文窗口 2 记的"121.500–121.833s 启用切开"只覆盖了第一组。

### 2. 变化的空间包络

以 A 窗 5.467s 为基线、5.600s 为峰值，逐格差分（每格单位为差分百分比）：

```
     c0     c1     c2     c3     c4     c5     c6     c7
r0    0.0   -1.0   -1.8    0.0    0.2    0.0    0.1    0.0
r1   -0.2   11.8   28.0   27.9    9.1   -0.2   -0.0   -0.0
r2    0.1   19.8   36.5   43.2    9.7    0.0    0.1    0.0
r3   -1.9   17.9   37.5   39.3   10.8   -0.0    0.1    0.0
r4   -0.5    0.8    0.6   -5.9   -0.2    0.0    0.0    0.0
```

- c5–c7 三列（画面右 37.5%）增量全部 ≤0.2，r0 与 r4 两行（上下各 20%）也基本为 0。**切开只在中部 4 列×3 行的窗口内发生**，横向约 x=240–1200px，纵向 y=216–864px。
- 变化质心 cx=2.40 格、cy=2.04 格，换算 **x≈696px、y≈549px**（画面中心为 960,540）。质心比画面中心**偏左约 264px**，几乎不偏上。这与上文"数据栏细且稳"一致：右侧留出的数据栏整段不参与变化。
- 峰值格为 (r2,c3)=43.2、(r3,c2)=37.5、(r3,c3)=39.3，呈 3×3 块状而非单点，最大单格 47.0。块内增量是块外的 3–40 倍，说明剖切面是**一个连续的矩形区域**在变，不是零散标签在闪。

B 窗（121.400→121.533）变化横跨 c1–c6、r1–r3，质心 x≈992px，**接近画面中心**但纵向范围与 A 相同（20%–80%）。C 窗（145.200→145.267）覆盖 c1–c7、r0–r4 即**整幅 87.5%×100%**，质心 x≈978px——这与"透明化"是全局材质改变（整机不透明度/深度排序变化）而不是局部结构位移吻合。

### 3. 落定后的保持长度

- **A**：5.833–9.500s 中位 pix_diff = 1.290，最大 2.63。这是**非零的持续运动**（内部转动仍在），不是静止画面。相对 5.000–5.467 的基线 1.23–2.30 并无下降，说明切开后内部机构照常转。
- **B**：122.400–125.000s 中位 0.540，最大 1.44。比 A 低一半以上，是**低幅持续运动**（小角度观察/轻微旋转）。
- **C**：146.533–148.900s 共 72 帧，中位 0.590，p90 0.820，**逐帧值集中在 0.45–1.09**，且 0.59→0.92→0.58→1.09 无单调趋势。这是一段**近冻结但非冻结**的保持，持续 **2.27–2.37s**，直到 148.900 的 26.39 和 149.067 的切镜打断。全片有 37 段 pix_diff<0.1 的静止段（最长 1.533s，在 79.500–81.033），C 窗这段不属于其中任何一段。

### 4. 音频对齐

- 三段切换的响度台阶（480ms 级 RMS 均值）：A `−18.68 → −6.40 dB`（**+12.3 dB**）；B `−20.70 → −8.70 dB`（**+12.0 dB**）；C `−14.52 → −8.61 dB`（**+5.9 dB**）。全片 RMS 均值 −11.33 dB、中位 −9.20 dB、p10 −22.0 dB、p90 −4.4 dB。
- A 窗第一个 onset 在 **5.503s**（`noise`，centroid 3783 Hz），画面上第一个变化帧在 5.500，**差 3ms**。B 窗第一个 onset 121.394（noise，2988 Hz）对 121.400，**差 6ms**。C 窗 onset 145.287（noise，3236 Hz）对峰值帧 145.267，**onset 晚 20ms**。三处都是**宽带噪声型** onset 先于或贴合画面变化，而不是先出音乐再接动作。
- A 窗 5.500–5.733 内 onset 序列为 5.503 / 5.689 / 5.828，间隔 0.186 / 0.139s，峰值强度 4.45 / 5.19 / 6.42——**三连击逐次增强**，与画面双峰+收尾的三段对得上。
- B 窗是两拍：121.394(7.16) → 121.603(9.97) → 121.835(9.22)，然后 122.133–122.267 第二组画面脉冲对应 onset 122.044 / 122.230，画面峰值帧 122.200 与 onset 122.230 **差 30ms（onset 在后）**。

### 5. 可执行参数

1. **切开动效时长 0.133s ± 0.033s（4 帧 @30fps）**，峰值落在第 3 帧（起始后 +0.100s），第 4 帧即回落到基线 1.5 倍以内。来源：A 窗 5.500–5.633 逐帧 pix_diff。
2. **位移缓动用"双段式"而非单条 ease**：第一段在 0–0.033s 达到峰值能量的 45%（4.06/9.06），中途 0.067s 回落至 43%（3.92），0.100s 达到 100%，随后 0.033s 内跌到 21%。等价于 `ease-out` 主段 + 一个 0.067s 间隔的二次收笔。来源：A 窗归一化曲线 0.356 → 0.714 → 0.338 → 1.000 → 0.082 → 0.046。
3. **剖切区域限制在横向 12.5%–62.5%、纵向 20%–80%**（1920×1080 下即 x 240–1200px、y 216–864px），质心放在 **x≈696px（画面中心左 264px）、y≈549px**；右侧 37.5% 宽的区域保持不动以容纳数据栏。来源：A 窗 8×5 分格差分 c5–c7 全 ≤0.2。
4. **瞬态对比度分档**：结构位移型用 7–11× 平稳段像素差（A 7.0×，B 10.8×），全局材质型用 56× 以上（C 56.5×，单帧 33.36 对 0.590）。低于 5× 的切换在 30fps 下几乎读不出是"事件"。来源：三窗峰值/平稳中位数比。
5. **落定后的保持段按运动量分三档**：持续机构运动用 pix_diff 中位 1.29（A，5.833–9.500）；低幅展示用 0.54（B，122.400–125.000）；讲解静帧用 0.59 并保持 2.27s（C，146.533–148.900）。**不要**把讲解段做成 0.0 的真冻结——实测最接近冻结的段仍在中位 0.59。
6. **音频在切换点做 +12 dB 台阶（结构位移）/ +5.9 dB（材质改变）**，台阶前预留 0.35–0.50s 的 −18 至 −21 dB 低电平（A 窗 pre 段 −18.68、B 窗 pre 段 −20.70）。来源：480ms 级 RMS 均值。
7. **切换音要贴画面 20–30ms 内，且首击用宽带噪声（centroid 2.9–3.8 kHz）**：实测 A +3ms、B +6ms、C +20ms；三处首个 onset 的 `kind` 都是 `noise`。来源：`rotor-audio.json` onsets 与帧 PTS 对齐。
8. **保持段的发声密度维持 5.4–5.8 个 onset/秒**，即画面停下后声音事件流不能跟着稀疏。来源：C 窗冻结段 5.73/s vs 全片 5.41/s。
9. **剪辑节奏**：全片 40 次切镜、平均 4.25s 一刀；最长无切段 102.200–140.933（38.73s）属软件教学段，**机械讲解段（0–102.2s）平均 3.01s 一刀**（33 刀/102.2s，即 102.2s 内有 33 个断点）。切开演示本身（5.5–9.5s）落在无切区内，靠内部运动撑住而不靠切。来源：`frames.json` cuts 数组（阈值 0.35）。

### 6. 本轮不能断言

- `tempo` 字段为 129.2，但 onset 间隔中位数 0.163s、众数区间 0.15s，换算约 6.1 个/秒，与 129 BPM（0.464s 间隔）不符；920 个 onset 里 796 个标 `tonal`、124 个 `noise`，整体更像**人声讲解为主的连续事件流**，`tempo` 不宜当作音乐 BPM 直接使用。
- 双峰结构（5.533 峰 + 5.600 峰）到底是"端盖先退、内部后显"两个独立动画，还是一个动画的中途停顿，仅凭 30fps 的像素差无法分辨；0.067s 的间隔也可能只是采样混叠。
- 没有 diff 到单格的运动方向信息：能证明"哪些格子变了多少"，不能证明"哪一块往哪个方向移了多少"。上文"端盖退去"的具体位移方向仍是观察描述。
- C 窗保持段中位 0.590 而 A 窗 1.290 的差值，可能来自旋转慢/快，也可能来自视频压缩码率或噪点差异，**不能据此断言转速比**。
- 原声未做主观实听；`rms_db_curve` 与 onset 只说明能量与事件时刻，不能说明用了什么音效素材、是否为原创。
- 未取得原作者项目文件，上述时长与缓动是从成品反推，不是作者参数。
