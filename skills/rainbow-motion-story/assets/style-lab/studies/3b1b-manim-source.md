### 公式匹配值得学的细节

`TransformMatchingStrings` 在匹配实现 123–186 行先处理显式 `key_map` / `matched_keys`，再找最长相同子串；它不是理解代数的求解器。底层 21–115 行还尝试同形匹配，并对未匹配部分安排淡出/淡入。因此：

1. 先列语义 ID，例如 `force.gravity`、`pressure.gradient`、`error.current`，再映射到字形。`x` 的形状相同，不代表两处 `x` 是同一推导角色。
2. 拆分时复制：`a(b+c)` 中一个 `a` 要形成两个分支，先保留出处，再分给 `ab` 与 `ac`。不要让匹配器随意猜。
3. 合并时先显示操作，再收束结果；至少留一个能读完的静止终态。
4. 等号链、定义、近似、极限是不同关系。动画顺滑不能掩盖符号使用错误。
5. 源例中的 `A²=(C+B)(C−B) → A=√((C+B)(C−B))` 在一般代数里需要补 `A≥0` 的条件；否则应展示 `|A|` 或 `±`。借用动画方法时仍要单独校验数学。

## 四组影片源码：把图形变化变成论证

### 1. 线性代数：把矩阵列变成基向量的去处

[源码 `_2016/eola/chapter3.py`](https://github.com/3b1b/videos/blob/306a1346a356c7a7b097875ceb51c5cd67d0a56c/_2016/eola/chapter3.py#L577-L763)；[官方教学页](https://www.3blue1brown.com/lessons/linear-transformations/)。

细读 `FollowIHatJHat` 577–599、`TrackBasisVectorsExample` 601–763。顺序为：先辨认两根基向量和系数，再一起变换网格与向量，然后用相同系数拼回结果，最后把结果写成矩阵列。631–641、686–714 行使对象、符号和颜色保持对应；670–683 行把线性组合具体表现为缩放和首尾相接。

可复用配方：保留灰色原网格 → 将两根基向量按语义着色 → 示范 `v=x e₁+y e₂` → 同步映射网格、向量和基向量 → 用变换后的基向量重新构造 `Av` → 矩阵列从对应向量的终点读出。镜头的主问题是“只知道两根箭头去了哪，为什么足够确定所有点？”

数学检查：旧源码的 `transposed_matrix` 是旧辅助类的接口约定；迁移时必须实测 `A @ e₁` 和 `A @ e₂` 对应列，不把转置名称照抄。显示 `(1−α)I+αA` 的过渡应称为展示路径；它可能经过奇异矩阵，不是额外的动力学模型。

### 2. 微积分：从两次观测，逼近一个局部变化率

[源码 `_2017/eoc/chapter2.py`](https://github.com/3b1b/videos/blob/306a1346a356c7a7b097875ceb51c5cd67d0a56c/_2017/eoc/chapter2.py#L961-L1152)；[官方教学页](https://www.3blue1brown.com/lessons/derivatives/)。

细读 `DsOverDtGraphically` 961–1152。989–1005 行由同一曲线上的两个点构造时间差和位移差；1012–1038 行先放大局部再解释两条测量线；1041–1071 行才把两条线连回 `ds/dt` 和差商；1096–1111 行让输入线、局部三角形与放大框共同移动。

可复用配方：先问“这一刻的快慢怎么测？”→ 两次观测 → 水平差与竖直差分别出现 → 标签进入分子分母 → 缩短 `h`，割线逐渐贴近切线 → 显示差商与解析导数的误差。整个过程只用一份 `x,h,f(x),f(x+h)` 状态。

数学检查：`h` 有限时写差商或近似，不能把数值差商直接写成精确导数；`h=0` 时不要做零除，应切换为解析极限/导数表达。屏幕斜率受坐标轴比例影响，数字读数按数据坐标计算。旧文件 8 行直接注明 GraphScene 未适配较新改动，不能假定当前环境原样可跑。

### 3. 傅里叶：同一条波，从时间域绕到复平面

[源码 `_2018/fourier.py`](https://github.com/3b1b/videos/blob/306a1346a356c7a7b097875ceb51c5cd67d0a56c/_2018/fourier.py#L792-L1044)；[官方教学页](https://www.3blue1brown.com/lessons/fourier-transforms/)。

细读积分助手 44–57、`FourierMachineScene` 792–1044、质心与频率联动 1584–1665。961–964 行通过 `g(t)exp(−2πift)` 把同一信号样本映射到复平面；998–1044 行使时间域探针和复平面向量共同前进；1638–1665 行将绕圈频率、数值标签、质心和频谱读数一起变化。

可复用配方：波形上选一个带身份的时间样本 → 它在复平面上旋转，长度仍表示原信号值 → 扩展到整段样本 → 只改变绕圈频率 → 重心偏移与频谱读数同步出现。观众先看见“什么时候抵消，什么时候偏向一边”，再读积分公式。

数学检查：信号频率、绕圈频率、动画播放速率是三件事。所谓质心应对应等时间采样/积分权重，不是按绘制曲线弧长求质心。源码默认使用有限窗归一化以及实部，可读 6–8、44–57 行；复用不能把 `Re F(f)` 标成 `|F(f)|` 或无限窗精确频谱。复数求积用现代 API 或分别积实虚部并验证，不照搬旧 SciPy 调用。

### 4. 注意力：先把一个词讲清，再扩展成矩阵

[源码 `_2024/transformers/attention.py`](https://github.com/3b1b/videos/blob/306a1346a356c7a7b097875ceb51c5cd67d0a56c/_2024/transformers/attention.py#L784-L960)；[官方教学页](https://www.3blue1brown.com/lessons/attention/)。

细读 763–962、1085–1212。先用框和亮度聚焦一组 query/key；逐项呈现点积，再聚焦一列。892–929 行将该列的 softmax 结果移到另一个空间层，并让相机转到可读的斜视角；932–960 行推广到其他列，再回正视合并。1085–1115 行把权重和 value 配对，1140–1201 行显示求和与更新量。

可复用配方：一个对象有一个具体问题 → 它与几条候选信息比较 → 分数归一化 → 复制候选 value 并按真实权重表示 → 合成为更新量 → 再扩展到矩阵。学习的是“局部解释—全局推广”的顺序，而不是一次把全部连线画满。

真实性检查：784–815 行明确存在人为生成与设定的教学数值，不能把这些权重叫作真实模型头的可解释性结果。若使用原创 toy attention，固定随机种子/输入，展示真实计算的 softmax、行列方向、mask 和 `√dₖ` 缩放，清楚说明这是演示数据。

| 观众此刻要判断什么 | 选用动作 | 先保留什么 | 不要做什么 |
|---|---|---|---|
| 这一项从哪里来、去了哪里 | 符号身份匹配、复制分支、局部收束 | 等号基线、语义色、来源项 | 只因字形相同就交叉飞行 |
| 数字变化对实体意味着什么 | 单一参数驱动实体、公式和读数 | 单位、坐标、同一时钟 | 分别给数字和图形写两条不同曲线 |
| 抽象表达对应哪段几何 | 测量线 → 标签 → 公式的交接 | 原对象与定位线 | 直接跳进满屏公式 |
| 整个空间接受什么规则 | 基向量/网格共同变换 | 灰色原网格、原点 | 只动一个箭头却说所有空间变了 |
| 局部细节为什么影响全局 | 局部放大 → 操作 → 回到全图 | 追踪框与同一数据点 | 移镜和公式变化同时抢主动作 |
| 一个例子怎么推广 | 先一项、再同类项、最后全体 | 一个已理解的锚点 | 初始画面就堆满矩阵、粒子和文字 |

呼吸节奏来自“观察初态—一次改变—看清终态—提出下一步”，不来自所有对象持续摆动。公式留在易读层；焦点靠颜色、亮度、相对位置和近邻标注完成，避免每一项都放大、发光、旋转。

## ManimGL 与 Community 迁移对照

| 当前上游 GL 用法 | CE 实作要核对的接口 | 不可默认相同之处 |
|---|---|---|
| `from manimlib import *` / `manimgl` | `from manim import *` / `python -m manim` | 依赖、配置、渲染器和命令不同 |
| `Tex` / `TexText`，`t2c`，`isolate`，字符串索引 | `MathTex` / `Tex`，`substrings_to_isolate`，`set_color_by_tex`，`get_parts_by_tex` | 字形拆分、重复词选择和分组方式不同 |
| `TransformMatchingStrings`；`TransformMatchingTex` 是其别名 | CE `TransformMatchingTex`，或显式分组配对 | 同名类不保证同一匹配算法和参数；一对多用复制明确表达 |
| `ShowCreation` / `axes.get_graph` / `axes.i2gp` | `Create` / `axes.plot` / 对应图点接口 | 角点、不连续点、采样范围和曲线取点需再验 |
| `self.frame` / `fix_in_frame()` | 按 CE 场景类型使用 camera frame 或 3D fixed-in-frame 接口 | 相机对象与固定层机制不同 |
| `CONFIG`、`OldTex`、`GraphScene`、自定义 `manim_imports_ext` | 重新组织构造参数和场景代码 | 影片旧代码还有自定义人物/素材/辅助类，不是单文件安装库 |

本轮原创运行例采用本机已确认的 **Manim Community 0.19.1**，是教学方法的迁移实现。未安装 ManimGL，也未把原作者影片工程标为已运行。

## 交付给制作环节的检查表

1. 每个公式片段有稳定语义 ID、颜色、数学关系以及出现/消失原因。
2. 重复符号、一对多拆分、负号、根号、上下标在起中终三处核对。
3. 读数、曲线、几何、字幕来自同一状态；改变播放时长不改变数学结果。
4. 任意定位、倒序定位和重播得到一致状态；不把累计帧历史当状态。
5. 同时只推进一个主要观察任务，复杂转换后留清楚的终态。
6. 验证有限差分、矩阵列、复数实虚部、归一化权重等实际数值，不只看有没有报错。
7. 研究范围、原创程度、渲染后端与实际验收范围分别记录。
