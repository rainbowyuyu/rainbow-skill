# 视频参考逐条研究
本资料库按方法组织，不绑定任何视频主题。每条分别保存观察事实、动作相位、可复用规则、实现建议和不能推断的内容。
公共方法库现有58个原创候选；[审美方向工作台](../lab/aesthetic-direction.html)以同一物件比较三种构图、光线和节奏；[传输视觉工作台](../lab/transmission-effects.html)提供相对运动曝光对照和确认后推进窗口两个例子；[MOFs文案工作台](../lab/mofs-writing.html)用同一解释链比较三种开场，并支持本机逐句改写；[机构工作台](../lab/rotary-interaction.html)分别控制前盖、轴向拆解、机位和转速。代码与原片证据分开记录。
已复核8张全片稀疏概览、24组密集联系表，共711个精确PTS静态样本。旧1×静音播放范围单独列出。原声未主观实听，信号分析不代替听感判断。
