## 最值得复用：同一实体的概念换位

**重点窗口：5.583333–6.583333 秒，源帧 335–395。**

这段的价值是：观众不用重新辨认一个新物件，就能意识到「我们仍在看它，但现在要解释另一件事」。对象持续存在，构图中被腾出的区域成为新概念的阅读位置。

逐帧观察支持的细分：

1. **5.583–5.633 秒**：旧标签与脑图的构图近似停留，给前一句结束的余地。
2. **约 5.650–5.850 秒**：脑图向左上明显移动，旧标签向左退走。约 5.717–5.817 秒，部分旧字暂时叠在脑图前方；复用时应主动修正这个阅读遮挡，而不是照搬。
3. **约 5.867–6.467 秒**：脑图停在新的左上位置，右下保持空白。这里的空白时间使下一项信息有落脚点。
4. **6.483–6.583 秒**：`Slow` 从浅灰逐渐清晰，首次进入新阅读区。不是旧标签与新标签同时争夺注意力。

可把这套关系用于「观测 → 判断」「构件 → 作用」「现象 → 方程」：先留下被解释的实体，再改变围绕它的问题。不能把本片的脑图及其标签当作神经科学证据，也不能将对照标签套成模型推理速度的实测结论。

## 实现机制：推测，不是读取到的源码

- 脑图轮廓和纹理在换位前后相似，支持用一个稳定资产做位置/尺度变换的实现思路；静帧不能证明它是 2D PNG、实时 3D 或预渲染序列。
- 标签灰度与软边的变化可以用 opacity + 少量 blur 重现，也可能是其他合成方式；具体 easing、弹簧参数和滤镜链未查证。
- 背景曲线/点阵的移动可以理解为一个较大的二维排版画布滑动，也可由多层独立变换实现；不得把它描述为已确认的 3D 摄影机。
- 采样显示动作之后有较长稳定区，但没有测量连续播放的速度/加速度，也没有监听音乐来推断卡点。

## 原创改写的设计约定

新增候选 `mf-concept-bridge` 以「看见 → 判断」为主题：一个原创观测球从两组词之间被辨认，来到中央完成测量解释，再让位到左侧，让相同测量被组织为下一步判断。

- **同一身份**：`observation-entity` 全程唯一；尺度、位置、球面标记和测量值保持连续，不以跳切更换对象。
- **同一数据**：固定教学输入 current = 72 cm、target = 100 cm，差距由同一数据计算为 28 cm。动画重新安排解释视角，不伪造物理过程或真实推理。
- **一层信息一层动作**：对象运动时不新增长句；位置稳定后才引入新标签，结果出现后停止装饰运动。
- **先读得清，再迁移**：旧标签离开实体区域后再出现新标签；连接线靠近对象与测量位置，不交叉穿过字面。
- **有限时间**：14 秒，绝对时间采样，尾端稳定阅读；支持随机定位、倒序定位和 reducedMotion。
- **不继承原资产**：不用脑图、水印、原片台词和声音；仅迁移对象身份、构图让位和阅读时间的关系。

原创建模/绘制与测试入口将位于 `lab/modules/motionface-concepts.js`、`scripts/test_motionface_concepts.mjs`；其验证结果与源片观察分别记录。

## 取用时的检查

1. 固定实体在镜头中是否始终可追踪，跨阶段是否偷偷换了几何或数据？
2. 新标签有没有在旧标签尚未退出、实体尚未稳定时同时出现？
3. 文字是否放在真实腾出的留白，而不是覆盖物件或装饰纹理？
4. 人为加快 tempo 后是否还留有完整阅读窗？低动态模式是否仍保留语义次序？
5. 科学字段来自实际数据还是教学示例？文案必须与实现一致。
