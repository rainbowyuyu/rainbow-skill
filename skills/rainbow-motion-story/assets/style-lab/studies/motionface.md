# Motionface：文字、图形与信息交接研究

研究日期：2026-10-24。来源首页：<https://motionface.cc/>；官方页脚指向的公开社区：<https://github.com/vibe-motion>。

## 观看与获取范围

实际访问了公开首页、文字分类列表、首页六秒动画与官方 GitHub 社区页面。文字分类当时显示 21 个条目；只把列表用于了解候选方向，没有把缩略图当成完整动画。

第一阶段先研究公开页面。随后用户明确允许第三方应用 `motion-recorder` 的 GitHub 邮箱授权，完成登录，查看并下载了两段可播放作品用于研究：`Focus · Kinetic Typography | Remotion 复刻` 与 `Mindset · FrameCo 动态思维模式 · Remotion 复刻`。作品绑定仓库仍需10 Face解锁；本次没有付费解锁、消耗 Face 或获取这些受限源码。

首页动画通过公开播放控件暂停，并在 0、18、36、54、72、90、108、126、144、162、179 帧取样。播放器最大帧 179，标示总时长六秒；最后一帧约 5.97 秒。截图对应实际 UI 值，不是独立推断的镜头切点。证据为 11 帧联系表（外部或本机资源，未随公开包收录）与取样记录（外部或本机资源，未随公开包收录）。早期播放中取样保留在 evidence/motionface 根目录，不用于精确时间判断。

本轮没有原作音轨主观听审，不对原作音效、节拍同步或具体制作软件作猜测。时间采样能看清状态交接，不能单凭 0.6 秒间隔确认全部中间帧无瑕疵。

## 首页的可见动作

| 观察窗口 | 可见内容 | 可转移的方法 |
|---|---|---|
| 0–1.2 秒采样 | 三张内容卡由靠近、倾斜，展开为较平稳的横排；卡内内容有变化 | 先给出可识别实体，再展示差异；外框和编号保留身份 |
| 1.2–2.4 秒采样 | 卡片依次侧转，另一面显示代码符号；“复刻”出现 | 以翻面解释表示转换；翻转沿顺序传递，避免瞬间换成另一组对象 |
| 2.4–3.6 秒采样 | 三张卡缩小、靠拢，连接线汇聚到中间节点 | 位移先建立关系，连线随后确认关系；信息密度增加时给构图让位 |
| 3.6–4.8 秒采样 | 下方三张输出卡展开，分别承担标题、配色、内容；“Remix”接过文字焦点 | 从共同来源分发到不同用途，保留一条连续阅读路径 |
| 4.8–5.97 秒采样 | 主拓扑与文字位置基本稳定，输出卡内仍有局部表现 | 大结构停住供阅读，小范围生命感不干扰主关系 |

## 本轮原创复现的范围

`mf-card-convergence` 直接转译首页“同一对象翻面、汇聚、生成关系”的方法；图形、中文内容、配色与时长重新设计。

`mf-mask-typeset`、`mf-focus-handoff`、`mf-trace-assembly` 是面向解释型视频的原创方法延展，并结合公开社区中的文字显露、组装与连续解释方法。它们不是广场作品的逐镜复刻。

后续增加 `mf-type-orbit-lock` 与 `mf-concept-bridge`，分别转译实际观察到的“环形字粒收成可读句子”和“同一主体换位，留白承接新概念”。使用原创中文与几何对象，不复制原片的脑模型、键帽、商标、影像或音轨。

## 公开数据与文字示例的补充检查

另从官方公开仓库的固定提交取得 `shot-gallery-data-type.mp4`，检查到 1440×540、12fps、6秒、只有视频流。按 0、0.5、1.0…5.5 秒抽取并静态审阅 12 帧；见联系表（外部或本机资源，未随公开包收录）。其中包含柱形、数字卡、代码揭示、分段主标题与强调线；约3秒后展示序列再次出现。只能据此说明这些静态状态及先后关系，未把抽帧检查写成完整连续播放或原片听审。

这份样例补充了“布局先稳定、局部信息分批出现”的用法。新候选的14秒时长、中文主题、材料表现和配色为独立设计，并未复制其镜头库。

## 应用时保留的区别

- 观察结果与原创编排参数分别记录。新示例的缓动、时长和文字不是原站的精确参数。
- 画面中的关系必须来自内容；翻面、光窗和线条只是帮助观察，不能替代数据、证明或仿真。
- 公开可读不等于允许整库复制。未确认许可的源码只用于研究机制；新示例独立编写，不带原片素材、商标、音轨或源站代码。
- 本次目标是升级可复用方法库，没有改动此前的机器人、无人机或科普成片。
