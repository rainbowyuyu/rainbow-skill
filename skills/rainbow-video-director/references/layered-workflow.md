# 多段组片与协作

## 默认包

单段可只交一份完整Markdown。多段建议如下，按实际任务删减：

```text
00-film-brief.md       全片总提示词，直接可读
01-sequence.md         紧凑时序和各段入口/出口
scenes/S01.md          完整分段执行提示词
scenes/S02.md          下一段，具体继承上段状态
sources.md            实际用到的事实/素材/参考
```

正式制作再添加源工程、音频谱、缓存、预演与成片。复杂时间协作可添加film-plan.json，不要求纯提示词凑JSON或四层文件。段长服从因果/音乐/理解，不按固定秒格机械均分。

每份scene应能独立复制使用：带全片位置、目标、共同美术/主体、准确时间链、确切字句与声音、技术路径、预演验收和出口。引用外部事实资料可以，但不能只写“见L1/L2”让执行者重新组装意图。

## 一条主时钟

用整数帧分段，区间左闭右开。总时长T、帧率F与帧数N必须相容；全片帧n对应t=n/F，片段局部帧为n−start_frame。真实配音/素材源时间分列。主编排负责总时间，所有实现读取同一版本；改变段长时更新后续事件、字幕、公式表达式、仪表时间基准和声效。

相邻段交接至少写：持续的实体及姿态/位置、视点与主运动方向、当前文字/焦点、光照/颜色、还在响的尾音、下一段第一个动作。位置数字只在有统一坐标时写，不能用伪精确值替代可理解的构图。

跨镜头可做硬切、动作匹配、遮挡或溶解，各自写清目的。预留过渡handles用于合成，不重复计入影片总长；只由最终合成处理一次，不让每段独立做淡入淡出后再叠一遍。循环单独检查边界状态与速度。

主体首次接触水/地、主体整体通过、摄影机通过、观众声场变化是不同事件。布景显现不是实物行程；更新地形、灯光和透明状态时检查邻帧、影子和反射。

## 协作方式按难点选择

优先按段落或难点拆工，给每人完整上下文和独占文件。例如一人做嵌套入口预演、一人核科学机制、一人写音乐/旁白编排。需要大量3D与图形同步时可以分成编排、实体/摄影、文字/可视化、声音四个职责；四职责是协作方式，不是每片必须生成四套文档。

子任务带当前全片总提示词、本段正文、版本/路径、素材事实、共享事件及验收窗口。可创造性提出替代方案，但不得无声改主时钟或实体身份。主导演负责融合冲突，交付仍是一部片的连续提示词与实现，不把协作者报告原样堆给用户。

## 可选 film-plan v2

仅用于检查时间覆盖与文件引用，不能评价故事与画面。示意schema如下（此例的路径与正文在实际包中必须存在）：

```json
{
  "schema_version": 2,
  "title": "两段连续讲解",
  "duration_seconds": 12,
  "fps": 30,
  "frame_count": 360,
  "global_prompt_file": "00-film-brief.md",
  "loop": false,
  "segments": [
    {"id":"S01","start_frame":0,"end_frame":150,"prompt_file":"scenes/S01.md",
     "entry_state":"主体从画面左侧进入，背景低亮。",
     "exit_state":"同一主体停在右下三分处，前景框沿向上运动。",
     "transition_out":{"type":"occlusion","description":"框沿遮挡后接到同一部件的近景，保持向上方向。"}},
    {"id":"S02","start_frame":150,"end_frame":360,"prompt_file":"scenes/S02.md",
     "entry_state":"部件近景从同一向上运动继续，随后减速。",
     "exit_state":"部件稳定，解释字退出，留下完整结果。",
     "transition_out":{"type":"end","description":"动作落定并留住声音尾部后结束。"}}
  ],
  "events":[{"id":"contact","frame":210,"segment_id":"S02"}]
}
```

运行 `python scripts/validate_director_package.py <包目录>`，v2不要求评分文件、每秒JSON或四层目录。缺帧段、重叠、重复ID、越界事件、缺prompt会报告错误；文字语义、实际动作和循环连续性仍由看稿/预演确认。

声音谱继续用validate_sfx_cues.py。v2事件是frame，声音校验的事件是time秒：由唯一film-plan派生 `time=frame/fps`，连同项目版本生成其contract视图；不要直接把v2文件当作旧声音contract，也不手工维护两套可编辑主表。纯Markdown声音方案也可先交，实际素材到位再建技术谱。

## 旧包兼容

没有film-plan.json时，validate_director_package保留旧的contract+四层包检查并报告legacy-layered。旧分数量表只服务已存在的历史包格式，不是新版质量目标；不为新任务重建它，也不自动修改历史包。原始技能已备份于本轮work/director-rebuild-20261031/before。
