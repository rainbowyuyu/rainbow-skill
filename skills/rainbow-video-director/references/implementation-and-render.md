# 确定性制作与交付

先核实当前工程、工具版本、共享依赖、可用素材和目标画幅。提示词选择可实现路线，正式制作再提供真实命令。不要为每部片复制node_modules，也不要把Windows/H100/Blender混写成作者案例里的Metal配置。

## 一条时间线，任意时间可重现

HTML/Canvas/Three.js：建立 `evaluate(t)` 返回状态，`seek(t)` 把状态应用并完成当帧绘制。RAF可驱动交互预览的播放位置，但不能成为视觉状态的唯一来源。禁用会独立跑动的CSS transition、未重置计时器、逐调用累积的相机旋转和不固定的随机数。顺序播放与随机seek到同一t应一致。

Remotion：使用当前帧与实际fps驱动属性，核对已安装版本的时间API。嵌套片段的局部帧不等于全片帧，音轨源帧又是第三个时间轴；显式转换，避免片段从零开始时实体状态也重置。当前官网API可能新于项目版本，不为照文档强制升级。

Blender：相机/物体按帧求值，物理先烘焙为缓存，再对同一缓存渲染。Manim：使用其时间线、变换关系与实际渲染帧率；需要重采样的后处理从缓存画面进行，不伪称所有引擎都必须有浏览器seek函数。

真实物理用固定步长求解并缓存状态。随机访问可插值缓存，或从已知检查点确定性重演；不要每次截图只前进一步。显示速度、角度、图表和声音控制量来自同一轨迹，强调用颜色/位置/透明度，说明线在运镜中保持稳定屏幕线宽。

## 常用运动的可执行起点

归一化段内时间 `u=clamp((t-a)/(b-a),0,1)`。平稳起止可用五次曲线 `6u^5-15u^4+10u^3`，它在两端速度和加速度为0，适合需停稳的移动；连续穿梭镜头不要每段都归零，应以共享端点和切线速度连接路径。曲线位置均匀不代表弧长速度均匀，沿轨道飞行可预采样弧长后反查参数。

无回弹弹簧可从临界阻尼响应 `x(t)=1-(1+ωt)e^(−ωt)` 起步（初始位置0、初速0、固定目标1）；有初速或拖拽放手要使用匹配初始条件的解，不能直接重置。它仅渐近到目标，精确闭环要用周期路径或设计一段显式收束区，不强行把末帧钳到目标造成跳变。

变形除了相同顶点数，还要统一路径方向、起点、孔洞与子路径对应。透视变形遵循真实3D或明确2D设计；刚体不能在运镜时忽然反转前后关系。镜头roll用于转弯/主观感受，阅读区逐渐回稳；不要随机抖动代替运动能量。

## 字体、素材与帧准备

捕获前等待字体加载、纹理上传和当前素材帧解码。真实视频可以预先解码成帧序列，或使用当前引擎验证过的离线解码组件；不必所有项目都复制整部视频为PNG。源时间到影片时间的映射记录在唯一时序中，避免先seek到帧却截到上一帧。

每个待渲染页可提供 `ready` 和 `await seek(t)`。等待条件必须对应这一帧的实际加载，不是固定sleep。屏幕预览与离线捕获共用求值函数，不能另做漂亮预览而最终渲染走旧逻辑。

## 子帧模糊与循环

选定输出fps为F、快门比例s（如0.5表示半个帧间隔）、每帧K样本，样本时刻可写为：

`t(n,k) = n/F + ((k+0.5)/K-0.5) * s/F`，其中 `k=0…K−1`。

所有子帧由同一seek求值，在线性光空间加权累积后输出。写清是几何/相机模糊还是整张图；文字若需要清晰可最后合成，但物体遮挡关系仍应一致。像素/定格风格通常不用时间模糊。首尾采样越界须有显式策略：循环取模，非循环采用有定义的前后状态或减小边界快门；不要从未定义帧取垃圾。

精确周期T需要位置、姿态、颜色、文字、光标、粒子相位以及可见速度一致，即S(T)=S(0)，连续动画还检查导数。N=T·F必须是整数，导出n=0…N−1；第N帧用于检查，不追加编码。若用户字面要求末编码帧也等于首帧，则设计首尾静止停留并说明它会占时间，不能同时承诺不停顿周期运动。

## 先渲染什么

先做风险最高的2–4秒：嵌套入口、透明水面、机械接触、形变拓扑或文字交接。然后做全片低成本预演；检查整体节奏后再提升材质与采样。接缝检查 t−1/F、t、t+1/F，形变额外查25%/50%/75%，最快运动和最密文字另看连续片段。

代码预演可做一个很小的乱序采样检查：相同时间从不同历史抵达时状态/像素相同；检查速度连续时用有限差分，容差由数值噪声和目标帧率决定。全片仍需原速回看，不能用同帧hash证明好看。

## 音频与交付命令

音乐/旁白/FX共用全片时钟，但各自保留真实源时间。旁白完整自然，不使用统一atempo硬塞旧时长。精确事件音对语义同步点；必要时整句让位，不按每个字抽吸。响度目标按渠道选，选-14LUFS不等于必须所有短片都-14；最终编码复测响度/真峰，真实听感仍另验。

交付命令至少说明工作目录、入口、配置、帧率、尺寸、帧范围、输出路径及依赖来源。要引用真实存在的脚本与实测参数，不能发明 `npm run render`。代码制作时应写好预览/抽帧/全渲染脚本，再运行小范围确认；纯提示词可要求制作方提供这些命令，但不得标成已经验证。

用户已有片源、配音和工具保持可追溯。只打包必要源文件与许可允许的资产，依赖以锁文件/共享路径交接；最终输出包含源工程、时序、预览、实际命令和MP4。用ffprobe检查尺寸/fps/帧数/音轨并做完整解码；媒体内容好坏由实际看听记录决定。
