# 专项协作提示词（可选）

先给协作者完整的分段执行提示词和全片总指令，然后限定本次职责。它要实现一段可观看的内容或解决一个具体难点；不能只按层名生成一套文档。

说明输入版本、独占输出位置、可修改范围和交接时间。列出本层要继承的实体/镜头/字句/声音事件，以及依赖其他人的真实输入。跨层冲突由主导演统一改时钟。

3D专项交实体与摄影实现、关键帧预演及已知问题；图形专项交同一画面的文字/公式实现；音频专项交实际语句/事件谱与处理记录。只写提示词时对应交完整设计，不能谎称已渲染/听审。

不默认要求四层×六文件或逐秒JSON。按真实复杂度拆工，合回同一分段成片。配音/音效专项读取performance-and-sound与sound-sourcing-and-mix，保留原曲、现有声音及实际事件。
