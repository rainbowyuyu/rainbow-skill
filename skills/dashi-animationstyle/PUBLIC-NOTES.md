本目录来自已安装的第三方技能，保留其原始许可与署名。

本机用户名、工作目录、内网地址与聊天标识已改为示例。机器专用配置、声音参考、原始参考网页和媒体、生成缓存未收录。需要的工具必须按当前项目实际定位；文档中的示例路径不代表已部署。

## 模板的使用方式

风格 HTML 是作品模板，需要通过 `pipeline/新建作品.mjs` 创建作品目录并准备时间线与音频，不保证直接打开每个模板就能播放。页面依赖的 `timeline.js` 在作品阶段生成（示例见 `examples/token/timeline.js`）；共享动效代码来自 `pipeline/动效部件.js`，应按生成脚本复制到作品目录。公开包不含 Token 示例旁白音频，使用示例前补齐音频，或改用自己的旁白按正文的“用法一”创建。先运行环境自检，再核对所选风格的字体和资源。
