# sound

Find and download sound effects from Freesound for videos, using download counts, ratings, descriptions, and licenses to select clips. 用 Freesound 给视频找音效：按下载量、评分人数、上传者描述、时长和许可证挑选，再下载到工程里。用户说「找个音效」「配个 whoosh / 点击 / 碰撞声」「给这个镜头加音效」「只要 CC0 的」时使用。

未核实完整分发许可或独立来源，保留目录记录，未搬运正文及代码。

已发现的环境：claude。
