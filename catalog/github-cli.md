# github-cli

GitHub CLI (gh) comprehensive reference for repositories, issues, pull requests, Actions, projects, releases, gists, codespaces, organizations, extensions, and all GitHub operations from the command line. Use for: (1) Repository management and cloning, (2) Issue and pull request workflows, (3) CI/CD pipeline management, (4) GitHub API automation, (5) Authentication and security setup, (6) Bulk operations and scripting. Triggers include requests for 'github', 'gh', 'git', 'repository', 'pull request', 'issue', 'ci/cd', 'workflow', 'release', 'clone', 'fork', 'merge', 'review', 'deploy', or GitHub-related development tasks.
