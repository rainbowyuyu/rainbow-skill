# wtt-code-animation-studio

将用户的想法、主题、文章或现成剧本制作成前端代码动画，按内容与实际旁白决定时长，交付中文剧本、分镜、可改源码和带声音 MP4。编剧后根据内容推荐风格，由用户选择再制作；覆盖手绘纸纹、复古印刷网点、像素、水彩、沙画、粉笔、粒子、马赛克、黏土外观、MG 与混合画法，新增画法按片实现与验证；默认 Canvas/p5.js 逐帧绘制，经浏览器和 FFmpeg 导出。用户只要剧本或技术分析时只完成指定范围。

未核实完整分发许可或独立来源，保留目录记录，未搬运正文及代码。

已发现的环境：claude。

没有可核实的独立上游地址；请从原安装渠道查找，不猜测下载地址。
